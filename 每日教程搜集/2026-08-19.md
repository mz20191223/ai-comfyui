### 1.2 Qwen-Image-Edit 官方 ComfyUI 原生工作流精确清单 + Lightning 4-step（🆕 出图线 A 可操作配方）
- 来源：`docs.comfy.org/tutorials/image/qwen/qwen-image-edit`（官方）、`github.com/ModelTC/LightX2V-Qwen-Image-Lightning`（LoRA 仓库，确认有 `Qwen-Image-2512-Lightning-4steps-V1.0`，2026-01-01 发布）、`ernie-image.app` 混合管线、`thundercompute.com` 实战。
- 核心要点（官方文件清单，可直接落地）：
  - 模型目录：`diffusion_models/qwen_image_edit_fp8_e4m3fn.safetensors` + `text_encoders/qwen_2.5_vl_7b_fp8_scaled.safetensors` + `vae/qwen_image_vae.safetensors` + `loras/Qwen-Image-Lightning-4steps-V1.0.safetensors`。
  - 参数纪律（官方明确，错配是质量翻车首要原因）：BF16 → CFG 4.0 / 40 步；FP8 → CFG 4.0 / 20 步；**FP8 + Lightning → CFG 1.0 / 4 步**（必须，否则 grid artifacts / 过饱和）。
  - **🔴 关键坑（官方坐实）**：`qwen_image_fp8_e4m3fn` 是直接 downcast 自 bf16，配 bf16 训练的 Lightning LoRA 会产生网格伪影；官方已发布"scaled fp8 base"解决兼容。→ 我方 HAI 用的是 `qwen-image-edit-2511/2512-Q4_K_M.gguf`（GGUF 量化，非 fp8），接入 Lightning 类 LoRA 时同样需验证量化 base 与 LoRA 的兼容，先小范围测再上桃子。
  - 官方 2512 版本支持最多 3 张输入图（多图融合/角色一致性）；支持 Union ControlNet LoRA（depth/edge/keypoint，strength 0.5–0.8）。
  - ERNIE-Image（生成，文字/排版强）+ Qwen-Image-Edit（编辑，Arena 编辑榜 #1，Apache 2.0 双开源）混合管线：FP8 + Lightning 4-step，4090D 首图 ~55s / 后续 ~34s。
- 适用场景：出图线 A 角色圣经/参考图生成提速（Lightning 4-step），以及多参考锁角色出桃子多角度参考集（服务于 Step 1 与 Step 2）。
