## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 官方「角色一致性」博客（SOP 级，直接服务第一步）
- 来源：https://ltx.io/blog/how-to-maintain-character-consistency-in-ai-video
- 核心：把跨镜一致性拆成**四层技术栈**，并给了可落参数：
  1. **Image Conditioning（帧 0 锚定）**：用 `TI2VidTwoStagesPipeline`，参考图替换起始噪声，角色外观从帧 0 贯穿整段；首帧取景要与期望第一帧一致（走路用全身、特写用近景）。
  2. **IC-LoRA（结构控制）**：Pose / Motion Track / Union 三种适配器锁身体结构与运动（承接 C119 画轨迹）。
  3. **角色 LoRA 训练**：数据集 20–30 张多角度图、500–2000 步、rank 32–64，把身份编码进权重，跨生成免每次喂参考图。
  4. **固定 50–80 词角色提示词块**：所有镜头共用同一段角色描述。
- 适用：这正是我们「Qwen 出角色圣经静帧 → LTX I2V 出带情节镜」主线被官方点名的做法，直接落成《桃子第一步 SOP v2》技术标准。

### 1.2 LTX-2.5 Ingredients 官方参数（升级 C133：待验 → 有官方设置可试）
- 来源：https://website.ltx.io/model/capabilities/ingredients
- 核心：参考表（reference sheet）打包法——角色脸+转面、道具、场景各一干净面板，**黑底无文字**，作为静态视频循环到**至少 121 帧**（输出分辨率+fps）；两段式提示词 `Reference sheet: [描述] / Generated video: [动作]`。
- 官方验证设置（直接可用）：base = `LTX-2.3-22B` + `ltx-2.3-22b-ic-lora-ingredients-0.9.safetensors`；**strength 1.4 / 30 步 / CFG 4.0 / STG mode `stg_v` block 29 scale 1.0**；最佳 768×448、121 帧、24fps。
- 注意：官方 Ingredients 用的是 **LTX-2.3** IC-LoRA，不是 2.5；我们主线仍按 2.5 走，2.3 可作 interim（见 C169）。
- 适用：桃子「角色圣经一表锁三元素（人/物/景）」打包候选，减 C121 多参考图顺序错乱风险。

### 1.3 LTX-2.5 时间一致性博客（STG 修复纪律，进 SOP v2）
- 来源：https://ltx.io/blog/temporal-consistency-in-ai-video
- 可直用的排查→修复表：
  - **闪烁（Flickering）**：调高 STG scale；降提示词场景复杂度；用图像条件锚定帧 0。
  - **水波/扭曲（Warble）**：调整 STG 作用的 transformer block；缩短片段；用 `RetakePipeline` 只重生坏段。
  - **身份漂移（Identity Drift）**：用**原生多镜输出**而非一长段；IC-LoRA Pose；训角色 LoRA。
  - **运动断裂（Motion Discontinuities）**：提示词连续显式写运动；首尾帧关键帧插值；用 motion-trajectory 直接画路径。
- 适用：直接并入《桃子第一步 SOP v2》的「五类失败自查」升级版。

### 1.4 LTX-2.5 原生多镜 + 一致声音技巧
- 来源：https://website.ltx.io/model/capabilities/multi-shot-video-generation
- 官方确认：原生多镜单 pass 跨切保持角色/环境/光/声一致；社区实例 **JoyAI-Echo + LTX Merge**——把 Echo 的身份记忆 graft 到 LTX 自然嗓音，单序列全镜一致角色+人级旁白。→ 漫剧（Step3）旁白一致性可参考。

### 1.5 hypit（C168，新漫剧装配/包装层候选）
- 来源：https://github.com/hypit-ai/hypit ｜ 介绍 https://hypit.ai/ ｜ 评测 https://aiidelist.com/blog/hypit-ai-video-cloning-workflow
- 核心：给 Claude Code / Codex 这类编程 Agent 一门 **SVML 词级锚定视频语言**；上传参考视频→Agent 逆向拆成**可编辑/可重跑的工程**（画面/字幕/B-roll/特效全绑在「词」而非「秒」上）；改一句台词全轨自动重排；本地无头 Chromium 并发渲染，**BYOK（Seedance / GPT Image / WhisperX）**；官方示例 ~$1/条（20s），单命令出 100 变体。Apache-2.0 + 附加条款（禁多租户 SaaS / 商业转售）。
- 星数：8.7k→11.2k（09-23 实时），日增快。
- 适用：**Step3 漫剧包装/批量变体层** + 后期词级精修（改台词不重渲）；**不是第一步核心生成工具**，且依赖云模型出 A-roll、需 Node 22.15+ 与编程 Agent。
- 状态：待验（Step3 预研）。详见 C168。

**下一步：多角色** — 今日无新必须项；Kling 3.0 Elements / Omni（C77/C95/C105/C119）维持首选云侧；本地多角色仍看 SkyReels-V3（C117）。
