### 1.2 「按镜头选模型」成为 2026 主流方法论（多源对齐，印证并强化我们基线）
- **来源**：toolso.ai 实用指南（https://toolso.ai/blog/ai-video-generation-practical-guide）、agentwriting 创作指南（https://agentwriting.com/?p=25482/）、tahou 全链路指南（https://www.tahou.com/article/214768628284125189）、localaimaster 本地实测（https://localaimaster.com/blog/local-ai-video-generation）。
- **核心范式**：**不再按项目绑一个工具，而是把每个镜头路由给最合适的模型**（"The per-clip price spread is ~5×… a single-vendor project almost always overpays or under-delivers"）。具体路由表：
  - 英雄镜头 / 画质天花板 → LTX 本地 或 Kling 3.0
  - 长镜头 / 锁角色 / 对口型 → Seedance 2.5（30s 一镜 + 50 参考）
  - 多角色 / 控制 / 物理准 → Kling 3.0
  - 填充 B-roll / 批量 / 体积 → Kling 3.0 / MiniMax H3
  - 控制 / 关键帧 / 局部返工 → Runway Gen-4.5
  - 本地可控 + 音画同网 → LTX-2.5
- **对桃子的意义**：这正好是我们 v4 多模型基线的理论背书——「本地 LTX 控 + 云快验 Kling/Seedance」双轨不是临时妥协，而是 2026 行业共识。建议把这条写入 v5 编排原则。

### 1.3 LTX-2.5 能力坐实补充（官方 ComfyUI Day-0 集成）
- **官方文档**（https://links.comfy.org/docLTX2_5）+ RunComfy 工作流（https://runcomfy.com/comfyui-workflows/ltx-2-5-comfyui-image-to-video-synced-audio）+ 今日头条/IT168 实测（https://www.toutiao.com/article/7673040796823601707）+ intelligentliving.co 综述。
- **新增确认点**：
  - **Diffusion Fidelity Rendering**：按场景复杂度分配算力——结构（运动/构图/取景）先在 8× 时间压缩潜空间生成，同时产出一组高保真 keyframes（复杂镜头自动多给 keyframes）；再由专用 pixel-diffusion 阶段渲染最终帧。→ 纹理/材质/人脸逐像素级、复杂镜头自动多分配算力。
  - **原生多镜头**：一次生成即多镜跨切，跨镜头保持角色/环境/光线/嗓音/风格一致。
  - **Auto duration**：读 prompt 预测时长，少调两个参数。
  - **速度对比**（厂商自报，GB200 自托管单图 10s 视频）：LTX-2.5=6.8s；Gemini Omni=52s；Grok=63s；Veo 3.1=70s(8s 片段)；Seedance 2.5=317s；Kling 3.0 Pro=398s。→ LTX 速度天花板（自托管场景）。
  - **成本**：自托管权重免费（LTX-2.x Community License，年营收<1000万美元商用免费）；托管 API $0.09/s(720p)→$0.30/s(4K fast)。社区 FP8/CPU offload 16–24GB 可跑（**印证 A10 24GB 可行**，与 C69/C80 一致）。
  - **模板**：官方 3 个原生工作流 T2V / I2V / FLF2V（首尾帧）。

### 1.4 Seedance 2.5 实务纪律坐实（多源对齐，可直接当 SOP）
- **来源**：博客园测评（https://www.cnblogs.com/ji-ke-ke/p/21553788）、18183 图生视频教程（https://www.18183.com/gonglue/202608/o0il4hc4.html）、今日头条保姆级流程（https://www.toutiao.com/a7677855484740796974）。
- **能力坐实**：50 全模态参考（30 图 + 10 视频 + 10 音频）、单段原生 30s 直出、时间戳分镜控制（"0-3s 校园开场 / 3-8s 自我介绍 / 8-12s 互动"）、智能局部编辑（框选某段改台词/黑板字，不重做整条）。
- **图生视频提示词公式**（可直接用）：`保持上传图片的主体/身份/构图/颜色和光线。动画化[主体动作]。添加[镜头运动]。保持[保护细节]稳定。结尾于[最终画面]。`
- **稳妥纪律**：首次 5s 验证主体稳定再延长；480/720p 试跑再升 1080p；每次只增/改一个变量（动作 or 镜头 or 光线）；生成后检查「形状/脸部/手部/文字」。
- **对桃子第一步的意义**：这些是 C56/C66/C72 的 Seedance 实务 SOP 补全，可直接落到云快验轨道。

### 1.5 Kling 3.0 工作流细节（官方 + 教程，标注 SEO 站）
- **官方**（https://klingai.com/）：视频 3.0 / 视频 3.0 Omni，Omni One 架构，原生多模态指令深度解析 + 跨任务融合，视觉主体 + 听觉音色双重绑定，超长视频精准分镜，音画同步特征解耦。
- **教程细节**（klingai26.com 实操页，⚠️ 该域名为 SEO/镜像站，**非 official klingai.com**，其工作流写法参考但不作为官宣依据）：

  - I2V：**图携带身份，提示词要短只写运动**（"describe motion for the subject and the camera separately"）

- **价格参考**（kling3ai.app，SEO 站，仅作区间参考）：Starter $19.9 / Creator $49.9 / Pro $99.9，约 $0.083–0.10/point。→ 国内访问与单价仍待用户实跑验证（维持 C77 标注）。

### 1.7 本地开源工具箱补货候选（GitHub 实测 / awesome-repos）

### 1.8 H3 vs Wan 2.2 本地实测 + 完整 2K 边界（印证 C55/C64）
- **来源**：今日头条 Mac 实测（https://m.toutiao.com/article/7671917645372850726）+ 5090 实测（https://www.toutiao.com/a7671967976593146418）+ minimaxh3.tv 官方比对（https://minimaxh3.tv/zh/blog/minimax-h3-vs-wan-2-2）。
- **核心结论**：
  - H3 本地 base 输出 **768p**，完整 2K 需官方 API（再生成模块未开源）→ **印证 C55/C64 本地 A10 跑 768p/1344×768 质量补镜轨道，不指望本地 2K**。
  - H3 原生立体声音频（含台词口型、环境声）一次生成；Wan 2.2 静音需后期配音 → 做叙事内容 H3 总工时更短。
  - **选型法则**：动作/群戏/需控制 → Wan 2.2；对白/氛围/要声音 → H3（再次印证「按镜头选模型」）。
  - 社区节点 **CharlesMod/h3-studio**（FL2VA 首尾帧 I2V + Ref2VA 多模态参考，权重 `pruned_int8_convrot` + `qwen3vl_32b nvfp4_awq` 文本编码器）→ **标记社区节点、需用户实跑验证**，印证 C55 权重清单。
  - ⚠️ **minimaxh3.tv 自述为独立服务，非 MiniMax 官方、非阿里云运营**（其 zh 文已披露），价格/功能以 MiniMax 官方为准；勿把该站当官方。
