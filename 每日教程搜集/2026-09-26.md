### 1.2 LTX-2.5 实操九技巧 —— 强化 SOP 纪律 C106/C107（零成本·必进《桃子第一步 SOP v2》）
- 来源：mhpq.cn 资讯（2026-09-26）http://www.mhpq.cn/news/229748
- 可落地的几条：
  - 技巧5 **多镜头锁定**：每镜描述重复关键特征词（例「红夹克青年 / 灰白旧工厂」），重复越一致跨镜越稳。
  - 技巧8 **I2V 提示词只写运动不写内容**（「雨滴滑落 / 窗帘被风吹动 / 人物缓缓转头望向镜头」）——内容已由首帧定，再写场景反而干扰运动生成。→ 强化 C107/C106。
  - 技巧9 **控制运动幅度**：「轻微/缓慢/微妙」vs「剧烈/快速」决定运动幅度；新手把动作写太猛 → 画面抖动/形变。
  - 技巧7 **Duration Head 时长预测器**：提示词里暗示节奏（缓慢镜头/快速切换/长时间注视），不指定帧数时交给时长头自动判断。
  - 技巧6 **负面提示词**：distilled CFG1 时作用有限；人物特写场景适度配合可减瑕疵（安全网）。
  - 技巧4 **光线词**（黄金时刻/逆光剪影/体积光穿透雾气）值得多写词，LTX 扩散保真度渲染对复杂光线分配更多算力。

### 1.3 Wan 3.0 官方 ComfyUI API Nodes 落地 —— 细化 C46/C71/C101
- 来源：wan2.video（Verified Sep 14, 2026）https://wan2.video/wan3.0-comfyui
- 核心：ComfyUI v0.33.4+ 内置 Wan 3.0 官方 API Nodes + 3 套模板（T2V / I2V / Reference-to-Video），30s 上限、1080p、原生音画；参考语法 `@Image1 / @Video1 / @Audio1`（资产挂在参考节点上，标签只引用不自动上传）。本地权重仍无。
- 适用：桃子云快验「参考直读 one-take」仍可用，但消耗 Comfy 额度（阿里云 Model Studio 免费配额不自动适用，需单独计费）。
- 维持：仅云、成片优先本地开源；IP 风险维持内部试验。

### 1.4 Kling 3.0 Omni 完整指南 —— 强化 C77/C95/C105/C117
- 来源：rekreate.ai（Kling 3.0 完整指南）https://rekreate.ai/models/kling-3-0
- 核心：Multi-shot 最多 **6 shots × 3–15s/镜**；segment mode 16–300s；Standard（快/省，试提示词）vs Pro（锐利/稳脸/复杂运动，出最终版）；四段式提示词（主体+动作+场景+风格）；**每个镜头角色描述保持一致、只换景别/动作/相机**；参考图锁身份；负面提示词防 recurring artifacts（文字/多指/招牌扭曲）。
- 适用：桃子第一步云侧串镜首选之一（身份锁 + 原生音画 + 首尾帧）。成本：API ≈0.075 美元/秒（≈0.5–0.75 元/秒）。

### 1.7 角色一致性 2026 通用工作流 —— 强化 C43/C58/C98/C107
- 来源：wan-3.io（6步+two-clip test）、reccloud、piclumen、consistentcharacter.ai
- 可落地纪律（进 SOP）：
  - **Two-clip test（漂移自检）**：用真实工作流生成同一角色两镜 → 静音拼接看过渡 →「这是同一个人吗？」犹豫即失败；漂移先在 step2 抓，别到 step9。→ 桃子串镜 QA 必备。
  - **Asset pack 前置**：锁主参考后，先产 6–10 姿势 + 8–12 表情 + 2–3 背景，再逐镜动画（2–6s）——与我们的「角色圣经六视图」一致。
  - **冻结脸块**：一句精确脸 + outfit 描述，每镜 verbatim 粘贴，绝不改写（改写 = 漂移）。
  - **I2V anchor 每镜**：永远从锚定关键帧做 I2V，不从纯文本重生身份。

### 1.8 Mickmumpitz 模块化电影工作流 —— 强化 C104
- 来源：今日头条转载（2026-09-04）+ Pixo/agent 技能盘点 https://www.toutiao.com/article/7681646123601232399
- 核心：「Nothing is baked in」——每镜四路输入（角色参考/场景参考/声音样本/提示词），换主角 = 换参考图重跑一镜；自写十几个 ComfyUI 节点（镜头复制/排序/装配/跨镜调色）全开源（Manager 搜 Mickmumpitz）；9月初版已能渲 Blender 视口动画 → 成片 + 对口型音同步。4 个月换两代引擎（Wan VACE+SkyReels → H3），架构一版未动。
- 适用：漫剧 Step3 装配范式参考；印证我们「参考图层化」主线哲学。
