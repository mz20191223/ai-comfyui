## 1. 新发现：教程 / 工具 / 工作流

### 🔥 头条（本地开源·直接服务「原生音画」诉求）
- **C172 DreamX-Creator 1.0**（阿里 AMap/高德地图团队，2026-09-03 开源，Apache 2.0）
  - 来源：GitHub `AMAP-ML/DreamX-Creator` + HF `GD-ML/DreamX-Creator` + arXiv 2608.31106；第三方实测 ik3d.fr/dreamx-creator。
  - 核心：原生**音画同步**联合生成（7B 视频 DiT + 7B 音频 DiT，Gated Cross-Modal Attention 逐 token 门控），输出 2K（5B SR-DiT 一步 Refiner 上采样）；**基于 Wan2.2 底座**（共享文本编码器/VAE，自带 CreatorDACVAE 音频 VAE）；单卡可跑 + CPU-offload。
  - 适用：本地「图+提示词→带同步声音的片段」，与我们 LTX-2.5 / H3 的「原生音画」诉求同赛道，且 Apache 2.0 商用最友好。
  - ⚠️ 关键限制：**目前仅推理脚本（两模块各带 requirements+README），ComfyUI 节点未确认**；无硬 benchmark 表；需实跑验画质/运动是否及 LTX-2.5。**先跟踪，不替换主线。**

### 本地视频模型 / 工作流
- **C173 Wan2.2-ReMix V3.0**（CSDN 本地实践）
  - 区分 I2V 与 Remix 两种模式：I2V = 参考图作强锚点（严格复刻首帧，运动受限易僵）；Remix = 参考图作**特征线索**（提取画风/构图/主体，允许重新组织画面，运动更自然，但对提示词质量要求更高，不严格复刻）。
  - 适用：漫剧里「想保留角色大体特征又要大动作/换场景」时选 Remix；严格定妆复刻选 I2V。8–12G 显存 FP8 可跑 3–6s 片段，系统内存建议 32GB+，`--vram-management auto` 防碎片。
- **LTX-2.5 Ingredients IC-LoRA**（reveo.news / r/StableDiffusion 单帖）
  - 单一参考表（角色转面+道具+场景合一张）驱一致视频，模型卡 `Lightricks/LTX-2.5-22b-IC-LoRA-Ingredients`。
  - ⚠️ **仍仅 Reddit 单源 + 门控 HF，无 Lightricks 官方 changelog 确认** → 维持 C133/C160「待验」，不轻信。
- **LTX Studio 免费档含 LTX-2.5**（intelligenttools.co）
  - Lightricks 浏览器平台，所有套餐（含免费档）可用 LTX-2.5；商业免费阈值年营收 < $10M。属云端托管选项，非本地，**仅作云快验备选**，不进本地主线。

### 出图线 A
- **Qwen-Image-2.1 官方 ComfyUI 模板落实**（cldnavi.com / comfy.org）
  - Image Edit 模板支持 `image_1`…`image_16` 按索引指代（`<image_1>`…），原生 2K，int8 约 17GB；RGBA 透明输出（需提示词显式声明）。
  - ⚠️ **仅非商用许可** → 不出图线A 切换，维持 Qwen-Image-Edit-2511/2512。

### 云快验 / 闭源
- **Sora API 今日（2026-09-24）正式关停**（golden-prompts 迁移指南坐实）
  - Sora App 已于 2026-04-26 下线，Sora API 于 09-24 关停，无继任模型。迁移目标 = Veo 3.1 / Kling 3.0 / Seedance 2.5 / Wan 3.0 / LTX-2.5。
  - 影响：**任何标「Sora2」入口（含 Digen 商店页所列 Sora2 集成）均失效/误导** → 维持 C82 禁用。
- **Kling 3.0 Omni 串镜纪律再坐实**（rekreate.ai / kavel.ai）
  - 最多 **6 shots / 每 shot 3–15s**，原生音画；Elements 锁角色 + Motion Control 复制参考视频动作；`[说话人:名字]` 对白。`Shot 1 / Shot 2 ...` 每段保持角色描述一致、只换景别/动作/相机。**第一步单角色带情节（多镜）最佳云快验之一**。
- **Seedance 2.5 vs Kling 横评**（rekreate / kavel；neural4d 偏袒页仅参考）
  - Seedance：30s 单镜 + 最多 50 参考（30图/10视频/10音频）+ region inpainting 局部修改。Kling：多镜叙事 + 人体运动最强 + Motion Control。两者互补，无推翻。
- **Wan 3.0**（wan2.video / comfy.org）
  - 仅云 ComfyUI API Nodes，无本地权重；480/720/1080p、30s、@Image1/@Video2/@Audio1 指代、doc/网页解析。Wan 2.2 仍是开源本地路径。无新变。
- **Digen**（apkpure / 多篇评测）
  - RealMotion 2.6 / Act-Motion（动作迁移锁脸）/ Lip Motion Gen-2（对口型）。维持「单镜 5s 免费快验」，**禁用其 Sora2 入口**（已死）。

**对「第一步：桃子单角色带情节」的直接判断**：
- 本地最高杠杆仍是 **Qwen 出图 → LTX-2.5 I2V**（被官方四层栈背书），DreamX 即便落地也属同类备选，不构成替换理由。
- 云侧「带情节多镜」**Kling 3.0 Omni 是最优快验**（6 shots 原生音画、锁角色、IP 风险低），优于 Seedance 的 30s 单镜（更适合长独白/一镜到底）。
- DreamX-Creator 价值在于「本地原生音画 + Apache2.0」——一旦出 ComfyUI 节点，可与 H3 并列作为本地音画备选，但**现阶段零可落地动作**。
