## 1. 新发现：教程 / 工具 / 工作流

### 1.1 🆕【最高优先·视频身份锁升级】10S-Comfy-nodes —— LTX 2.3 身份保留 + 超分画质正规军（无重训）
- 来源：GitHub `TenStrip/10S-Comfy-nodes` https://github.com/TenStrip/10S-Comfy-nodes ；RunComfy 节点页 https://www.runcomfy.com/comfyui-nodes/10S-Comfy-nodes ；中文解读 https://sota.jiqizhixin.com/project/10s-comfy-nodes ；配套教程「2 Steps to Perfect AI Video」 https://frontiermodels.cc/video/2-steps-to-perfect-ai-video-consistency-and-2k-tiled-upscaling （Veteran AI, 2026-07-10）；HF Dockerfile `snorinGirl/10eros-likeness-i2v` 印证节点族（LikenessGuide / LikenessAnchor / TiledSampler / STGGuider）。
- **核心要点（直接命中我们「LTX 视频保 ID 弱、单 pass 必漂」的痛点）**：
  - **LTX Likeness Guide**（教程主角）：把参考肖像转成「**Persistent Identity Anchor**（潜空间 + conditioning 双层锚定）」，约束贯穿**所有帧**而非只种首帧；关键参数 `silent_reference`（只锁脸身份、不强制构图）、`bbox_only`（限定人脸 bbox 排除背景干扰）、手动人脸区域覆盖。**专门对抗 LTX 生成中后段「脸变宽/油光/种族 homogenize」的坍缩**。
  - **LTX Face Identity Reinforcer**：让 **Alissonerdx 的 `LTX-Best-Face-ID LoRA`** 能在 i2v 下正确工作（原 LoRA 仅 T2V）——内部实现「重叠布局参考 token 注入 + 逐 RoPE 维度相位旋转 + 人脸 bbox 对齐」，单/双参考脸皆可；这是**我们 IC-LoRA-Ingredients 之外的第二套 LTX 身份锁（脸 bbox 锚定）**。
  - **LTX Reference Enable / Conditioning / Bypass**：序列级参考 token 前缀注入（与 latent anchor 不同的干预点，二者可叠加）；`strength` 默认 1.0，首帧畸变降到 0.6–0.8。
  - **LTX Tiled Sampler / Latent Upsampler (Tiled)**：超分阶段**空间分块采样 + 余弦汉明重叠融合**，根治 LTX 超分**色调偏移 / 条件漂移**；**v1.2.0 新增「音频感知分块采样」保口型对齐**；可出 **1920×1024 / 1024×1920 的 2K** 直出（消费级 GPU 达不到的高分辨率）。
  - 另含 Face Attention Anchor / Latent Anchor / Latent Anchor Aware（身份+场景稳定）、Text Attention Amplifier（防提示词稀释）、Latent Motion Retime/Sharpener/Temporal Inpainter 等。
  - **⚠️ 兼容性硬约束**：节点只适配 **LTX2 / LTX-AV 双流音视频 DiT**（依赖 `LTXAVModel`/`BasicAVTransformerBlock`/`SymmetricPatchifier`），**不兼容 Wan 等其他模型**。✅ 我们 LTX 2.3 正是双流 AV DiT，**架构吻合可用**（与 GGUF/FP8 加载路径大概率兼容，上机验证一次即可）；❌ 不能用于 Wan 评估轨道。
- **适用**：**视频身份锁 + 超分画质**双重升级，与我们 07-29/07-31 的 IC-LoRA-Ingredients 正交可叠加（IC-LoRA 参考表 + 10S Likeness 锚 + Best-Face-ID LoRA 三件套并行）。直接服务「第一步桃子带情节单镜脸/衣不漂 + 2K 出片」。**无重训、仅装一个 custom_nodes 仓库**。

### 1.2 🆕 Qwen-Image-Edit Multiple Angle LoRA（fal，96 视角）+ VNCCS 可视化运镜 —— 桃子多角度参考集 + 环绕运镜
- 来源：stable-diffusion-art.com 实战 https://stable-diffusion-art.com/qwen-image-edit-multiple-angle-lora ；fal 训练 96 视角多角 LoRA；配套 `ComfyUI_VNCCS_Utils`（可视化转盘设方位角/仰角）。
- **核心要点**：
  - **fal 的 Qwen-Image-Edit Multiple Angle LoRA** 是首个「同一物体 96 个不同视角」训练的多角 LoRA；叠加 **Lightx2v 4-step Lightning LoRA** 提速 4×。
  - 用 **VNCCS Visual Camera Control** 节点（图形转盘）替代文字设角度，把单张桃子图编辑出「多视角」（前/侧/背/俯/仰…），喂参考图即可。
  - 两个 use case 直击我们需求：① **相机环绕角色**（多角图作 Wan 2.2 First/Last Frame → 环绕运镜视频）；② **一致角色带动作**（Qwen 改 pose → 接视频模型连成片）。
- **适用**：补强「出图线 A 桃子参考集」——比纯 Qwen 多参考 / 360° orbit 更可控地拿到**密集多角度**（96 视角），直接做桃子「角色圣经 / 多角度表」；并解锁「桃子被镜头环绕」这一单角色带情节常见镜头。**注**：原工作流用 2511 bf16，2512 多图机制同源应可直接换。

### 1.3 🆕【最高优先·第一步模板】lovisdotio Sora2Alike 全循环管线 —— 单角色带情节/对话/多镜/口型 完整可抄模板
- 来源：GitHub `lovisdotio/ComfyUI-Workflow-Sora2Alike-Full-loop-video` https://github.com/lovisdotio/ComfyUI-Workflow-Sora2Alike-Full-loop-video （含 ComfyUI-Lovis-Node 自定义节点 + Next Scene / Motion Push-In 等 LoRA）。
- **核心要点（这是迄今最贴近「第一步」目标的现成编排）**：
  - **4-LLM 预处理**：① Scriptwriter 生成 N 句对白 → ② Cinematographer 生成 N 个分镜提示（第 2 镜起前缀 "Next shot..."）→ ③ Animation Director 生成 N 个视频动画提示 → ④ Voice Casting（MiniMax）生成嗓音档案。
  - **执行流水线**：Phase1 用 **Qwen-Image** 出场景1 → 自动 face swap（参考照→生成图）→ 合成对白音频 → 量精确时长 → **Wan 2.2 I2V + Infinite Talk** 按音频时长出说话头；Phase2 **迭代循环**：取上镜末帧 → **Qwen-Image-Edit + Next Scene LoRA + "Next shot..."** 出下一角度（保角色/环境）→ face swap → 音频→动画；Phase3 拼接所有片段+音频成连续视频。
  - **两项关键创新**：**① 末帧续镜（last-frame continuation）**——每镜从上镜末帧起，换角度但仍保角色/场景；**② 动态时长同步**——视频长度自动匹配音频时长（Audio Duration 节点）杜绝口型错位。
- **适用**：**第一步「桃子单角色带情节（含对白/运镜/多镜）视频」几乎可直接套的编排骨架**。我们的适配点：把「face swap」换成**桃子 Qwen 多参考 conditioning**（非人类角色 IP-Adapter 锁不住，已证）；视频段可继续用 **LTX 2.3**（或 Wan 2.2 作快速通道）；保留 4-LLM 脚本 + 末帧续镜 + 音频时长同步这套纪律。**强烈建议作为「我们第一步编排」的研究底稿**。
