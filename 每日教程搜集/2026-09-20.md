## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 Ripple 视频编辑工作流（本地·直接服务第一步）[C145]
- **来源**：AGI Hunt `https://agihunt.info/p/1a0af6954a202ab74fa991fd1c5`
- **核心**：LTX-2.5 Ripple 偏「视频编辑」——把参考视频的动作套到图片角色上（可换角色/服装/背景/风格/灯光），同时**保留原视频运动**；可生成更长视频、一致性更好。对比 MiniMax H3 Viggle-Animate（动作迁移，6GB 约 15 分钟更快，但更偏纯动作迁移）。实测 RTX 3060 6GB + 16GB 内存约 **31 分钟/条**。
- **适用场景**：当我们有一段「真人/参考动作」视频作源时，直接「换脸换装成桃子」保留动作——比纯 I2V 从零生成运动更可控、更稳。对「桃子做特定动作带情节」是**本地零成本**高杠杆手段。

### 1.2 Qwen-Image-Edit「三锚点工作流」(Triple Anchor) [C146]
- **来源**：CSDN `https://blog.csdn.net/weixin_29035405/article/details/164309809`
- **核心**：Identity Anchor（`identity_strength=0.85`，实测 0.8~0.9 最优） + Structure Anchor（face_detail_map，`detail_level=2`） + Scene Anchor（scene_cond，`text_guidance_scale=7.5`）。**关键纪律：三个 Anchor 接入顺序敏感（Identity > Structure > Scene），顺序错会导致换脸/换风格。**
- **适用**：出图线 A 锁角色纪律补强（印证 C129 内置 char_consistency + Identity Lock），给了一个可手调的 `identity_strength` 实操值。

### 1.3 PRINTFILM 一站式自架漫剧 / 短视频流水线 [C147]
- **来源**：今日头条 `https://www.toutiao.com/a7686117830370050575`；仓库 `github.com/yi1108/printfilm`（MIT，~491★，2026-09-10）
- **核心**：主题/口播稿 → 分镜 → 生图/生视频 → 配音 → FFmpeg 合成。国产模型驱动（Kimi/DeepSeek 写脚本、Seedream/Seedance 生图视频、豆包 TTS，回退 edge-tts）；带角色/场景/音色**资产库 + 节点式编排 + 账号/计费/后台**。
- **适用**：漫剧（最终目标）装配层新候选；**但依赖 Seedance（见 3.2 IP 风险），本地部署仍需多家 API Key。**
- ⚠️ 微信公众号/B站/小红书原文反爬未直抓，以上为聚合/转载镜像，标注「**需用户手动发链接**」，未编造。

### 1.4 openOii 多 Agent 漫剧编排开源 [C148]
- **来源**：grabbyte 博客 `https://blog.grabbyte.com/p/2026/09/08.html`；仓库 `github.com/Xeron2000/openOii`
- **核心**：多专职 Agent 协作模拟剧组分工（编剧/美术/分镜/生成调度/合成），对标 OiiOii；可导出 FCPXML/EDL 进专业剪辑精修。
- **适用**：漫剧（最终目标）装配层编排候选，与 Toonflow / LumenX / dramaClaw(C144) / PRINTFILM(C147) 并列。

### 1.5 GitHub AI 视频 50 条流水线排名（2026-09 快照）[印证 C78/C112/C131/C144]
- **来源**：pixo.video `https://pixo.video/blog/open-source-ai-video-pipelines`
- **数据**：MoneyPrinterTurbo 120.4k（上一代素材拼接）、Toonflow 15.1k、huobao-drama 14.8k、ViMax 12.3k（HKU 学术严肃）、NarratoAI 11k、seedance-2.0 7.2k、Jellyfish 6.3k、ArcReel 4.3k、FireRed-OpenStoryline 3.4k、lumenx 1.2k。
- **关键洞察**：pixo 直言「一句话→成片」是 *watchable not publishable*，跨镜一致性/音画同步/节奏正是自动化崩盘处；诚实架构需**每镜人工审核门**。印证我们「本地 LTX 控质量 + 云侧快验」分工，不与全自动画等号。

### 1.6 MAGI-2 Preview 硬件坐实 + 驳斥「单卡 4090 本地部署」误导 [C149 / 复核 C114-C126]
- **官方级核实**：aitoolbox `https://www.aitoolbox.hk/tools/magi-2`（另 BlinkedTwice、QbitAI 公众号镜像）
- **事实**：114B MoE（激活约 6B），Apache 2.0，原生音画同步，10s 上限，1080p（512×896 预览 → 1088×1920 精修）。**硬件硬性要求 8× NVIDIA Hopper（H100 同级），约 307GB 权重；预览版无小卡量化/蒸馏变体。** 推理成本约 ¥0.5/10s 是「大规模部署成本」，非本地门槛。
- **结论**：**坐实 C114/C126 排除**。今日头条等「单张 4090 本地部署」为误导/夸大（把推理成本误读为本地门槛），**不可信，切勿据此追**。若 Sand.ai 后续出托管 API（传闻）再重评。

### 1.7 本地视频模型矩阵再校准（Wan 2.2 / LTX-2.5 / SANA-Video / HunyuanVideo）
- **来源**：bestfreewebresources `https://www.bestfreewebresources.com/?p=22904` + dev.to `https://dev.to/czmilo/2026-complete-guide-top-text-to-video-models-on-huggingface-49p2` + viralmint `https://viralmint.net/blog/run-ai-video-generation-locally`
- **要点**：
  - **ComfyUI v0.36.0（2026-09-15）** 已发，视频节点进 nightly；跑 LTX-2.5 / Wan 2.2 务必保持 ComfyUI 最新（缺节点=版本旧）。
  - **Wan 2.2 TI2V-5B**：Apache 2.0（最宽松、可商用），24GB 消费卡可跑（RTX4090 约 9 分钟/5s 720p），面部渲染强 → 本地「画质优先」备用候选坐实（印证 09-17 C 系列）。
  - **LTX-2.5**：ComfyUI 原生三模板 T2V/I2V/FLF2V；用 int8_convrot 构建（非 BF16）；原生多镜 + 同步音画（印证主线）。
  - **SANA-Video 2.0 5B**（C140）：5B 720p 8s TI2V（bf16）+ 4-step preview T2V-only；硬件推荐 16GB（1080p 建议 4090）；ComfyUI 节点需 preview 分支、上游 PR 未合，待验。
  - HunyuanVideo 1.5：14GB offload 可跑，但 Tencent 社区许可排除 EU/UK/SK；非首选。

## 2. 可行性分析（结合阶段目标与基线）

### 2.1 第一步：桃子单角色带情节视频
- **LTX-2.5 Ripple（C145）** — **值得立刻尝试（零成本·本地·最高优先）**。前提：我们得有一段「真人/参考动作」视频作源（没有则先用 Digen/Kling I2V 出一段运动，再用 Ripple 换桃）。收益：运动可控、一致性高、比纯 I2V 从零生成更稳；风险：31min/条（6GB）偏慢、需源视频、Ripple 社区节点成熟度待验。
- **Qwen 三锚点（C146）** — 零成本，并入出图线 A 纪律（`identity_strength=0.85` 实操值），立刻可用。收益：锁角色更稳；风险：接线顺序敏感，须按 Identity>Structure>Scene。
- **Kling 3.0 Omni（已基线）** — 云快验，6 shots×3-15s + Element 绑定锁角色，Standard 草稿/Pro 终稿；适合桃子带情节分镜快验。成本：消耗额度（需授权）。
- **LTX 官方 I2V / FLF2V + 末帧 chaining（已基线 C98/C107/C128）** — 本地零成本首选，维持。

### 2.2 下一步：多角色
- Kling 3.0 Omni Elements（最多 3 角色）+ LTX 多镜（2-4 cuts 一致性从句）仍是主路线；Seedance 2.5 因 3.2 转折恢复可用（云侧）。

### 2.3 最终：漫剧
- 装配层候选扩至：Toonflow(15.1k) / huobao-drama(14.8k) / ViMax(12.3k) / Jellyfish(6.3k) / ArcReel(4.3k) / dramaClaw(C144) / PRINTFILM(C147) / openOii(C148) / lumenx / LocalMiniDrama。均待用户实跑；Pixo 警告「全自动≠可发布」——必须保留每镜人工审核门。

### 2.4 成本 / 风险 / 收益总览
| 项目 | 成本 | 风险 | 收益 |
|---|---|---|---|
| LTX-2.5 Ripple(C145) | 本地零成本(电) | 慢/需源视频/节点待验 | 高(运动可控) |
| Qwen 三锚点(C146) | 本地零成本 | 接线顺序敏感 | 中(锁角色更稳) |
| Kling 3.0 Omni | 云额度 | 闭源/商用需审 | 高(带情节快验) |

| PRINTFILM/openOii | 自架+API | Seedance依赖/IP | 低(漫剧远期) |
| MAGI-2 | 8×H100(不可及) | 误传4090 | 不适用(A10) |
