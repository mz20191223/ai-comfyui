## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 独立实测与精准部署（最贴合主线，新增可落地细节）
- **aistudynow 实战评测**（相对 08-14「多镜提示词纪律」的第三方印证）：
  - 原生多镜写法：一次生成 宽镜→中镜→特写 三连切，每切后**只重复需保持一致的细节**（如"同一女人、黄色雨衣、雨夜霓虹街"），无需每镜复读全提示词。
  - **Prompt Enhancer（提示增强器）**：简单提示词开、精确时间线/剪辑/对白/运镜提示词时**务必关**（会自动改写你设定的结构）。
  - **Duration Predictor（时长预测头）**：中庸好用但非盲从——对话场景手设 15s 会中途停滞，预测 19s 才够；但首末帧转场预测 18s 反而出物理问题，10s 更干净。
  - 弱点仍是大破坏/复杂物理（龙撞船碎片化不自然，MiniMax H3 同场景物理更好）。
  - 来源：https://aistudynow.com/ltx-2-5-in-comfyui-what-improved-best-workflow-settings-and-my-tests
- **smeltcore 精准部署配方**（RTX 4060 Ti 16GB 跑 22B，验证 08-14「A10 24GB 可跑 GGUF」）：
  - 6 个文件合计 **37.244 GiB**，含易被漏的两个：**①潜空间 2× 上采样器（两阶段模板必需，缺则图跑不起来）**；**②Prompt Enhancer 模型（即使关闭增强器也必需）**。
  - 变压器用社区 GGUF（realrebelai Q3_K_M 10.7GiB / A10 用 Q4_K_M ~15.1GiB），门控首方文件需先接受 LTX-2.5 许可。
  - ComfyUI 核心节点 `comfy_extras/nodes_lt.py`（v0.32.0+，无需 Lightricks 官方节点包）。
  - 来源：https://smeltcore.com/recipes/ltx-2-5-on-rtx-4060-ti-16gb-22b-audio-video-in-16-gb-via-a-community-q3-k-m-gguf

### 1.2 Seedance 2.5 升「第一步验证首选」已坐实（官方 workflow + ComfyUI 节点）
- **官方 ComfyUI Partner Node 公告 + 可下载 R2V/T2V workflow**（确认 08-13/08-15）：单跑 30s 连续、最多 50 参考（30图/10视频/10音频）、时间线级控镜（硬切卡拍）、R2V 内联引用、10+ 语言原生口型、无水印含商用。
  - 来源：https://blog.comfy.org/p/seedance-25-is-now-available-via
- **GitHub `amortegui84/comfyui-seedance`**：含 **Identities 持久化**（每角色一组资产 ID 存 JSON，跨机可复制，下拉复用，零重传）；I2V/R2V 互斥模式；2.5 节点 30/10/10 参考。直接服务「桃子锁角色」第一步。
  - 来源：https://github.com/amortegui84/comfyui-seedance
- elser.ai 维持「4 类漂移（身份/服装/性能/空间）+ 10 步 + R2V 内联引用」SOP——第一步可直接套。

### 1.3 Wan 3.0 官方 API 文档坐实（升为「可落云验证」，非待验）
- **阿里云官方 API 参考**：模型 `wan3.0-video`，**公测 preview**，30s 单出，480P/720P/1080P，API 价 **0.3 / 0.6 / 1.2 元/秒**；支持 T2V / 首帧 / 首末帧 / **Omni-Reference（PDF·PPT·DOC·网页链接→视频，全行业独一份）** + R2V；异步调用，视频 URL 24h 有效。
  - 来源：https://help.aliyun.com/en/model-studio/wan3-video-generation-api-reference
- 多源实测（光子星球/itbear）：30s 东方奇幻叙事连贯、文字渲染准、文档转视频方向对；**短板：音频质感与文字准确度官方自认待提升**（音频是否原生同步各源说法冲突，待用户实证）。
