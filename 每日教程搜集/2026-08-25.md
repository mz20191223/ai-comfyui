### 🔴 A. Wan 3.0「正式上线」（2026-08-24，最大增量）
- 来源：[太平洋科技/今日头条 2026-08-24](https://www.toutiao.com/article/7677482381191774754/) / [FrontierNews](https://www.frontiernews.ai/news/article/alibabas-wan-30-lets-you-turn-a-powerpoint-into-vi-d5a26594)
- 核心要点：单段最长 **30s 一镜到底**；新增 **doc/xls/ppt/pdf/txt/key/pages/numbers/md 输入**（≤1 文件或链接，≤100MB，≤50 页）；人像模块「千人千面」——精细还原五官/皮肤纹理，微表情+肢体动作+情绪互匹配；多人同框区分独立神态；参考图复用角色/道具/空间/风格全程统一；智能时长推荐 + 视频续写。
- 接入面扩大：阿里云百炼、万相官网、万镜一刻、千问创作 PC 端/App、堆友、IFSTUDIO，以及麦芽（跳跃视界/Deevid/剧火）、京东灵境、美图、井萌。
- 适用场景：把「剧本/PPT/分镜文档」直接转成带连续运镜的视频，**极适合第一步的「带情节」快速验证**（给文档/分镜即可出 30s 叙事）。
- ⚠️ 关键限制（多源印证）：**权重仍闭源、本地不可跑**。atlascloud / versely / wan2-7.io 三源独立核实——HuggingFace（Wan-AI 27 仓）+ GitHub（Wan-Video 6 仓）最高版本号仅 2.2，**无任何 3.0 权重/模型卡/许可证/ComfyUI 节点**；2.5/2.6/2.7/3.0 连续四代旗舰闭源。阿里自己承认**音频质量与屏内文字**是弱项。定价 $0.05/s@480p、$0.10/s@720p、$0.20/s@1080p（≈$12/分钟 @1080p，低于 Veo 3.1 的 $0.40/s）。

### 🟢 B. LTX-2.5 工作流与多镜提示词纪律全面坐实
- 来源：[RunComfy I2V+同步音频工作流](https://runcomfy.com/comfyui-workflows/ltx-2-5-comfyui-image-to-video-synced-audio) / [fal 多镜提示词指南](https://fal.ai/learn/tools/how-to-use-ltx-2-5) / [soloa 提示词指南](https://soloa.ai/blog/ltx-2-5-prompt-guide-2026) / [ModelScope 官方权重+文件清单](https://modelscope.csdn.net/6a7e76ba10ee7a33f29ac6c5.html) / [ltx.io 官方指南](https://staging.ltx.io/blog/comfyui-workflow-guide)
- 精确文件清单（A10 24GB 用 Q4_K_M 常驻 ~17.7GiB，两易漏文件必装：`latent-spatial-upscaler-x2` + `gemma4_e2b_it` Prompt Enhancer）：transformer（dev / distilled 8步 CFG=1 / comfy-int8-convrot / nvfp4）、`gemma4-12b-with-proj-ltx-2.5`（文本编码器）、`ltx-2.5-video-vae-bf16`、`ltx-2.5-audio-vae-bf16`、`ltx-2.5-duration-head-bf16`。
- **多镜散文提示词纪律**（fal/soloa 多源印证）：一次生成写**时间顺序散文**（非镜头列表）；每次转场四要素——①点名切法（hard cut / dissolve）②从零重建景别/机位/光（cut 后一切重置）③用初次相同词重认角色（"the woman in the bronze gown" 而非代词）④显式写声音跨镜；**每代 2–4 镜、fal 停在 3 镜**。
- 参数：蒸馏 8 步 CFG=1；完整 25–35 步 CFG 3.0–4.2（>5 易过饱和）；i2v denoise 0.45–0.65；负向："blurry, distorted anatomy, warped faces, flickering background, unnatural jitter…"。
- **实测坑**（wailaike 外来客）：物理穿透/软硬物体碰撞仍翻车、镜头移开再回归脸部漂移、"25岁女性"易偏老→**用 "girl" 替代 "woman"**（年轻亚洲脸 hack，与历史结论一致）。
- 文本编码器 Gemma 4 12B **偏英文**→ 中文复杂动作/运镜失真，写英文或走 Prompt Enhancer（与 08-22 结论一致）。ComfyUI v0.32.0+ 原生节点（#15499），无需 vendor 包。
- 适用场景：**第一步桃子单角色带情节=本地主线路线图已完整**，A10 可跑。

### 🟢 C. FLUX 3 Video 进入视野（BFL，新晋云验证候选）
- 来源：[BFL 官方](https://bfl.ai/blog/flux-3-video) / [AI Insiders](https://aiinsiders.net/article/black-forest-labs-opens-flux-3-video-cites-lead-over-rivals) / [Runware](https://runware.ai/blog/flux-3-video-beyond-text-to-image)
- 核心：20s@720p HD、上采样 Full HD；**原生同pass音画**；**单 clip 内多镜**（SHOT 1: / HARD CUT. 标签）；**14+ 语言口型同步对白**（含中文）；T2V/I2V/关键帧/视频续写（4s 续镜）/屏内文字/世界知识。BFL 自评 Elo T2V 1135、I2V 1051（自测，带星号）；定价 draft $0.06/s、full $0.17/s、FHD $0.29/s（v2v 更高 $0.12–0.53/s）。经 BFL API / Runware / 部分伙伴，暂无独立 App。
- 适用场景：强音画+口型+多镜的**云质量补镜 / 第一步替代验证**，闭源 API-only、本地不可跑。

### 🟢 E. Qwen-Image-Edit-2512 官方站坐实「出图线 A」方案
- 来源：[qw-image.com 官方](https://qw-image.com/en-IN) / [CSDN Edit 节点 5 开关](https://blog.csdn.net/weixin_42372837/article/details/157633008) / [frontiermodels Grid Method](https://frontiermodels.cc?p=6011/)
- 要点：官方确认 low-drift 编辑、**多图融合**（参考图组）、**2512 新增 Object Anchor Detection（对象锁定开关，开箱即用防误伤）**、Consistency Enforcer 节点、**Character_Seed_Lock 工作流**；[08-22 已确认的] **Qwen-Character-2512 LoRA** 可下载（character_strength 0.6–0.9、FaceNet 87% 相似、导出 character_embedding.pt）→ **桃子角色圣经零训练方案坐实**。Grid Method（Qwen2512 单采样出 4 宫格分镜 + Unblur Anything LoRA 超分 + LTX 出片）继续有效。
- 适用场景：出图线 A 锁桃子脸/服装/多角度参考集，服务第一步+下一步多角色。

### 🟡 F. 漫剧工作流系统化（预研 Step 3）
- 来源：[51CTO ComfyUI 漫剧](https://blog.51cto.com/u_16099209/14823172) / [阿里云开发者](http://developer.aliyun.com:443/article/1747611) / [yxlz 角色锁定](https://yxlz.com/forum.php?goto=lastpost&mod=redirect&tid=5835)
- 要点：标准四段——①Qwen 分镜结构化（JSON，9:16 竖屏）②**角色锁定三驾马车：IP-Adapter-FaceID（骨相克隆）+ SDXL/专属 LoRA（皮相）+ ControlNet Canny/Depth（骨架）+ Adetailer（脸细节）**③批量分镜图（ImpactPack/Wildcard）④静态转动态（LTX Video 首选，单图 5–10s 竖屏）。
- 适用场景：最终漫剧本地可控路径的预告，与现有「IP-Adapter+FaceID+LTX-2.5 多镜」路线一致，非推翻。

## 3. 及时调整建议

- **不替换现有基线**。LTX-2.5（视频主线）+ Qwen-Image-Edit-2512（出图线 A）+ Seedance 2.5（云快验）+ Digen（单镜）仍是我们的 stack。
- **🆕 建议把 FLUX 3 Video 加入「云质量补镜」候选池**（与 H3/Wan 3.0 同类），理由是它原生音画+14 语言口型+单 clip 多镜，对白镜质量可能优于 Seedance；但因闭源、无本地，仅作精修备选，不替换 Seedance 的「第一步快验首选」地位。
- **🆕 Wan 3.0 由「公测候选」升为「正式上线的云选项」**，接入面更广（多平台），但**本地仍不可跑**，故不改变「仅云验证」定位；建议第一步可用「分镜文档→Wan 3.0」粗验情节，但最终成片仍走 LTX-2.5 本地。
- **🆕 提示词层面立即采用 fal 多镜散文纪律 + "girl" hack + 英文/Prompt Enhancer**——这是今天坐实的最低成本、最高确定性增益，直接提升第一步成片率，无需换工具。
- 无需放弃任何现有步骤。
