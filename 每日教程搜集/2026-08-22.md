## 1. 新发现

### 1.1 LTX-2.5：多镜提示词纪律坐实 + 三层结构可直接套模板
- **官方/社区统一的多镜写法（fal.ai / theneuron.ai / runpod / wmrh.cn 多源交叉印证）**：一次生成写「一段按时间顺序的散文」，不用分镜列表、不用 SHOT ONE/硬切标记；每个转场用四要素描述——① 用文字点名切法（hard cut / dissolve）；② 重建景别/角度/光线（切点是重置的，模型无从推断）；③ 重复角色识别词（"the woman in the bronze gown" 跨镜带人，代词不行）；④ 显式说声音是否跨镜延续。Lightricks 建议 **每次 2–4 镜，fal 实测停在 3 镜**（第 4 镜会分薄前 3 镜的算力）。
- **三层提示词结构（wmrh.cn 实测 + docs.ltx.io）**：① 场景叙事（自然语言整段弧线）；② 视觉锁（光线/风格/色彩全片统一）；③ 声音（可关 generate_audio）。关键参数：`duration: null`（交给 Duration Head 自动判时长）、`camera_motion`（可选）、`generate_audio: false`（静音出片）。
- **⚠️ 重要实操修正**：LTX-2.5 文本编码器是 **Gemma 4 12B，官方明确以英文优化**，中文语义（尤其复杂动作/运镜）理解不够精确 → **写英文提示词，或用内置 Prompt Enhancer 把中文短句扩成英文电影级指令**。这对我们中文项目是直接可落地的纪律。
- **负面词/蒸馏模型边界**：蒸馏模型默认 CFG1 时负面词作用有限；人物特写等需严控场景可适度配负面词（模糊/畸变/多余手指/水纹）。
- **图生视频（I2V）提示词聚焦运动**：画面已由输入图决定，提示词只写运动与变化（雨滴滑落、人物转头），别再描场景细节。
- **可下工作流**：官方 T2V / I2V / FLF2V 三个 JSON 模板（Comfy-Org/workflow_templates + ComfyUI 模板浏览器一键下模型）；变体 INT8 / BF16 / NVFP4 / GGUF（realrebelai Q3_K_M 10.7GiB、Abiray/VantageAI Q4_K_M 15.1GiB），A10 24GB 用 Q4_K_M 常驻 ~17.7GiB 宽裕。
- 中文聚合教程参考：wmrh.cn《LTX-2.5 提示词 9 技巧》（技巧3-9 即上述镜头语言/光线/多镜锁角色/负面词/时长头/I2V 聚焦运动/控幅防失控）。

### 1.2 Qwen-Image-Edit-2512：角色圣经零训练方案坐实（出图线 A 具体化）
- **CSDN 实跑项目（agent.csdn.net《打造专属插画集》）确认可用工作流 `Character_Seed_Lock.json`**：上传设定稿（≥1024×1024）→ 勾选 **Enable Character Embedding** + Embedding Strength 0.85 → 输出风格化重绘 + `character_embedding.pt` 特征向量文件（自动存 embeddings/）。即「一张图定义整个系列」的零训练锁角色路径。
- **Qwen-Character-2512 LoRA 确认可下载**（修正 08-07「未见干净独立版本」措辞）：单参考锁角色，`character_strength` 0.6–0.9（0.9 高度一致但略僵），连续 10 张 FaceNet 相似度 87% → 出图线 A 桃子角色圣经可直接用，无需训练。
- **compshare 镜像「角色一致性增强」四功能**：单角色一致性 / 多人合照一致性 / 内置 LoRA（光照增强、视角变换）/ 工业设计。参数纪律：步数 40、True CFG 4.0、Guidance 1.0，固定种子可复现。印证 08-19「出图线 A 加 Lightning 4-step 提速」可叠加。
- 提示词纪律（seedance-pro.org 汇总）：动作+目标+约束（保留身份/结构/细节）；复杂编辑分步做、每步重申约束；多图融合用 2+ 参考图保每人身份。

### 1.3 🆕 Wan-Animate-2 开源（Apache 2.0，2026-08-07）—— Step 2/Step 3 运动迁移候选
- 阿里通义万象开源，14B 双分支 DiT，**参考图 + 驱动视频 → 动画视频**（端到端，不做骨架/姿态提取，避免身份漂移与手部/微表情丢失）。arXiv 2608.06009。
- 输出：Base 720p@24fps；**Lite 变体 400×720 实时 24fps**（数字人直播/虚拟主播）。显存 Base ~28GB / 量化 ~16GB（A10 24GB 可跑量化版）。
- **ComfyUI 原生节点 `WanAnimate2ToVideo` + `WanAnimate2Cache`（省约一半时间）**；DiffSynth-Studio 低显存逐层执行。支持单→多 / 多→多角色驱动、文本驱动视角控制（Viewpoint LoRA，机位与驱动视频解耦）。
- **对项目的意义**：这是「下一步多角色」「最终漫剧」的**运动迁移**直接候选——桃子出图（Qwen）后，喂一段同体型驱动视频即可让桃子做指定动作/表演。第一步（单角色带情节）也可用：ref image=桃子 + driving video=通用动作 → 桃子表演。但需先有一份驱动视频素材，属加分项，不进第一步必做。

### 1.4 Seedance 2.5 R2V：anchor 管线坐实（第一步云快验首选再强化）
- **一致性靠参考图纪律、非开关**（siray.ai 明确：无内置 character lock）。可靠管线 = **Z-Image（文生图）出锚点图集（正面/四分之三/侧面 3–4 角，中性光照背景）→ Seedance 2.5 `ref2v` 端点（最多 30 图 + 10 视频 + 10 音频）带入运动**。多角参考显著降跨镜漂移。
- 分辨率/价格：480p $0.134/s（便宜档）vs 720p $0.290/s（无 4K）；30s 单出、多语口型、原生音频。Runware 指南补充 `referenceVideos`（运动/机位/口型时序）+ `referenceImages`（身份）双输入融合（角色换演/运动迁移）。
- elser.ai 四维漂移诊断（身份/服装/性能/空间）可直接当 QA 清单套桃子。

### 1.5 🆕 Seko 3.0（商汤，2026-08 升级）—— Step 3 漫剧「云全包」路径候选
- 定位「创编一体 AI 剧组」：剧本→分镜→角色/场景/道具→视频→配音→剪辑一站式；**SekoIDX 跨镜头/跨集一致性引擎**，支持 100 集连续生成、自动复用前序资产；SekoTalk 多人对口型（10 语言）；漫剧 Skill。
- 底层模型矩阵含自研 Seedance 2.0 + Vidu Q3 + 可灵 3.0 Omni。定价「基础免费 + 积分」，1080P 约 8 积分/秒（≈ 几十元/分钟）。
- **对项目的意义**：Step 3 漫剧若走「闭源快速验证」路线，Seko 3.0 比单模型拼接更省事；但非本地可控、IP 出境/合规/成本需评估，仅作对照候选，不替换本地主线。

### 1.6 通用一致性纪律（igly.ai / domer.io / elser / siray 多源印证）—— 与 v4 基线对齐
- **参考栈（reference stack）法则**：1–4 张干净图（正面/侧面/表情/全身），**给参考命名角色而非匿名文件**，跨镜复用同一套；提示词只写场景/动作/运镜，身份交给参考图。这条与现有 v4「Lock-Then-Animate / 参考图集 / 提示词锚定」完全吻合，非推翻。
- 先锁角色设计再生成任何帧；同参考跨 3–4 场景批量测一致性；短镜（4–6s）一致性风险低；剪辑调色掩小漂移。

## 2. 可行性分析（对照阶段目标 + 技术基线）

### 第一步：桃子单角色带情节视频 —— 今天「可立即跑」的路径清晰
| 路径 | 落地方式 | 可行性 | 成本/风险 |
|---|---|---|---|
| **LTX-2.5 本地**（主线升级） | A10 24GB + GGUF Q4_K_M + 3 层英文提示词 + 3 镜模板 | 🟢 高（配方/工作流/提示词均坐实） | 中：需本地部署权重（~37GiB 含易漏潜空间上采样器+Prompt Enhancer）；英文提示词纪律 |
| **Qwen-Image-Edit-2512 出图**（线 A） | Character_Seed_Lock + Qwen-Character-2512 LoRA 建桃子角色圣经 | 🟢 高（工作流+LoRA 均确认可用） | 低：零/低训练，单卡可跑 |
| **Seedance 2.5 R2V 云快验**（并列） | Z-Image 锚点 → ref2v 多角参考 | 🟢 高（端点/价格/纪律明确） | 低 GPU；按秒付费（480p ~¥1/s）；第三方 API/IP 出境风险 |
| **Digen**（单镜补充） | 单镜头快速验证 | 🟢 维持 | 低 |

**结论**：第一步的三条腿（线 A 出图 + LTX 本地多镜 + Seedance 云快验）今天都已从「可操作」升为「有具体模板可照抄」。**最高优先仍是把 LTX-2.5 GGUF 在 A10 上跑通 + 用 3 镜英文模板出桃子第一个带情节片段**。
