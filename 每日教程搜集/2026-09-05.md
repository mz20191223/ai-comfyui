## 1. 新发现（教程 / 工具 / 工作流）

### C86 · Kling 3.0 Motion Transfer（动作迁移/运动控制）工作流
- 来源：DEV Community `dev.to/devxo/a-developers-practical-guide-to-ai-motion-control-how-kling-motion-transfer-works-2mb5`（2026-09）
- 核心：用一段**参考视频驱动动作**（提取身体轨迹、关节、手势时序），施加到你的角色图上，而不是让模型自由想象运动。模型只"跟随"参考运动，输出**可预测、可复现**。
- 两种模型：Motion Control 2.6 / 3.0（3.0 旗舰，角色一致性与复杂肢体动作更好）。
- 四步工作流：① 上传参考图（身份锚点，正脸/清晰/光照好）→ ② 上传运动参考视频（清晰无遮挡、相机角度匹配、<10s、动作类型匹配）→ ③ 文本提示**只做"运动后 styling"**（背景/机位/光影/氛围，不控制运动）→ ④ 选模型生成。
- 失败模式：角度不匹配（参考侧脸贴正脸图）、比例不匹配（全身参考贴半身图）、过度依赖 prompt 控制运动（改运动要换参考视频）、低质量参考图。
- 适用：桃子单角色做"特定动作"（跳舞/挥手/走位）时，运动一致性比纯文生视频强很多。云（Kling），成本待实跑。

### C87 · ViMax：Agentic 视频生成框架（多智能体端到端）
- 来源：GitHub `hkuds/vimax`（协议未注明，需确认）；v1.2.0 已含 Web UI
- 核心：Director/Screenwriter/Producer/Video Generator 一体化。四种入口：Idea2Video / Script2Video / Novel2Video / **AutoCameo**（把参考照片的人放进故事并保持一致外观）。
- Web UI：命名项目、Agent Loop 对话、storyboard 预览、渲染检查点、文件上传、provider 设置、暗色模式。支持 Seedance 2.0、Google Omni、MiniMax chat 等 provider。
- 适用：最终漫剧（多镜头多角色编排）的 Agent 编排层候选；AutoCameo「一致外观」思路对桃子角色锚定也有借鉴。对第一步偏重。

### C88 · InfiniteTalk：无限时长虚拟人视频（美团开源）
- 来源：CSDN 美团技术团队 `blog.csdn.net/MeituanTech/article/details/151977274`（2026-09-04 发布）；GitHub 开源 ~1.6K stars，HuggingFace 月下载 64.8K
- 核心：**语音驱动图像 / 语音驱动视频**，口型精准、动作流畅；流式生成架构支持无限时长、身份锚定 + 全身自由表达、口型到全身动作同步。解决传统 video dubbing「口型僵局」与长视频累积误差/过渡生硬。
- 适用：桃子「对白/口播驱动」的情节视频（先写配音 → 音频驱动角色说话）。开源，与 C79 Wan 2.2-S2V 同属「音频驱动」路线，互为补充。工程化成熟度待实跑。
- ⚠️ 确切 GitHub 仓库名搜索未给出，需用户手动确认（CSDN 源链接如上）。

### C89 · 魔因漫创 Moyin Creator：开源短剧工具
- 来源：`i.yeyulingfeng.com/a/459864.html`（第三方长文）；文称 GitHub `MemeCalculate/moyin-creator`（待用户确认）
- 核心：五大板块 剧本→角色→场景→导演→S级（Seedance 2.0）。**6 层身份锚点**（角色圣经）跨镜一致；`@Image/@Video/@Audio` 多模态引用；智能提示词三层融合（动作+镜头语言+对白唇形同步）；首帧图网格拼接。
- 适用：漫剧编排层候选（与 Toonflow C78 同类）；桃子第一步可取其「角色圣经 + Seedance 多模态引用」思路。
- ⚠️ 仓库真实性需用户手动确认（第三方长文，未独立核验）。

### C90 · LumenX：阿里通义 AI 原生短漫剧平台（已确认仓库）
- 来源：GitHub `alibaba/lumenx`（MIT，已确认)
- 核心：Studio 全链路 = 剧本分析→角色定制（三视图）→场景定调图→分镜视频（I2V/R2V + 批量抽卡）→智能配音（CosyVoice / Qwen3-TTS）→FFmpeg 合成导出。Playground 独立生成台：6 模式、10+ 模型（Wan 2.7 / Seedance 2.0 / Kling V3 / Vidu Q3 / HappyHorse / GPT-Image-2 等）。本地优先，最简只需一个 DashScope API Key。
- 适用：漫剧（最终目标）**强候选**——阿里系 + DashScope 我们已在用（Qwen/Wan/Seedance），集成成本低。
- ⚠️ 列「Wan 2.7」：本地开源权重仍按基线判定为 SEO 伪造（已排除），此处应为 DashScope 云端 API 模型别名，非本地权重；不纳入本地主线决策。

### C91 · ArcReel 弧光影坊：AI Agent 驱动自托管视频工作台
- 来源：GitHub `ArcReel/ArcReel`（Docker 一键部署)
- 核心：小说/剧本输入 → 自动提取角色/场景/道具，跨镜头复用资产图保一致；最大特色：**可导出剪映草稿继续编辑** + 内置费用追踪。
- 适用：漫剧编排层候选；「导出剪映草稿」对我们后续精剪很友好。

### C92 · LTX-2.5 → 4K 放大工作流（强化本地主线）
- 来源：`ai-videoupscale.com` 社区教程（2026-09)
- 核心：LTX-2.5 先出 720p/1080p 基础视频 → LatentUpscale（`4x-UltraSharp` 两段到 2048×1152，或 `4x-Neo` 单次 4× 到 3840×2160）+ VAEEncode + 无损 FFmpeg 导出。VRAM 8–12GB。启用 **Temporal Consistency** 减闪烁；必须用 **LTX-VAE** 而非 SD VAE。
- 适用：**直接提升 A10 24GB 本地主线（LTX-2.5）成片分辨率到 4K**，不换模型、不增主线复杂度。强推荐本地落地。

### C93 · Seedance 2.5 实务 SOP 再细化（四层提示词 + 白模预演）
- 来源：今日头条/小云雀 `toutiao.com/a7680774459817230900`、`a7680772960130482722`（2026-09，转载长文)
- 核心：① 四层提示词结构 = 继承内容 / 逐张参考职责（角色图锁外形、场景图锁空间、白模动态参考锁机位路径）/ 按时间段写动作+镜头+声音（0–4s/4–8s/8–12s）/ 必保与禁改元素。② Seedance 2.5 新增**白模/绿幕参考**：3D 预演转实拍，锁空间关系/主体轨迹/相机路径。③ 单段 4–30s、单次最多 30 图+10 视频+10 音频（≤50 素材），片段重拍只重做一段。
- 适用：细化 C56/C66/C83 的 Seedance 第一步云快验 SOP，尤其多镜头/多角色预演。
- ⚠️ 中文长文为今日头条转载，微信公众号/小红书/B站原文反爬未直接抓，如需原文链接需用户手动发。

### 强化（非新，但给出具体可操作纪律）
- **Kling 3.0 提示词纪律**（promptsrush / tenorshare）：六槽结构（景别主体 / 动作 / 机位镜头 / 光向 / 氛围 / 调色+时长）；**动词而非形容词**驱动运动；锁首帧；element reference 锁角色；每次只改一个变量；多镜每段给独立时长求和。强化 C77/C83。

## 2. 可行性分析（对照阶段目标 + 当前基线）

当前阶段 = **第一步：桃子单角色带情节视频**。逐项评估：

| 编号 | 方式 | 服务第一步？ | 落地成本 | 风险 | 收益 |
|---|---|---|---|---|---|
| C92 | LTX-2.5 4K 放大（后处理） | ✅ 直接提升本地主线成片 | 低（加 ComfyUI 节点 + 放大模型） | 极低（不改模型） | 高（4K 成片、A10 24GB 够） |
| C93 | Seedance 2.5 四层提示词+白模预演 | ✅ 细化云快验 SOP | 低（提示词模板） | 低 | 中高（多镜一致性提升） |
| C86 | Kling 3.0 Motion Transfer | ✅ 桃子特定动作一致性 | 中（需参考运动视频 + 云额度） | 中（参考视频质量门槛） | 高（动作可控可复现） |
| C88 | InfiniteTalk 音频驱动对白 | ⚠️ 仅对白类情节 | 中（本地部署或云） | 中（风格偏数字人，需验证贴合度） | 中（解决口型/对白） |
| C79 | Wan 2.2-S2V 音频驱动 | ⚠️ 对白类情节 | 中（本地 A10 量化） | 中 | 中（本地可控） |
| C87/C89/C90/C91 | Agent 编排层 | ❌ 主要服务漫剧 | 高（整套平台） | 中（维护/配置） | 未来高（漫剧） |

**结论**：今天研究以「强化现有基线 + 补细节」为主，无推翻性发现。
- 对第一步最值得立刻做的是 **C92（4K 放大）+ C93（Seedance SOP）**，零到低成本、直接增效。
- **C86（Kling 3.0 Motion Transfer）** 是云快验新武器，特别适合桃子"做某个动作"的镜头。
- 音频驱动支线（C88/C79）仅当情节含"说话/口播"时才需启用，不作为第一步默认路径。
