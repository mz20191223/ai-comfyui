## 1. 新发现：教程 / 工具 / 工作流

### 1.1 本地主线 LTX（直接服务第一步·零/低成本）

- **C183　LTX-2.5 I2V + Lip Sync 现成 ComfyUI 工作流**（Civitai 模型 2913183，9-04 发布、8天前核验）
  - 来源：<https://civitai.com/models/2913183>
  - 核心：在官方 LTX-2.5 I2V 模板基础上，用 `LTXVAudioVAEEncode` 编码一段驱动音频 + `SetLatentNoiseMask`（SolidMask=0 全保留）把音频锁成固定条件，同时喂入 base 与 refine/upscale 两遍采样，让嘴型跟音频走。**纯 Comfy 原生节点（comfy-core），无需任何自定义节点包**。
  - 适用：桃子「带情节 + 对白」本地出片——无需再拆 TTS + 独立口型工具，一条 LTX I2V 直接出带口型视频。
  - 关键坑：refine 遍必须从原始编码音频取 latent，不能从 base 输出取（早期版本漂移 bug 根源）。

- **C184　LTX-2.5 22B I2V 在 8GB 笔记本实跑配置**（agihunt / Reddit 用户，RTX 4060 Laptop 8GB VRAM + 16GB RAM）
  - 来源：<https://agihunt.info/p/1a06f41218f1f18792b3fed6> （镜像，原帖 Reddit）
  - 核心：22B 不全载显存，ComfyUI 用 VRAM 搬活跃块 + 异步权重卸载；W4A8 ConvRot 量化 + Gemma 12B 文本编码器 + tiled VAE + async offload。稳定 576×1024 / 24fps / 10s，身份与背景几何不崩。
  - 坑：`--fp16-vae` 出黑视频，改 `--bf16-vae` 修复。工作流在 `reventadirecta/LTX-2.5-I2V-8GB-V` 仓库。
  - 适用：印证我们 A10 24GB 跑 LTX-2.5 绰绰有余（8GB 笔记本都能跑），强化 C80/C102 的「8GB 可跑」结论，给我们性价比兜底。

### 1.2 云快验（Seedance / Kling / fal H3）

- **Seedance 2.5 实战深测（多源印证）**：30s 原生时长、50 多模态参考（30 图+10 视频+10 音频）、局部修改（框选区间只重生坏段）、3D 白模预览、原生 4K、油腻感改善。
  - 两个新踩坑（进云侧 SOP）：① `duration` 缺省 = -1 时模型自定 10s，**费用翻倍** → 每次显式写时长（25–28s 留余量）；② 首尾帧模式下宽高比必须设 `adaptive`，填具体值（16:9/9:16）直接 400 报错。
  - 「全能参考」模式 + `@图片1 @图片2` 语法（多角色同框不撞脸）；白模/绿幕参考做工业化运镜。
  - 来源：<https://cxgn.cn/seedance-25-8> / 即梦深测长文（微信公众号镜像，**需用户手动发链接**）/ <http://www.hqwc.cn/news/913103.html>

- **Kling 3.0 多镜头 + 免费档坐实**（iishki / genmedialab / 18183 / datacamp）
  - 免费账号 **66 credits/月**，够 1 条 5s 1080p 带原生音频；5s 1080p 带音频 60 credits、无音频 40；Turbo 更便宜。
  - Multi-Shot 最多 5–6 镜 / 15s；Custom Multi-Shot 按钮可逐镜写提示词+设时长；首帧必填、尾帧可选；原生音频支持中/英/日/韩/西，引号内写对白即配音。
  - 提示词结构：主体动作（动词）+ 一个相机运动 + 光与情绪 + 声音（若开）。「描述运动不描述画面」与 LTX 纪律一致。
  - 来源：<https://iishki.com/en/blog/kling-3-0-guide> / <https://www.genmedialab.com/tutorials/how-to-use-kling-ai> / <https://www.18183.com/gonglue/202609/rlvcpqhp.html>

### 1.5 出图线 A（零成本·强化既有）

- Qwen-Image-Edit 多源实操强化（CSDN / thundercompute / mhpn）：
  - **多图输入**：2509 及以后版本接受**最多 3 张输入图**，输出比例跟随第一张；提示词显式指代每张角色（「图1 的人穿图2 的衣服」）。
  - **Inpainting（局部重绘）**是保脸首选——只重生遮罩区、保留姿势/原像素，避免全帧重绘的脸漂移；代价是姿势被固定（移动头部不自然）。
  - ControlNet Union LoRA（`qwen_image_union_diffsynth_lora.safetensors`，深度/边缘/关键点合一）、Lightning LoRA 4/8 步可在 8GB 跑（CFG=1、steps=4）。
  - 三锚点 `identity_strength=0.85 / detail_level=2 / text_guidance_scale=7.5`、顺序 Identity>Structure>Scene 已坐实（C146）。
  - 来源：<https://blog.csdn.net/weixin_29035405/article/details/164309809> / <https://www.thundercompute.com/blog/qwen-image-edit-comfyui>
