## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5（视频主线）
- **官方 int8-convrot ComfyUI 量化变体坐实**：`ltx-2.5-22b-distilled-transformer-comfy-int8-convrot`（Comfy-Org 出品，docs.comfy.org / comfyui-wiki 明确清单）。此前我们记的是社区 GGUF Q4_K_M（realrebelai/Abiray/VantageAI ~15.1GiB）；现在多了**官方单行量化下载路径**，A10 24GB 部署更干净。
- **HF 仓库已门控**：`Lightricks/LTX-2.5` 变为 gated，须先接受许可 + 申请访问通过才能下载，否则模型拉取失败。→ 部署前多一步账号操作。
- **能力再确认**：原生多镜（一次出连续远中近镜、跨镜锁角色/环境/光线/嗓音）、Auto Duration（提示词读动作预测时长）、Prompt Enhancer（Gemma 4 12B 偏英文）、原生 4K HDR。
- **横评坐标（厂商自报、未第三方复现）**：速度 LTX-2.5 第一（10s 720p 在 GB200 上 6.8s；API 10s 1080p 23.7s）；质量盲测胜率 LTX 67% > Seedance 65% > Gemini Omni Flash 55% > H3 50%。作「本地可控优先」的判断依据。

### 1.2 MiniMax H3（本地对比 / 质量补镜轨道）
- **加速生态再扩充**（关联 C57）：
  - **H3 Max**（fal 后训练版）：Artificial Analysis 榜 I2V #1 / T2V #3，5s 片段 <3s 出片，$0.04/s @768p（促销至 9-1 已过期），**权重计划发布**。速度-质量 Pareto 前沿。
  - **FastH3**（FastVideo 团队 / Hao AI Lab + Nuva + NVIDIA FastGen）：将 49 步压到 4 步（稀疏蒸馏 VSA），**开源权重 + 预提取 LoRA**，4-step VSA / Data-Free checkpoint。本地 H3 提速的第三条路。
- **本地实跑复证**：RTX 4080 16GB + pruned+int8，10s 视频约 10 分钟出片；API 经七牛云 MaaS（`minimax/minimax-h3`，768p ¥0.5/s、2K ¥0.8/s）。官方许可排除美/欧/英/韩，中国自托管 OK。

### 1.3 Wan 3.0（闭源云并列，仅验证）
- **GA 于 2026-08-24**，当前有**限时 30% 折扣至 2026-09-23**（百炼/千问）。标准价 480p ¥0.3/s、720p ¥0.6/s、1080p ¥1.2/s；折扣后约 ¥0.21/0.42/0.84 每 秒。
- 能力：30s 一镜到底 + **doc/xls/ppt/pdf/md/网页直读**生成视频 + 约 20 参考 + 原生音画 + 多语配音；弱项音频/屏内文字（阿里自承）。
- **对桃子第一步的意义**：「写一页分镜/剧本 markdown → 直接出 30s 带情节成片」是 all-in-one 最低门槛云路径；折扣窗口关闭前试水成本最低。

### 1.4 Seedance 2.5（第一步云快验首选）
- **API 分辨率纪律修正（重要）**：ModelArk / 第三方 API（Atlas Cloud、VideoGenAPI、seedanceapi.com）**实测仅 480p/720p**，并非 Dreamina 网页宣称的 1080p/4K。模型 ID `dreamina-seedance-2-5-260628`。按 token 计费（$10.70/1M 无视频输入、$6.40/1M 有视频输入），非简单按秒；5s@720p 示例约 $1.156。
- 能力维持：30s 一镜 + 50 参考（30图+10视频+10音频）+ 时间戳编辑 + 3D 白模预演（锁机位）+ 局部编辑不破全片。API 在美区不可用（走即梦/豆包国内入口）。

### 1.5 中文「桃子第一步」可抓 SOP 收敛（最具体落地路径）
- 多源中文教程（今日头条 / CSDN / 效率AI实战派）对齐出一条**可复制流水线**：
  1. 角色资产锁定：即梦「AI 分身」（正脸+美颜+读「123 456 789」）→ 出标准三视图 → 角色 ID 持久化。
  2. 图生视频：可灵 / 即梦 / Seedance，单镜 **3–5s、微动作、推拉运镜**，复杂动作拆镜。
  3. 配音+字幕：剪映 AI 配音（每角色固定一个音色）+ 智能字幕。
  4. 剪辑合成：剪映 7 步法（排序→对齐音画→0.2s 淡入淡出→字幕→BGM/音效→特效→调色导出）。
- **效率AI实战派**明确选型递进：**即梦 Seedance 2.5 起步 → 可灵做剧情 → ComfyUI 专业**。这与我们 C56（即梦分身+Seedance R2V）完全吻合，且是中文语境下最不踩坑的路径。

### 1.6 Wan-Animate-2（Step2/3 运动迁移，已可操作）
- 官方 ComfyUI 工作流已坐实（docs.comfy.org、seedance.tv、runcomfy、aistudynow 实测）：`WanAnimate2ToVideo` + `WanAnimate2Cache`，**INT8 ConvRot 包 A10 可跑**；81 帧窗 ≈3.4s@24fps，Move/Mix 双模式，LightX2V 蒸馏 LoRA，continue_motion 串联长视频。实测 22s 快舞跟随良好。
- 适用前提：已有桃子角色静帧 + 一段驱动视频（需先备素材）。

### 1.7 漫剧端到端开源仓库坐实（Step3 预研）
- **`gagansharma18/Stixx_images_videos_workflow`**：Z-Image-Turbo 出角色一致起帧 + LTX-2.3 动画（motion distillation + alignment LoRA）+ `run_pipeline.py` 批量跑多场景并自动拼 `final_storyboard.mp4`。印证 v4 漫剧骨架 C48。
- **Dify + ComfyUI 全自动生产线**（多篇 2026 教程）：Dify 当大脑（编剧/导演/提示词 Agent）+ ComfyUI 当双手（Flux 出图 + IP-Adapter-FaceID + LTX-2.3 视频 + Qwen-TTS），零代码串成端到端。印证 C62 装配层方向。

### 1.8 Gemini Omni 1.1 Flash（待核实国内可用性）
- Aug 27 发布，Arena T2V #1；场景延展（读 10s 前序片段、延展时锁身份/嗓音/光线）、首尾帧、360p 草稿模式（快 60%、1/3 价）。$0.03/s 360p → $0.30/s 4K。
- **区域限制**：Google AI Studio / Gemini API 为主，国内直连大概率受限 → 暂列「待核实」，不进本地/国内主路径。
