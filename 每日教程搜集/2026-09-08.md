## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 主线实战纪律（强化，非新工具）
- 来源：theneuron.ai《LTX-2.5 Video Prompting — Full Guide with Timestamps》（LTX 团队直播整理）；Runpod 官方博客《LTX-2.5 on Runpod》；jamlee.life / xxmr.cn 部署笔记。
- 核心要点：
  - **只重拍坏掉的 3 秒**（retake / morph-cut）：不整段重生成，用 morph-cut 补两段之间的丑缝隙。
  - **inpaint + 视频续写**延展长视频：取上段末帧续生成，保视觉逻辑（与基线「首镜→末帧→续生成→拼接」法一致）。
  - **反复出场角色**：训 LoRA，或锁定一致出图流再 I2V。
  - **audio-to-video**：音轨直接驱动作/表情/时机。
  - **Duration Head**：按提示词语义自动推断时长（叙事节奏初感知）。
  - **官方部署硬事实**：HF `Lightricks/LTX-2.5` 已门控（须接受许可+申请通过）；Comfy-Org `*-comfy-int8-convrot` 量化仅 ComfyUI 可用、bf16 全精度包 ~66GiB；Gemma 4 12B 是 LTX 专用编码器（官方 stock 版不可替）；**16GB VRAM 下限，但"舒适生产"约 48GB（即便用 distilled）**——A10 24GB 能跑但偏下限，迭代偏慢。
- 适用场景：桃子第一步本地主线的日常出片纪律，直接降废片率、省算力。

### 1.2 Kling 3.0 多镜头 + 首尾帧解除互斥 + Turbo 低价（强化 C77）
- 来源：klingai.com API 更新公告；阿里云 Model Studio《Kling Video Generation API Reference》。
- 核心要点：
  - 2026-05-07 起，多镜头视频**可同时设首帧与尾帧**（`multi_shot=true` + `shot_type=intelligence` 智能分镜）。
  - Omni 参考视频 3–15s、支持 4K；3.0 4K 94 cr/s、3.0 Pro 26–38 cr/s、3.0 Turbo **720p 0.8 cr/s / 1080p 1.0 cr/s**（最便宜迭代档）。
  - Elements 主体库支持绑音色、智能补全多角度图。
- 适用场景：桃子带情节云快验——智能分镜一次出多镜头叙事，Turbo 档低成本试跑。

### 1.3 Jellyfish AI 短剧工厂（新候选 · 漫剧装配层本地开源）
- 来源：GitHub `Forget-C/Jellyfish`（Apache-2.0，2026-07 ~5.5K★ / 960+ forks，本地部署）。
- 核心要点：端到端短剧工作台——脚本拆解→镜头准备→候选确认→生成→导出成片；**共享实体模型（角色/场景/道具/服装）跨镜复用**治「角色漂移」；统一异步任务中心。
- 适用场景：最终漫剧目标装配层，与 Toonflow / Moyin / LumenX 并列的本地开源选项。

### 1.4 Ovi 1.1 本地音画同生（新候选 · 单视频+原生音频）
- 来源：GitHub `character-ai/Ovi`（Apache-2.0 释权重）；aikolhub 实务笔记。
- 核心要点：原生 960×960、10s、视频+音频双 backbone 跨模态融合、FP8/qint8 offload ~24GB（A10 可跑）、24fps；`Audio:` 写声音、`<speech>...</speech>` 写对白。
- 限制：正方形 960×960 **不适 9:16 竖屏**；首帧一致性非持久身份系统。
- 适用场景：本地单段音画同生探索；竖屏短剧需裁切/重排，性价比待验证。

### 1.5 角色一致性通用纪律（平台无关方法论，直接服务桃子第一步）
- 来源：Hailuo AI《S2V Consistent Characters》《Episodic Social Stories》；Igly《Reusable Reference Workflow 2026》；Vitra.ai《Fix Drift》。多源对齐。
- 核心要点（可直接写进桃子 SOP）：
  1. **Character Bible**：单张高保真母版参考图（≥1024²、中/近景、平光、PNG）。
  2. **Vocabulary Lock-in**：角色描述句**原样复制**进每个 prompt，不换同义词（"reddish hair"≠"auburn"会漂移）。
  3. **Anchor Shot**：最难动作镜头先锁样，再派生简单镜头。
  4. **Start Image 法**：由母版出分镜关键帧，各作 I2V 首帧。
  5. **6 秒稳定窗口**：单镜 ≤6s，后期拼接（超出易"form melting"）。
  6. **参考栈分离**：身份 / 产品 / 场景 / 道具各一张，不混用。
- 适用场景：桃子单角色带情节的一致性兜底，**零成本、零新工具**。

### 1.6 漫剧 6 步流水线再印证（中文长文，需用户手动发链接）
- 来源：微信公众号长文《AI 漫剧落地手册》（IMA 知识库镜像；**原文需用户手动发链接**）。
- 要点：角色一致性=外貌+气质+风格+构图四维；6 步=角色体系→一致性控制→剧情→动态演绎→转场→整片；三视图+参考图锁定；动作"小且具体"（点头/眼神/撩发，忌狂奔打斗）；单句台词一镜、3–5s/段。与 C63/C73 方向一致，非新工具。
