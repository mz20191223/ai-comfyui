## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 规格彻底坐实（强化 08-13→17，今日补技术细节）
- 来源：ComfyUI 官方博客 `blog.comfy.org/p/ltx-25-day-0-support-in-comfyui`、ComfyUI Wiki `comfyui-wiki.com/en/news/2026-08-11-ltx-2-5-open-weights-release`、第三方 `datanorth.ai`、`kie.ai`（2026-08-17 更新确认消费级/Apple Silicon 跑通 + 一周内落地 multi-subject reference LoRA）。
- 核心要点：
  - **架构**：22B 非对称双流 DiT + 自研 Gemma 4 12B 文本编码器 + 专用 Prompt Enhancer。
  - **Diffusion Fidelity Rendering（DFR，全新渲染范式）**：先在 8× 时间压缩潜空间生成结构与高保真关键帧，再用独立 pixel-diffusion 阶段从结构与关键帧渲染最终视频 → 高动态不糊脸、少涂抹、文本清晰。
  - **新扩散视频解码器**替换标准 VAE 解码：脸部/文字更锐利、快速运动少涂抹。
  - **原生多镜（multishot）**：一次生成多连接镜头（远/中/近），跨镜锁角色/环境/光线/嗓音。
  - **Auto duration**：附 `duration-head model patch` 插件，按动作自动定长。
  - **原生 4K HDR + DFR + EXR 输出**（生产管线）。
  - 变体：dev（全量）+ distilled（配 `distilled LoRA (450)` 少步）；量化 int8 convrot / NVFP4；上采样器 `2x latent spatial` + `2x latent temporal`。
  - **ComfyUI 原生 day-0（v0.32.0）**，3 个官方工作流模板 JSON 已可下载：`video_ltx2_5_t2v.json` / `video_ltx2_5_i2v.json` / `video_ltx2_5_flf2v.json`（仓库 `Comfy-Org/workflow_templates`）。
  - 许可：组织年营收 < 1000 万美元（~$10M ARR）免费商用、无强制水印/署名；之上需商务授权。
  - API 价（第三方口径，未官方坐实）：$0.09/s(720p) / $0.15/s(1080p) / $0.19/s(2K) / $0.37/s(4K)。
  - 盲测（厂商自报、未第三方复现）：LTX-2.5 胜率 67% > Seedance 2.5 65% > Omni Flash 55% > MiniMax H3 50%；文内另提 "Wan 2.6 at 42%"（仅厂商口径，Wan 2.6 是否存在待独立证实，低优先）。
- 适用场景：视频主线升级（直接命中三步目标，尤其是第一步多镜叙事一致 + 第三步漫剧多镜）。
