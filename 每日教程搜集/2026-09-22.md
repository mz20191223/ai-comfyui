## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX Desktop 官方本地 App（主线交付形态新选项）【C162】
- 来源：https://ltx.io/model/model-blog/how-to-set-up-ltx-desktop
- 核心要点：Lightricks 官方本地 AI 视频生产桌面应用。Fast 模式（低显存/快、量化）与 Pro 模式（16GB+ 高质）；原生多镜 + **音画同步输出**（MP4/H.264/ProRes/PNG 序列，无浮水印）；支持 T2V / I2V（运动控制）/ **Audio-to-Video**（喂音频生成同步画面）/ **串镜 chaining**（A 镜末帧→B 镜首帧迭代）；4K 输出；可选云端溢出路由。
- 适用场景：桃子 LTX 本地出片一站式（免拼节点），降低第一步上手门槛。A10 24GB 跑 Fast 模式绰绰有余。

### 1.2 LTX-2.5 I2V AUTO 两段式蒸馏 16GB 工作流（第一步 I2V 现成模板）【C163】
- 来源：https://civitai.com/models/2853322/ltx-25-image-to-video-auto-native-synced-audio-two-stage-distilled-16gb
- 核心要点：ComfyUI 工作流（需 ≥0.30 + 自定义节点 ComfyUI-QwenVL / Easy-Use / WAS）。Stage1 8 步蒸馏草稿 → VRAM flush → Stage2 2× upscale + 3 步 refine → 双 VAE 解码（视频+音频）→ 带原生音画 MP4。Motion Switch=0 时 QwenVL 自动读源图写运镜描述，1 切换手动。最小 16GB VRAM（RTX 5080 实测峰值 ~15.2GB，无泄漏），A10 24GB 余量充足。
- 适用场景：**桃子「Qwen 角色圣经静帧 → LTX I2V 出带情节镜头」直接套用**，省去从零接线；原生音画同步，省后期对轨。

### 1.3 FastH3 8-Step V2（H3 加速·研究框架）【C164】
- 来源：https://github.com/hao-ai-lab/FastVideo （NEWS 2026/09/15）
- 核心要点：hao-ai-lab/FastVideo 发布 **FastH3 8-Step V2**——data-free DMD2 蒸馏自 MiniMax-H3、80% Video Sparse Attention、8 次前向；另 FastH3 已可跑 Apple Silicon(MLX) / DGX Spark(CUDA13)。同期 FastWan-QAD(5s/1.8s)、FastMetal-QAD(1.3B/5B/14B Mac) 等。
- 适用场景：H3 出片提速（8 步出片）。**注意**：该栈要求 CUDA13/PyTorch 2.13 + FlashAttention4（note 实测 RTX4070 尚难「即开即用」），A10 + Windows 落地门槛高，先记录不急实跑。

### 1.4 ComfyUI-H3-Continuum v3.8（H3 长片生产采样器）【C165】
- 来源：https://note.com/sepiablue/n/n1255b4a0446e（Weekly Local GenAI 9/7–9/13，含 GitHub）
- 核心要点：MIT 许可节点（H3 权重仍受 MiniMax H3 Community License 约束）。工作模式 = **生成 → 逐 chunk 审查 → 只重生坏段 → 续接 → 延长**，而非「生成几段再硬拼」。9/8 热修：续接检查、从扩展点重生、渲染历史队列等。
- 适用场景：H3 出桃子「多镜连续叙事」的生产级采样器，直接印证并固化我们 C159「母版.json + 队列 + QC」模式。

### 1.5 MiniMax H3 8-Step All-in-One（RunComfy 现成工作流）【C166】
- 来源：https://www.runcomfy.com/comfyui-workflows/minimax-h3-8-step-acceleration-all-in-one-comfyui-workflow
- 核心要点：FL2VA 主干 + LightX2V Turbo LoRA + 8 步两遍采样 + **统一多模态参考节点**（图/视频/视频+音频/独立音频同节点）；Comfy-Org MiniMax H3 包（Qwen3-VL 32B 文本编码器 AWQ、Latent Upscaler 3D）；48GB GPU 实测。
- 适用场景：H3 8 步加速现成方案。**但 48GB 门槛高于 A10 24GB**，本地 H3 主线暂不宜照搬，列为云侧/大显存参考。

### 1.6 MiniMax H3 ComfyUI 搭建实战（微信公众号镜像）【纪律级】
- 来源：IMA 镜像《Ai短剧情报站：ComfyUI对接MiniMax H3》（原文反爬，标「需用户手动发链接」）
- 核心要点：本地最低 RTX3060 12G（吃力，不建议量产）；官方内置 H3 模板 5 分钟跑通；进阶用短剧专用 JSON（多参考图+权重+首尾帧+自动命名）。**实测纪律：H3 5–6s 最稳、7–8s 动作漂移、10s+ 崩坏率骤升**；竖屏 768×1344、20–30 步。
- 适用场景：印证并固化 H3「拆 4–8s 短镜」纪律（与既有基线一致），指导桃子 H3 补镜。

### 1.7 HD-V1（HiDream-O1-Video-1.0）发布（物理建模新模型·跟踪）【C167】
- 来源：https://www.toutiao.com/article/7685924752459858475/ ；https://ima.qq.com/wiki/（特工宇宙/量子位镜像，原文反爬）
- 核心要点：智象未来 09-15 发布原生全模态视频模型，5–20s 1080p，I2V 榜(AA WithAudio) 全球第 4 / Arena 第 8。**最大卖点=「前置意图理解 + 物理规律建模」（重力/碰撞/惯性写入底层逻辑），宣称减少穿帮、动作更连贯**——正戳中我们「严格物理逻辑」诉求。
- 适用场景：物理一致性候选。但 **09-18 已确认 HD-V1 内测、无公开权重/API**；今日发布稿仍未给出可调用入口。**→ 维持「跟踪·验证开放访问后再评」，勿追**，不替换现有选型。

### 1.8 Kling 3.0 角色一致四步 + 五大常见错误（云快验纪律）【纪律级】
- 来源：https://www.atlascloud.ai/zh/blog/guides/how-to-use-kling-3.0-for-character-consistency ；https://magichour.ai/blog/how-to-use-kling-30
- 核心要点：四步=主角色(参考图)→锁提示词(+负向)→AI 多镜头(多角度参考)→生成+扩展(前帧延续)。五大错误：① 提示词堆砌多光照/多运镜→抖动；② 参考图低质/风格化→脸漂；③ **音频加太早**（视觉未定就加对白→双重不稳定）；④ 矛盾运镜（静态锁定+大幅推镜）；⑤ 不做跨镜一致性自测。
- 适用场景：桃子 Kling 云快验 SOP。**新纪律：「音频最后加」顺序 = 锁身份→稳运动→定光→再加音频**；每镜先出中景低动验证再升。

### 1.9 单角色叙事一致性通用工作流（多源印证·含新 LUT 技巧）【纪律级】
- 来源：https://ai-lumineer.com/blog/character-consistency-2026 ；https://nexvy.ai/blog/how-to-create-consistent-characters-in-ai-video ；https://omniart.studio/blog/tutorials-how-to-guides/consistent-characters-ai-video-guide
- 核心要点：① 一张强参考静帧 > 多张弱图；② I2V 动画（别用文字重描脸）；③ 同 seed/同光比/同衣；④ 逐镜从同一锚生成再剪；⑤ **新技巧：所有镜头统一调色到单一 LUT**，抹平跨镜光照漂移；⑥ 模型：Kling(I2V 锚脸稳定)、Seedance(参考+运动连贯)。
- 适用场景：直接支撑桃子第一步 I2V-first 路线，LUT 技巧为零成本补强（并入 SOP）。

### 1.10 漫剧六工序拼装骨架（Step3 预研参考）【装配层】
- 来源：IMA 镜像《8个开源项目拼装漫剧》（微信公众号《AI智能通》，标「需用户手动发链接」）
- 核心要点：剧本分镜(LLM)→角色一致画面(**PuLID / IP-Adapter**)→图生视频(**MiniMax H3**)→配音(GPT-SoVITS/Fish Speech/IndexTTS)→口型(**LivePortrait**)→字幕(**manga-image-translator**)→自动剪辑(**auto-editor**)。注：PuLID 是 Qwen 出图外的另一种锁脸方案；LivePortrait 做口型、auto-editor 去静音精剪。
- 适用场景：最终漫剧(Step3)装配参考；第一步不投入。另 waoowaoo 已达 7.4k★ 工业级一站式（C137，已记录）。
