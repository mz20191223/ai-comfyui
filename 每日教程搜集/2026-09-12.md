## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 官方模型页 + 提示词指南（强化主线，非新工具）
- 来源：[ltx.io/model/ltx-2-5](https://ltx.io/model/ltx-2-5) · [deapi.ai LTX-2.5 Prompting Guide](https://deapi.ai/blog/ltx-2-5-prompting-guide-multi-shot-scenes-native-audio-and-prompts-that-actually-cut)
- 核心要点：
  - **基准横评坐实 LTX-2.5 本地主线首选**：10s I2V 生成速度 **6.8s（on-prem，最快）**；视觉伪影评分 **0.28（十模型最低）**；支持最长边 **1344**（2.3 仅 1024），Fast 档可上 **4K**，单段最长 **20s**；API 价 $0.09/s@720p。
  - **原生多镜（Native Multishot）**：一次生成内含真实剪辑（cuts），切镜后角色/环境/光线/嗓音保持——这正是「带情节」第一杠杆，无需逐镜拼接。
  - **提示词六要素**细化（印证 C107）：Shot / Scene / Action（最前、用 motion 动词 + "then" 串联）/ Character（仅 1 个主体，情绪用肢体而非命名）/ Camera（相对主体命名一个运镜）/ Audio（声画同生成，对话用引号+语言，约 2.5 词/秒）；写**一段现在时 4–8 句散文**，禁用 Subject:/Camera: 标签式。
  - 新能力：**Auto duration**（模型自定时长）、Diffusion Fidelity Rendering（按场景复杂度分配算力）、原生 4K HDR / RAW、可微调（ pretrained base checkpoint 专供 fine-tune）。
- 适用场景：桃子第一步「单角色带情节」直接落地；出图线 A 首镜/关键帧 → LTX I2V 多镜。

### 1.2 参考优先（Reference-First）角色一致性工作流（多源强印证，零成本纪律）
- 来源：
  - [8frame — Best AI Video for Consistent Characters 2026](https://www.8frame.co/blog/best-ai-video-generator-for-consistent-characters-2026)（成本量化：「先锁静止图再驱动视频」≈53 credits vs 重滚 T2V≈282）
  - [Hailuo — Episodic Social Stories / Vocabulary Lock-in / 6-Second Stability](https://hailuoai.video/pages/knowledge/episodic-social-stories-subject-consistency-ai-video)（内部实测 4–6s 稳定窗口）
  - [dev.to — Reference-First Workflow](https://dev.to/jamiecoleai/how-to-keep-characters-consistent-in-ai-videos-a-reference-first-workflow-4il8)（6 步顺序法：先简后繁、分层加复杂、逐帧 inspect）
  - [Wayaframe — How to Achieve Character Consistency](https://wayaframe.com/help/how-to-achieve-character-consistency)
  - [BudgetPixel — Wan 2.7 Start Image Method](https://budgetpixel.com/blog/from-character-design-to-cinematic-storytelling-creating-consistent-ai-videos-with-wan-27-on-budgetp)（Master Character → 每镜 Start Image → I2V，prompt 只写运动）
- 核心要点（五源共识，直接对齐我们 I2V-first 基线 C43/C58/C98）：
  1. **先锁静止图，再驱动视频**：主角色参考图（Master Reference）定身份，每段用该角色在本镜的图作首帧/参考，prompt 只描述「接下来发生什么」，绝不重描服装/发色/光线（重描会触发漂移）。
  2. **角度包（Angle Pack）**：单张正脸不够——生成 3–5 视图（正脸/三七/侧脸/微仰）作参考集，参考条件在未见角度上迁移差，跨角度一致性靠它补。Seedream V5 收 14 张参考、成本约 $0.06/张。
  3. **Vocabulary Lock-in**：角色关键特征用**同一句原文**逐镜复制粘贴（"wavy auburn hair in low ponytail"），换同义词即触发视觉漂移。
  4. **≤6 秒稳定窗口**：单段超过 6s 形变/换脸概率显著上升；专业做法=生成短「原子」片段，后期拼接。
  5. **I2V 优于 T2V 保一致**：T2V 每跑一次重新发明一张脸；I2V 有视觉起点，保人。
- 适用场景：桃子第一步零成本纪律升级；与出图线 A（Qwen-Image-Edit 出主角色+各角度）天然衔接。

### 1.3 LTX-2.5 实战设置与多工作流（ComfyUI 落地的可抄模板）
- 来源：[RunComfy LTX-2.5 I2V+音频](https://www.runcomfy.com/comfyui-workflows/ltx-2-5-comfyui-image-to-video-synced-audio) · [aistudynow 实测](https://aistudynow.com/ltx-2-5-in-comfyui-what-improved-best-workflow-settings-and-my-tests) · [earngenix I2V/FLF2V](https://www.earngenix.com/workflows/ltx-2-5-comfyui) · [lilys.ai 8合1](https://lilys.ai/notes/en/comfyui-20260826/ltx-2-5-all-in-one-workflow-comfyui) · [stablediffusiontutorials 模型清单](https://www.stablediffusiontutorials.com/2026/08/ltx-25-video-generationint8bf16nvfp4gguf.html)
- 核心要点：
  - **实测起手设置**（aistudynow）：常规 I2V 关 Prompt Enhancer（自己写清时序+运镜）；复杂对白先试 Duration Predictor；首末帧(FLF2V)复杂转场仍可能几何崩（门/座椅/车）——短 10s 优于 18s；低显存用 Q4 GGUF，有余量优先 distilled INT8；旧 LTX 2.3 LoRA @0.5 可微修物理（非通用）。
  - 8 合 1 工作流（lilys）：T2V/I2V/首末帧/首末帧+口型/图+音频口型/首中末帧+口型/音频生视频/视频转视频，**8GB 可跑**（GGUF distilled + LoRA）。
  - 模型文件清单固化（int8-convrot 官出，替代社区 GGUF）：diffusion + gemma4-12b-with-proj(int8-convrot) + video-vae + audio-vae + latent spatial/temporal upscaler x2。
- 适用场景：A10 24GB 本地 LTX 主线实操依据；与 C69/C80/C106 一致。

### 1.4 LTX-2.5 vs MiniMax H3 实拍对比（确认分工，非新工具）
- 来源：[pixomi.ai hands-on](https://pixomi.ai/blog/ltx-2-5-vs-minimax-h3?__pvhp=1)
- 核心要点：同 prompt 两测——**H3 运动更"接地"**（狗跑动有重量感、爪与地接触更真），**LTX-2.5 主镜头/定制/多镜更强**（动作完成且可认，但部分运动有"踩空"轻飘感）。
- 适用场景：印证基线分工——LTX 主线（多镜/定制/速度），H3 质量补镜轨（物理真实运动）。无需调整。

### 1.5 漫剧开源 8 项目全链路骨架（最终阶段参考，IMA 镜像）
- 来源：[IMA 知识库 — AI智能通《不花一分钱：8 个开源项目拼装漫剧》](https://ima.qq.com/wiki/?shareId=30ceb0c0a79aa47712182fb7d50c039f900717575a638fbc0fbaff91b6d2329f)（**微信公众号/小红书原文反爬，需用户手动发链接**；此为 IMA 转载镜像）
- 六道工序母版：剧本分镜(LLM) → 角色一致画面(PuLID / ComfyUI+IP-Adapter) → 图生视频(**MiniMax H3**，显存紧退 Wan2.2 5B) → 配音(GPT-SoVITS/Fish Speech/IndexTTS) → 口型(LivePortrait) → 字幕(manga-image-translator) → 自动剪辑(auto-editor)。
- 适用场景：最终漫剧阶段装配层参考骨架；与我们「Qwen-Image-Edit 出图 → LTX 出视频」主线可映射（把 H3 换成 LTX 即可）。

### 1.7 新开源视频模型（仅入库记录，非 A10 可跑 / 非叙事主向）
- **MAGI-2-preview**（SandAI-org，Apache 2.0）→ **C114**：114B MoE / 6B 激活，10s+同步音频，两阶段 1080p，Docker + offload。**但需 8× NVIDIA Hopper GPU（307GB 权重）**，A10 24GB 不可跑，仅记录。
- **LingBot-Video**（Robbyant/蚂蚁，Apache 2.0）→ **C115**：30B-A3B MoE / 3B 激活，RBench 开源第一（0.620），7 万小时机器人数据注入、重物理合理性；含 1.3B dense 消费级变体，ComfyUI WIP PR。**方向偏具身智能/机器人，非桃子叙事主向**，记录待评估。
- **Bernini**（ByteDance，Apache 2.0）→ **C116**：MLLM 语义规划(Qwen2.5-VL-7B) + Wan2.2-A14B 渲染器(SA-3D RoPE)，统一视频生成+编辑。**编辑向**，可作后期补镜/改镜候选，记录。

## 2. 可行性分析（结合阶段目标与基线）

### 第一步：桃子单角色带情节视频（当前最高优先）
| 方案 | 成本 | 风险 | 收益 | 判定 |
|---|---|---|---|---|
| **参考优先纪律 + LTX I2V 多镜**（C43/C58/C98/C107 + 今日 1.1/1.2） | 零（已有 LTX 部署 + Qwen-Image-Edit 出图） | 低 | **直接达成带情节**：一次生成多 cuts 保角色，省逐镜拼接 | **现在最值得做** |
| 角度包（3–5 视图）补跨角度一致 | 低（出图几次） | 低 | 解决侧脸/俯仰角漂移 | 值得，待实跑验证 |
| Digen 单镜快速验证 | 低（已有渠道） | 低 | 快速试运动/构图，再决定上 LTX | 维持 |
| H3 质量补镜（物理真实运动） | 中（API/本地 offload） | 中 | 个别物理镜头更真 | 维持 C55，非第一步必需 |

**结论**：今日无推翻性工具。LTX-2.5 基准横评（最快 6.8s、最低伪影 0.28、原生多镜、最长 20s）进一步坐实其本地主线地位。真正该立刻做的是**把多源印证的"参考优先工作流"纪律固化进桃子第一步**——零成本、最高杠杆。

## 3. 及时调整建议

**增量强化，非推翻现有基线。**

1. **第一步 SOP 升级（零成本，最高优先）**：把今日多源印证的"参考优先工作流"写进《桃子第一步 SOP》——
   - 出图线 A 产「主角色参考图 + 3–5 视图角度包」；
   - LTX I2V 用该角色在本镜的图作首帧，prompt **只写运动+运镜+音频**，绝不重描身份；
   - 角色特征用 Vocabulary Lock-in 原句复制；
   - 单段 ≤6s，多 cuts 用 LTX 原生多镜一次生成。
   - 替换/补充：原「逐镜 I2V 再拼接」→ 优先「LTX 原生多镜单次生成」，减少拼接与漂移。
2. **维持 LTX 主线**：基准横评证实最快/最低伪影/原生多镜/可微调，无需换模型；H3 继续作物理真实运动补镜轨（呼应 1.4）。
3. **漫剧装配层补 LocalMiniDrama(C113)**：与既有 Toonflow/Moyin/LumenX/ArcReel 并列，第一步跑通后再评估。

> 注：未发现有比「Qwen-Image-Edit 锁角色 → LTX 出视频」更优且能在 A10 24GB 落地的替代链，故**不调整主线**。
