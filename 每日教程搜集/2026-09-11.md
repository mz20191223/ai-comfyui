## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 官方 I2V 工作流 SOP 坐实（高价值·强化主线）
- **来源**：[docs.ltx.io 官方 I2V 指南](https://docs.ltx.io/open-source-model/usage-guides/image-to-video) + [RunComfy LTX-2.5 I2V+同步音频工作流](https://www.runcomfy.com/comfyui-workflows/ltx-2-5-comfyui-image-to-video-synced-audio)
- **核心要点**（官方明确行为，非社区猜测）：
  - 两阶段 pipeline：Stage1 源图以 conditioning strength **0.7** 注入生成视频+音频 → 2× latent spatial upscale → Stage2 源图以 strength **1.0** 重注入保细节。
  - 基础分辨率 = 目标的一半（最终 2× 放大输出）。默认 Width 768 / Height 512。
  - 帧数约束：**帧数 = 1 + 8 的倍数**（默认 97 帧 ≈ 4s@24fps）。
  - Prompt Enhancement 默认开（Gemma 模型扩写短提示词）；Audio VAE 在 Stage1 与视频联合生成音频。
  - 模型族：`ltx-2.5-22b-distilled-transformer` + `gemma4-12b-with-proj-ltx-2.5`(int8-convrot) + `gemma4_e2b_it`(enhancer) + video/audio VAE + `ltx-2.5-latent-spatial-upscaler-x2`。
- **适用场景**：出图线A 出的桃子首帧 → LTX I2V 带情节成片。直接固化进我们主线工作流。

### 1.2 LTX-2.5 提示词六要素 + 角色锚点公式（多源对齐·零成本纪律升级）
- **来源**：[soloa.ai LTX-2.5 Prompt Guide](https://soloa.ai/blog/ltx-2-5-prompt-guide-2026) / [supermaker.ai 一致性指南](https://supermaker.ai/blog/ltx-2-5-prompt-guide-for-consistent-characters-camera-control-and-product-ads) / [earngenix LTX 提示词修复](https://www.earngenix.com/tutorials/ltx-2-prompting-guide)
- **核心要点**：
  - 每 prompt 六要素：**Shot(景别) / Scene(光照气氛) / Action(动作时序) / Character(具体特征) / Camera(机位运动) / Audio(环境声/音乐/对白引号括起)**。绝不用逗号堆叠标签（tag stacking 致抖动/构图崩）。
  - **角色锚点公式**：姓名 + 年龄段 + 面部特征 + 发型 + 固定穿搭 + 标志性配饰 + 嗓音。例：`Maya, 三十出头, 鹅蛋脸, 暖棕肤色, 齐肩黑卷发, 米色亚麻外套, 小金坠, 低沉平静嗓音`。
  - 多镜：**每代 2–4 cuts**，用自然语言点名转场（"A hard cut transitions to…"），每次切镜重述身份标识 + 一致性从句（"Preserve character facial structure, outfit, lighting across all cuts"）。
  - 参数：CFG 3.0–4.2、full 25–35 步 / distilled 8–12 步、i2v denoise 0.45–0.65；对白用引号括起并注明语种/口音。
- **适用场景**：桃子第一步带情节提示词直接套用，提升一次通过率。

### 1.3 LongCat-Video —— 美团开源长视频模型（新·本地 A10 潜在可行）
- **来源**：[github.com/meituan-longcat/LongCat-Video](https://github.com/meituan-longcat/LongCat-Video) + [Kijai ComfyUI-WanVideoWrapper](https://github.com/kijai/ComfyUI-WanVideoWrapper) + [aistudynow 低显存实测](https://aistudynow.com/comfyui-longcat-workflow-make-very-long-video-on-low-vram)（第三方实测，发布日期说法混乱 2025/2026 不一，谨慎）
- **核心要点**：
  - 13.6B Dense Transformer，**MIT 开源**；T2V / I2V / 视频续写（continuation）统一架构。
  - 原生最长 **961 帧（~32s@30fps）**、480p/720p；Block Sparse Attention 支持分钟级续写。
  - **VRAM**：FP8 版 `LongCat_TI2V_comfy_fp8_e4m3fn` ~15.5GB（**A10 24GB 可跑**）；bf16 ~27GB（需 >24GB）；Avatar 1.5 = Audio-Text-Image2V、5+ 分钟连续、口型同步、FP8 12GB。
  - 实测低显存工作流：640×604 / 12 步 / CFG=1 出 93 帧 15fps，续写追加 prompt 衔接平滑、无色彩漂移。
- **适用场景**：补足 LTX-2.5 单段 ~20s 上限的「长叙事」短板；本地 A10 并行候选。

### 1.4 VDN-H3 —— MiniMax H3 加速（非 A10，仅记录）
- **来源**：[OpenVDN/vdn-minimax-h3](https://github.com/OpenVDN/vdn-minimax-h3)（2026-09-06 发布）
- **核心要点**：混合注意力（线性分支 + softmax 分支）让 H3 快于实时——8×B200 上 14.4s 片 11.23s 出（8 步）。需 82GB 权重 / FlashAttention 4 / PyTorch 2.13。**8×B200 配置，非 A10 适用**。
- **适用场景**：长期 H3 质量补镜轨道加速参考；本地 A10 当前不可跑。

### 1.5 OpenMontage —— Agentic 视频工厂（星数存疑·低优先级）
- **来源**：[calesthio/OpenMontage](https://github.com/calesthio/OpenMontage)（AGPL-3.0）；今日头条称 5.5万★、IMA 称 15.6k、另一 IMA 称 3224★——**星数差异巨大，5.5万或虚高**。
- **核心要点**：把 AI coding assistant（Claude/Codex/Cursor）当导演，12 流水线 / 52 工具 / 500+ skills，Remotion/FFmpeg 合成。偏**真实素材纪录片/营销片**（从 Archive.org/NASA/Pexels 拉真实运动画面），非 AI 角色生成主路径。
- **适用场景**：不在我们 AI 角色视频主线，仅记录。
