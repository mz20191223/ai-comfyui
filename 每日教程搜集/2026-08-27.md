## 1. 新发现（教程 / 工具 / 工作流）

### 🔴 1.1 MiniMax H3 本地 A10 24GB 可行性 — 修正基线"装不下"误判
- **来源**：掘金硬件账本（RTX 4090D 24GB 实测，2026-08-07）、今日头条 24G+64G 实测、51CTO 生产化实践、ComfyUI Wiki、runaihome GGUF 教程、ComfyUI 官方博客（#15224 day-0）。
- **核心要点**：
  - H3 是**开放权重**（MiniMax H3 Community License，非闭源；仅 2K 再生成模块 Context-IR 与部分未开源）。中国境内可用；年营收 <2000 万美元可商用（需署名）；不得用其输出训练其他模型。
  - **A10 24GB 可跑**，路径 = `pruned_int8_convrot` DiT（19.5GiB，近常驻）+ 文本编码器 `nvfp4_awq`（14.6GiB，顺序阶段不占常驻显存，与 LTX 的 Gemma4 同理）+ 双 VAE（~5.5GiB）。**本地原画封顶 1344×768（非 2K）**。
  - 但 A10 属 Ada 架构：`nvfp4` 在 40 系/数据中心 Ada 上走**软件反量化、无加速** → Ada 卡推荐改用 `int8_convrot` 文本编码器（27.1GiB，需 ~70GiB 系统内存）。**关键约束：系统内存**。社区实测底线 12GB 显存 + 32GB 内存可跑 480p；24GB 卡舒适线需 **64–96GB 内存**（权重全驻留内存防落盘）。
  - 速度：24GB 卡 offload 受限，5s@480p 约 2–4 分钟（20 步），10s 约 20–35 分钟；**永远用 5s 迭代提示词**。
  - 原生 32kHz 立体声音画同网络生成（单次前向，非后期对齐）——直接命中桃子"带情节 + 口型/环境音"需求。
- **适用场景**：本地可控、带原生音频的单角色带情节视频；质量天花板高于 LTX-2.5（seedance.tv 横评：LTX 赢迭代速度，H3 赢最终画质）。
- ⚠️ 需确认本机系统内存：H3 在 A10 上能否"舒适跑"取决于内存是否 ≥64GB，否则落盘变慢。

### 🟢 1.2 H3 加速生态（若跑 H3 必装）
- **来源**：runaihome（2026-08）、agihunt 2026-08-26、HuggingFace。
- **larryvrh/ComfyUI-MiniMax-H3-Turbo**：Turbo LoRA（v4 修塑料感），**4–8 步**出片（原 ~20 步），LoRA strength 1.0、steps 6–8 为质量甜点；自带双时钟采样器修 week-1 音频发脆。→ H3 提速最大杠杆，比任何量化都管用。
- **ComfyUI-PlagueKind-Nodes**（SLA Node v1.3.5）：可定制密集步数 + 后端选择 + 质量默认。
- **MiniMax-H3-RAVEN-Streaming-LoRA**（HF）：实时生成（自回归+扩散）。
- **lightx2v Minimax-h3-Turbo-SLA**：I2V 权重（稀疏注意力+蒸馏）。
- **NVIDIA 超加速管线**：H3 4 步 LoRA 起草 → LTX 步升采样精修（Sol-Attn），GB200 上 22.2× 提速（仅数据中心参考）。

### 🟢 1.3 Wan 3.0 官方 ComfyUI API 节点（云编排变易）
- **来源**：comfy.org 官方工作流（Wan3.0 T2V / Wan3ReferenceToVideoApi R2V 节点）、agihunt 2026-08-26。
- **核心要点**：Wan 3.0 已上 ComfyUI 官方 **API 节点**（远程推理，本地 GPU 非瓶颈）。R2V 节点接受参考图锁角色，返回 30s 带同步音频成片。已铺到 Magnific / Flova / Pollo / Merge 多前端，成本约 Seedance 2.5 的 1/3（$0.13/s、30s≈$1.2–3.9）；多语口型跨镜头/跨语种稳定。
- **适用场景**：桃子第一步云验证的"官方节点化"入口（比手写 API 稳）。仍为**闭源仅云**。

### 🟢 1.4 可抓的中文即梦 / 可灵实操教程（今日头条，非公众号/B站/小红书）
- **来源**：今日头条《效率AI实战派 AI视频生成工具完全指南 即梦·可灵·ComfyUI 三件套》（2026-07）、《AI短剧制作:可灵与即梦工具组合实战指南》（hqwc）、《如何做一部AI短剧？零基础全步骤实操教程》（今日头条 7671939224295178798）、《0基础打造AI演员/AI明星全套落地教程》（今日头条 7670107145584624164）。
- **核心要点**（与桃子 Step1 直接对齐）：
  - 选型递进：**起步用即梦（Seedance 2.5）、做剧情用可灵（Kling 3.0）、想专业用 ComfyUI**。
  - 即梦 Seedance 2.5：30s 单出、50 参考、首尾帧控制、局部编辑、动作模仿；免费 720p、付费 1080p/4K。
  - 可灵 Kling 3.0：人物一致性业界最强、运动笔刷（精确控区域运动）、对口型最准、多镜头一次生成。
  - 通用流水线：角色三视图（正面/侧/45°）→ 冻剧本 → 即梦分镜 → 可灵加动态 → 剪映配音剪辑。
  - 避坑铁律：**不做三视图直接生成=全程换脸**；单镜 ≤8s、动作只做转头/抬手/走路（复杂动作拆多镜）；上一镜末帧作下一镜首帧提衔接；逐个镜头校验重跑（"抽卡"）。
- **适用场景**：桃子第一步**低摩擦云快验**（无需本地 GPU、当天出片）。

### 🟡 1.5 LTX-2.5 二次元/赛璐璐弱点提示（风格风险）
- **来源**：51CTO《回归本地:如何高效生成AI漫剧与短视频》（2026-08）。
- **核心要点**：LTX-2.5 训练集偏写实真人影视，**对二次元赛璐璐平涂画风兼容性差**，生成漫剧动态时易线条模糊、色块渐变、人设微调变形。H3 demo 含"漫画风小超人"（漫画风可行）。
- **适用场景**：⚠️ 若桃子走**动漫/卡通风格**，LTX-2.5 存在人设漂移风险，需先测风格兼容性或加风格 LoRA；写实风则 LTX-2.5 优势成立。

### 🟢 1.6 开源本地化趋势确认（51cto / builderai.tools）

## 3. 及时调整建议

1. **🔴 修正基线对 H3 的误判**（最高优先）：H3 实为**开放权重**（非"闭源云并列"），且 **A10 24GB 本地可跑**（pruned_int8_convrot DiT 19.5GiB 近常驻 + 顺序阶段文本编码器 + 层卸载，需本机 ≥64GB 内存、本地封顶 1344×768）。建议将 H3 从"不进本地主线"调整为"**本地 A10 可跑的对比/质量补镜轨道**"，与 Seedance 2.5 云快验并列、且具备本地可控优势。
2. **是否替换 LTX-2.5 主线**：🟡 **暂不替换**（LTX 迭代更快、蒸馏+Guider 更成熟、A10 无 offload 拖累）；但 H3 原生立体声音频 + 更高画质天花板对桃子"带情节+口型"极具吸引力，列为**最高优先本地对比项**，等用户实跑 5s 样本后定夺。若桃子偏写实且重视音频，H3 有上位为主线的可能。
3. **🆕 若跑 H3，必装 Turbo LoRA（larryvrh v4，4–8 步）+ 双时钟采样器节点**，否则 many-minutes 渲染不划算。
4. **⚠️ 桃子风格前置判定**：若桃子为**动漫/卡通**风，先测 LTX-2.5 风格兼容性（51cto 提示二次元漂移），必要时加风格 LoRA 或对照 H3 漫画风；若为**写实亚洲脸**（与基线 "girl" hack 一致），LTX-2.5 优势成立，直接首跑。
5. **Wan 3.0 加官方 ComfyUI API 节点**作云验证入口（比手写 API 稳），维持闭源仅云。
6. **公众号/B站/小红书反爬**：今日未直接抓到（已标"需用户手动发链接"）；同类中文实操以今日头条/掘金/51cto 可抓内容覆盖，已纳入 §1.4。
