### 1.1 SANA-Video 2.0 5B —— NVIDIA 开源极速本地视频模型（新轨道，C140）
- 来源：
  - NVlabs/Sana GitHub（含新闻） https://github.com/NVlabs/Sana
  - ComfyUI Wiki 中文报道 https://comfyui-wiki.com/zh/news/2026-09-01-sana-video-2-0-4step
  - HF 权重 `Efficient-Large-Model/SANA-Video_2.0_5B_720p_4step` https://huggingface.co/Efficient-Large-Model/SANA-Video_2.0_5B_720p_4step
- 核心要点：
  - **Apache 2.0 开放权重**，4.47B 参数，混合注意力（75% 门控线性 + 25% softmax 锚点）+ LTX 2.3 VAE（128 通道）。
  - **4-step DMD 预览版**：T2V **仅文本生视频**，720p（736×1280），5s@16fps 或 8s@24fps，BF16 / CFG=1 / 四阶段采样；VBench 全维评测达标。
  - **50-step 基础 5B 版**：T2V + **TI2V（图像条件，8s）**，可作首尾帧外的图生视频。
  - 显存：小规格约 **4.6GB**、完整约 10.7GB → **A10 24GB 轻松跑**，比 LTX-2.5（22B）小 5 倍、快数个数量级。
  - 当前限制：4-step 预览**不支持首帧 I2V**（纯 T2V）；推理需 Sana 仓库 preview 分支 `feat/sana-video2-4step-preview`，上游 PR 未合，ComfyUI 节点就绪度待验。
- 适用场景：A10 本地**极速草稿/动态预演**——先用 4 步版 5–8s 验证构图与运动，再决定用 LTX dev 出正片；不替换 LTX 主线，作互补「草稿轨」。

### 1.2 AIComicBuilder / CineGen-AI —— 漫剧装配层新候选（Step3 预研，C141 / C142）
- **C141 AIComicBuilder**（LingyiChen-AI，GitHub） https://github.com/LingyiChen-AI/AIComicBuilder
  - 端到端流水线：剧本导入 TXT/DOCX/PDF → AI 提取角色+分集 → **角色四视图（正/四分之三/侧/背）** → 智能分镜（构图/灯光/运镜）→ **首尾帧生成** → 视频提示词 → 首尾帧插值生成视频 → 视频合成+**字幕烧录** → 失败自动重试 3 次 → 多模型（OpenAI/Gemini/Kling/Seedance/Veo）。
  - 有 **B站演示视频**（v0.2.1/v0.2.2 已接 Seedance 2.0 参考图模式）。→ 「需用户手动在 B 站搜 AIComicBuilder 演示」。
  - 定位：Step3 漫剧装配层端到端候选，与 Toonflow / LocalMiniDrama / novella 并列；**需用户确认仓库星数与活跃度**。
- **C142 CineGen-AI**（Will-Water，GitHub） https://github.com/Will-Water/CineGen-AI

### 1.3 Qwen-Image-2512 双路控制 + 中文文字像素级对齐（出图线 A 强化，C143）
- 来源：
  - 网心算力云《Qwen-Image 全新系列》 https://m.onething.net/media/462.html
  - CSDN《5分钟上手 Qwen-Image-2512-ComfyUI》 https://blog.csdn.net/weixin_35752233/article/details/157624939
  - ik3d《Qwen-Image-Edit Made Character Consistency Free》 https://www.ik3d.fr?p=47858/
- 核心要点：
  - **双路控制架构**：`Qwen2.5-VL` 负责语义理解 + `VAE` 负责外观约束 → 实现「**改什么就只改什么**」（换衣服不连发型/背景一起变），实测保留领带、手表、站姿。
  - **Text-Adapt 模块**：中文字体**像素级对齐、风格级延续**（手写体起笔顿点/收笔飞白可复刻），实测 27 组中文编辑 100% 准确、无断行/失真/锯齿。
  - **多图协同编辑**：2–3 张图才进入生产力区间（与 C121「顺序须与提示词指代一一对应」纪律一致）。
  - 2512 vs 2511：2512 生图更快（提速 18%）、细节/色彩更好；局部编辑仍用 2511（编辑分支）。
- 适用场景：桃子**角色圣经 + 中文标题卡/对白字幕卡**直出——减少后期 PS，出图线 A 新增能力点（强化 C47/C52/C67）。

### 1.4 Kling 3.0 I2V 实测参数 + Character ID 最佳实践（云快验 SOP 补充）

### 1.5 LTX-2.5 20 秒生成「五类失败模式」（SOP v2 失败自查，零成本）
- 来源：
  - prompt-architects《Structuring a 20-Second Generation》 https://prompt-architects.com/blog/221-structuring-a-20-second-generation-ltx-2-3
  - LTX Studio 官方提示词指南 https://ltx.studio/blog/ai-video-prompt-guide
  - The Neuron《LTX-2.5 Video Prompting》 https://www.theneuron.ai/explainer-articles/ltx-2-5-video-prompting-for-beginners-full-guide-with-timestamps
- 核心要点（**五类失败，四类是提示词侧**）：
  1. **Beat compression**：20s 塞 7 个节拍→每个被加速；砍到 4–5 个让每个呼吸。
  2. **Unassigned tail**：最后 3–4s 无指令→模型自由发挥；务必以「收尾动作」结尾。
  3. **Identity softening on wide**：拉远镜头脸变通用；用重复标识符锚定，拉远时保持朝向/距离一致。
  4. **Light logic breaking**：两个隐含光源打架→每拍只点名一个光源并描述其后果。
  5. **On-screen text / chaotic physics**（模型侧）：LTX 自承认短文字准确率提升但「跨帧拼写不保证」；关键标题/Logo **放后期**；避免高混沌物理。
  - 复用官方六要素（C107）+ 多镜 2–4 cuts 一致性从句（C130），本清单作为《桃子第一步 SOP v2》的「生成失败自查」段，零成本。

## 3. 及时调整建议

**增量非推翻**，在现有基线上补强 + 一处风险纪律收紧：

1. **云快验 Seedance 2.5 降级为「内部试验/非商用样片」专用**（替换既有「Seedance 剧作模式首选」表述）：多家媒体确认迪士尼/派拉蒙等就训练数据向 Seedance 发律师函、Seedance 2.0 曾延后发布。我们做**可能发布的微短剧**时，优先用本地开源权重（LTX/Wan 2.2/H3）出片，Seedance 仅用于内部玩法验证。**Kling 3.0 暂未出现同类公开法律警告**，可作云侧带情节样片的相对更稳选项（但仍建议商用前确认条款）。
2. **新增 SANA-Video 2.0 5B 为本地极速草稿轨（C140）**：A10 上先用 4 步版出 5–8s 动态预演验证构图/运动，再上 LTX dev 出正片；50 步版支持 TI2V 时可补「本地图生视频」空缺。不替换 LTX 主线。
3. **出图线 A 启用 Qwen-Image-2512 中文文字像素级编辑（C143）**：桃子中文标题卡/对白字幕卡直接出图，减后期；与既有角色圣经（CCC3.8 / C129）共用同一 2512 管线。
4. **《桃子第一步 SOP v2》补「LTX 20 秒五类失败自查」段**（零成本，合并 C107/C130）：beat 不超 4–5、结尾有收尾动作、拉远重复标识符、单光源、关键文字放后期。
5. **Kling 快验 SOP 补实测参数**（creativity 0.65–0.75 / 5–10s / Motion Brush / 负向 blur,flicker,distortion,morphing,artifacts）+ Character ID 3–5 图参考表；**执行前先核实 kling3.xyz 是否为官方/可信源**（疑似 SEO 镜像）。
6. **漫剧装配层新增 AIComicBuilder（C141）跟踪**，与 Toonflow / LocalMiniDrama / novella 并列，待用户确认星数后评估。
7. **基线/LTX 主线/Qwen 出图/Digen 补位全维持不变。**

> 无「替换现有主链路」级调整。若用户后续实跑 SANA-Video 5B 发现其 TI2V 质量可接受且远快于 LTX，则评估将其列入「本地快验主轨」候选（v5）。
