## 1. 新发现：教程 / 工具 / 工作流

### 1.1【头条·本地主线补强】LTX-2.5 六关键帧串联 50 秒可控长视频工作流（已核实）
- 来源：GitHub `reventadirecta/LTX_2.5_6FRAMES_5PROMPTS`（Sep 5–7, 2026，含双语/西英文档、工作流 JSON、自研节点、模型清单）；AGI Hunt 报道 https://agihunt.info/p/1a07abaa5529729915e9c81674d
- 核心思路：不用单一首尾帧，而是 **6 张有序关键帧 + 5 段独立提示词，串联 5 次 FLF2V（首尾帧到视频）生成**，每段场景/运镜/动作逐步演进，最后用自研 `LTX25VideoConcat` 节点拼成一段。
- 技术栈：LTX-2.5 22B Distilled + **W4A8 ConvRot Transformer** + Gemma 12B W4A8 文本编码器 + BF16 视频/音频 VAE + DynamicVRAM；`ImpactExecutionOrderController` 强制 5 段串行以压低峰值显存。
- 实测：RTX 4060 Laptop（**8GB VRAM**）+16GB 内存 + ComfyUI 0.34.3 + Windows；720×1280 竖屏、每段 10s、24fps，全流程 **30 分 54 秒**产出约 **50 秒**成片。
- 适用场景：**本地、零 API 费用**把单镜上限从 ~10s 拉到 ~50s 可控叙事；直接服务「第一步 桃子带情节」并可沿用到「漫剧」多镜头本地拼接。
- 交付物：仓库含 workflow JSON、custom_nodes/LTX25WorkflowTools、docs（INSTALLATION/CONCEPT/TROUBLESHOOTING）、models 清单。

### 1.2【本地 H3 轨道 / 漫剧装配】qamba-studio v0.2.3（报道级，仓库待确认）
- 来源：AGI Hunt 报道 https://agihunt.info/en/p/1a0866c83992bb4251f8ae771ba
- 核心：本地优先的 ComfyUI + MiniMax H3 桌面 app（mac/Win 构建），含**故事板/角色圣经系统**（角色/地点/道具出参考表，每镜从这些表起稿保一致）、One-shot 向导、Director chat 改戏重渲、**运动续接**（把上一段尾帧+音频钉进下一段，切点不重置运动）、后处理链（SeedVR2 修复/超分、LTX-2.5 细节 pass、FILM/RIFE 插帧、H3 FaceRefine、调色）。
- 适用：与既有 C55 H3 本地轨道同源，且是「漫剧装配层」本地新候选（与 C78 Toonflow / C90 LumenX / C96 Jellyfish 并列）。
- 待确认：GitHub 仓库 URL 本次搜索未直接核实，仅 AGI Hunt 报道 → 标注「需用户手动发链接/确认仓库」。

### 1.3【架构范式 / 漫剧参考】Mickmumpitz 模块化电影 ComfyUI 节点包（已核实思路，节点包可装）
- 来源：thedaringcreatives 专访 https://www.thedaringcreatives.com/creator-stories/mickmumpitz-comfyui-workflows；LobeHub 技能库已收录其 `comfyui-character-gen` 节点思路。
- 核心哲学：**「Nothing is baked in」**——每个镜头由可替换参考图层构建（角色参考 / 场景参考 / 声音样本 / 提示词四路输入）；换主角=换参考图重跑一镜，整片围绕新主角重建。自写十几个自定义节点（镜头复制/排序/装配成片/跨镜调色），**ComfyUI Manager 搜 "Mickmumpitz" 一键装**。
- 适用：对我们「漫剧」阶段是直接可借鉴的**架构范式**（工具是消耗品，架构才是资产；一致性=带人工检查步的数据集工程，不是祈祷）。其 9 月初工作流已能 Blender 视口预览动画直接渲染成片+对口型对白同步。

### 1.4【云侧 SOP 细化】Kling 3.0 官方工作流指南（2026-09-07，已核实）
- 来源：Kling AI 官方发布的 newcomers 指南（aib.vote 转述 https://www.aib.vote/en/news/kling-video-3-ai-video-workflow-guide）
- 核心：提示词公式 **「Scene + Subject + Movement + Audio + Style / Emotion / Camera」**；对白写成「"句子" + 情绪 + 语速 + 语调 + 角色标签」；Multi-Shot 由模型规划镜头切换/景别/机位，Custom Multi-Shot 可逐镜控时长；原生音频支持角色专属对白+多语种/方言；并明确**版权提示**（纯 prompt 通常不足以构成版权，需人工剪辑/叙事选择；YouTube 对写实 AI 内容需披露）。
- 适用：细化既有 C77/C95 云侧「桃子带情节」SOP；与 Seedance 2.5 互补（Kling 强在锁角色+音画同步+多镜头，Seedance 强在 30s 原生+局部修复）。

### 1.5【H3 本地部署实务】ComfyUI + MiniMax H3 出有声视频（已核实教程）
- 来源：掘金 https://juejin.cn/post/7682337326150205455 + 多篇 H3 部署文（tzjp 等）
- 核心：H3 模型/节点清单（FL2VA pruned int8_convrot ~19.5G DiT；Qwen3-VL-32B 文本编码器 ~14.6G；视频 VAE ~4.9G + 音频 VAE ~0.6G；Turbo 8-step LoRA）；节点四步地基（Loader→Conditioning→Sampling→Decode）；开源模型对比表（H3 音画同出最强、Wan2.2 纯视觉 Apache2.0 最干净、LTX-2 音画同出但对口型弱于 H3/S2V）。
- 适用：坐实并细化 C55 H3 本地轨道的落地 SOP；与我们 A10 24GB + ≥64GB 内存环境匹配。
