## 1. 新发现：教程 / 工具 / 工作流

### C179 · Lora Character Creator v3.0（Qwen 工作流，出图线 A 角色包量产）【新·零成本·直接服务第一步】
- 来源：https://civitai.com/models/2912213 （2026-09-13，含 SageAttention 加速版）
- 核心要点：用「任意模型生成的 1 张脸图 + 1 张全身图」作输入，Qwen-Image-Edit 自动产出 **48 张一致角色图**（多姿态 / 多服装 / 多表情 / 多构图），可直接用作 **LoRA 训练数据集** 或 多参考图素材。
- 适用场景：正是我们 SOP v2「asset pack 前置（6–10 姿势 + 8–12 表情 + 2–3 背景）」的现成量产工具。比手工一张张出快一个量级，且一致性强。用户本地有 Qwen-Image-Edit 即可零成本跑；无则走 Civitai 在线。
- 落地成本：低（已有 Qwen 出图线）。风险：Civitai 在线版需账号/额度，本地版需 Qwen 权重。收益：高（角色圣经从"手搓"变"一键 48 图"）。

### C180 · Qwen-Image-Edit-2511 + NextScene LoRA 连续式叙事分镜图生图【新·高价值·直接服务「带情节」】
- 来源：https://blog.csdn.net/qq_20288327/article/details/154440563
- 核心要点：一张参考图 + 剧情提示语 → 大模型生成分镜描述 → Qwen-Image-Edit 配合 **NextScene 镜头推进 LoRA + Lightning 风格强化 LoRA** 自动渲染**风格统一、连贯叙事、构图电影感的多张分镜图**；保持人物外观 / 动作 / 光影 / 背景一致。
- 适用场景：把"带情节的视频"往前推一层 —— 不止锁单个角色，而是**直接产出多镜连贯的故事板**，再逐镜喂 LTX I2V 串成视频。这正好补上「桃子第一步」最缺的"情节连贯分镜"环节（之前多在聊单镜 I2V，少有把 Qwen 出图线延伸到叙事分镜的现成工作流）。
- 落地成本：中（需 ComfyUI + Qwen-Image-Edit-2511 + NextScene LoRA 权重，LoRA 需下载）。风险：NextScene LoRA 质量待实跑验证、长序列漂移。收益：高（打通 Qwen出图→叙事分镜→LTX视频 全链路）。
- 注：CSDN 文含「NextScene_lora_v1-3000.safetensors」「Lightning」等具体节点名，动手前须查官方/作者页确认下载与接线（遵守"工具使用前必须官方教程确认"纪律）。

### C181 · Dreamina（Seedance 2.5）新 "Elements" 角色文件夹 + Canvas 画布【新·云侧角色锁强化】
- 来源：https://frontiermodels.cc/video/seedance-2-5-just-got-a-load-of-awesome-new-features （Theoretically Media 实测，2026-09-21）
- 核心要点：Dreamina 新版 Canvas/情绪板系统 + **Elements 文件夹**（可保存"可复用角色 + 自定义嗓音 + 一致角度"，对标 Kling Elements）；平台同时接入 GPT Image 2、Nano Banana Pro、Seed Audio 1.0，并**新增 MiniMax H3 视频生成选项**。
- 适用场景：云侧"带情节"快验 —— 存一次桃子角色（脸+身+嗓音+角度），后续每镜直接调用，比散参考图更稳；配合 Seedance 2.5 30s one-take 讲完一个情节点。H3 选项可作音画一体对照。
- 落地成本：低（平台操作，需用户授权 Seedance/Dreamina 额度）。风险：消耗积分、IP 风险按既有定级（MOU 后恢复云侧快验、成片仍优先本地开源权重）。收益：中高（角色锁 + 嗓音锁一步到位）。

### LTX-2.5 官方 I2V 行为坐实：I2V 提示词"只写运动、重描图内容 = 漂移根因"【纪律证据·进 SOP v2】

- 核心要点：官方/社区工作流明确——I2V 模式下"提示词重述照片已有的服装/发色/光线"会让模型去调和两份略不同的描述，**这正是中段可见漂移的根因**；正确做法是"只描述接下来发生的运动、相机行为、音频"。三种模式 T2V / I2V / FLF2V 节点图已开源可直接下载。
- 适用场景：固化《桃子第一步 SOP v2》"I2V 运动-only 提示词"纪律（之前 C26 备忘已记，今日获官方工作流行为级坐实，非新工具但是强证据）。
