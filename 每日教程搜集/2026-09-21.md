## 1. 新发现（教程 / 工具 / 工作流）

### 1.1 Agnes 免费档坐实 + 零成本漫剧落地（最高杠杆，直接服务「第一步」）
- **来源**：今日头条《我用一个开源项目把〈春晓〉做成了绘本动画，一分钱没花》（toutiao.com/a7685369842722980398）；LocalMiniDrama README（github.com/xuanyustudio/LocalMiniDrama，v1.2.8）
- **核心要点**：
  - Agnes 定价页写明：**agnes-image-2.0 / 2.1 / 2.5-flash 全部分辨率档「currently free」**；**agnes-video-v2.0「currently free」**（常态标价 0.005 美元/秒）。
  - 视频模型能力：图生视频、**首帧 / 首尾帧 / 多帧关键帧**、1080P、**原生音画同步**；接口 OpenAI 兼容，注册拿 Key 即调。
  - **LocalMiniDrama v1.2.8 已原生接入 Agnes AI**：文本/图片/视频一键配置，一个 Key 覆盖全流程（剧本→角色/场景→分镜→视频合成），纯 JS、下载即用、数据不出本机。
  - **Agnes Comic Drama（vvlife/agnes-comic-drama，26★）**：直接基于免费 Agnes API 生成 3–5 分钟漫剧的开源项目。
- **适用场景**：桃子单角色带情节视频的**零成本云快验**（比 Digen 控制力更强——支持首末帧 + 原生音画），以及短剧一站式预演。我们已有 Agnes Key，摩擦极低。
- **注意**：免费档属定价页动态内容，建议用户自行在 Agnes 控制台确认当前仍免费后再批量调用（遵守「真实付费 API 先问后调」硬规则）。

### 1.2 Qwen-Image 2.1 开放权重发布（2026-09-20，出图线 A 本地新候选）
- **来源**：OrcaRouter 对比评测（orcarouter.ai/blog/qwen-image-2-1-vs-qwen-image-3-0）；Qwen 官方时间线
- **核心要点**：
  - **Qwen-Image 2.1 于 2026-09-20 发布，开放权重**，但许可为 **Qwen Research License（仅非商用）**，商用需另签协议。
  - 参数：7B 视觉生成（32 层单流 DiT）+ Qwen3-VL 8B 文本编码器 + 64 通道 RGBA VAE（16× 压缩），原生 2K（2048×2048，40 步），全量下载约 33GB。
  - **Qwen-Image 3.0（2026-07-21 发布）是闭源托管 API**（Pro/Standard），无权重、无技术报告；FairStack 测其 identity consistency 仅 **50%**（角色锁弱于我们的 Qwen-Image-Edit 内置 char_consistency LoRA）。
- **适用场景**：本地出图/编辑的开放权重新选项；但因**非商用许可**与「3.0 角色锁弱」，不切换出图线 A——维持 Qwen-Image-Edit-2511/2512（已有 C129 char_consistency LoRA + C146 三锚点）。仅作「本地可控、非商用实验」记录。

### 1.3 comfyui-auto-drama + MiniMax-H3 Drama 框架（H3 视频线直接可用）
- **来源**：github.com/qiukaihui/comfyui-auto-drama（47★，MIT，2026-08-16）；CSDN《MiniMax H3 本地部署实战》+ 头条《导入直接跑 MiniMax-H3 漫剧完整工作流》
- **核心要点**：
  - **comfyui-auto-drama**：基于 ComfyUI + **MiniMax H3** 的自动化短剧流水线节点包（与我们现有 H3 Ref2VA 出桃子同模型）。
  - **MiniMax-H3 Drama 项目框架**（个人项目 D:\aishipin\minimaxh3，101/101 测试通过）：项目级隔离 pi + ComfyUI + H3，10 个 h3 skills + 9 个 h3_tools，全流程 剧本→分镜→队列提交→自动 QC→FFmpeg 合成 MP4；**「母版.json + 队列 + QC」模式**可直接复用。
  - 实操纪律：参考图 ≤1024、干净立绘比复杂场景稳；SAGE 注意力补丁降显存但大动作可能出雪花噪点；第一集跑顺后 Save(API Format) 存母版，之后只换图/换一句话。
- **适用场景**：桃子下一步多角色、以及「H3 自动化批量出镜」的方法论参考（我们已在用 H3，补「队列 + 母版 + QC」即可提效）。
