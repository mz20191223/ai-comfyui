## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 提示词与参数 cheat sheet 被多源坐实（零成本，直接服务第一步）
- 来源：
  - soloa.ai《LTX-2.5 Prompt Guide 2026》 https://soloa.ai/blog/ltx-2-5-prompt-guide-2026
  - deapi.ai《LTX-2.5 Prompting Guide》 https://deapi.ai/blog/ltx-2-5-prompting-guide-multi-shot-scenes-native-audio-and-prompts-that-actually-cut
  - jamlee.life LTX-2.5 中文解读 http://jamlee.life/archives/6230
- 核心要点：
  - **六要素写成 4–8 句连贯散文**（景别/场景光照/动作/角色/相机运动/音频），严禁标签堆叠（tag stacking 导致动作抽搐、构图泛化）。
  - **多镜 2–4 cuts** 用 `Shot 1… Cut to Shot 2…` 硬切，结尾加一致性从句：`"Preserve character facial structure, outfit, lighting direction, and mood across all cuts."`
  - **参数 cheat sheet**：full 25–35 步 CFG 3.0–4.2 / distilled 8–12 步 / i2v denoise 0.45–0.65（0.45 保源图、0.65 允许形变）/ 时长 auto；负向=blurry, distorted anatomy, warped faces, flickering background。
  - 一句话台词约 2.5 词/秒，10s 片段约 25 词；先低分辨率迭代再升 1080p。
- 适用场景：桃子带情节样片的所有 LTX 本地生成，作为《第一步 SOP v2》参数附录。

### 1.2 Qwen-Image-Edit-2511 角色一致性工作流强化（零成本，强化出图线 A）
- 来源：
  - ik3d《Qwen-Image-Edit Made Character Consistency Free》 https://www.ik3d.fr?p=47858/
  - CSDN《5个Qwen-Image-Edit-2511创意玩法》 https://blog.csdn.net/AmethystFox57/article/details/157127257
  - promptingpixels《Storyboards with Qwen Image Edit + ControlNet + WAN2.2》 https://promptingpixels.com/tutorial/storyboarding
  - compshare Qwen-Image-Edit-2511 WebUI 镜像 https://www.compshare.cn/images/tJS7K3zXNHDt
- 核心要点：
  - 社区 **Consistent Character Creator 3.8** 一键管线：单张肖像 → 转面(turnaround)/表情/服装/姿态包 + 数据集导出，全部同一人。
  - 内置 **LoRA 支持**（强化 C129 内置 char_consistency LoRA）；**Identity Lock 节点**（权重 1.0）绑身份；**Qwen-Image-Layered** 拆 RGBA 图层。
  - 多参考图：Qwen Image Edit 原生支持最多 3 张参考图（角色/场景/物体），与 C121「顺序须与提示词指代一一对应」纪律一致。
- 适用场景：用 CCC3.8 **批量产桃子角色圣经**（转面图+表情包+服装变体），比逐张手调更快更稳，零训练。

### 1.3 Seedance 2.5 I2V 参考系统最佳实践（云快验纪律细化）
- 来源：seedance.tv 官方《Image to Video Complete Guide 2026》 https://www.seedance.tv/blog/seedance-2-5-image-to-video-guide-2026
- 核心要点：
  - 最多 50 参考图，但 **I2V 实战 1–3 张定点最稳**（1 脸 + 1 物 + 1 环境锚），不是越多越好。
  - 常见问题与修复：① 运动过大早失稳 → 加 `slow, subtle`、限定转角如 `turns 30 degrees`；② 相机过猛切掉主体 → 加 `slow/gradual` + `hold on medium`；③ 音频不匹配 → 显式写环境音（café ambient / outdoor wind）；④ 灯光中途漂移 → 写 `constant studio light` / `unchanged window light`；⑤ 背景乱动 → 写 `background remains still`。
  - 竞品对比坐实：Seedance 2.5 I2V 30s/4K/原生音频/50 参考；Kling 3.0 ~10s/1080p/无原生音频；Veo 3 8s/1080p/原生音频。
- 适用场景：桃子云侧 30s 带情节样片（C123 剧作模式 / C134 小云雀入口）的身份锁定纪律。

### 1.4 Wan 2.2 ComfyUI 官方原生工作流（本地「画质优先」备用候选，非主线替代）
- 来源：docs.comfy.org 官方 Wan2.2 教程 https://docs.comfy.org/tutorials/video/wan/wan2_2 ；thundercompute 实测 https://thundercompute.com/blog/wan-2-2-comfyui-ai-video-model
- 核心要点：
  - day-0 原生支持（ComfyUI ≥ v0.3.46）；模板库直接搜 `Wan2.2 5B TI2V / 14B T2V / 14B I2V / FLF2V`。
  - **5B TI2V 模型更轻**，720p/RTX 4090 约 9 分钟/5s；Apache 2.0、**面部/皮肤/头发开源渲染最强**。
  - 提示词框架：相机框定 + 运动描述 + 氛围风格，80–120 词；负向=blurry motion, flickering, morphing faces。
- 适用场景：本地「画质优先/商用友好」备选；A10 24GB 可跑 5B 变体。优先级低于 LTX 主线，待验。
