## 1. 新发现：教程 / 工具 / 工作流

### A. LTX-2.5 官方精修：独立 distilled 模型 + Multimodal Guider + 两阶段管线（🔴 高价值，官方源）
- **来源**：
  - 官方工作流指南 `https://staging.ltx.io/blog/comfyui-workflow-guide`
  - 官方 T2V 新手指南 `https://docs.ltx.io/open-source-model/usage-guides/text-to-video`
  - ComfyUI Wiki 发布汇总 `https://comfyui-wiki.com/en/news/2026-08-11-ltx-2-5-open-weights-release`
  - LoRA 适配器开发者指南 `https://staging.ltx.io/blog/using-lora-adapters`
- **核心要点**：
  1. **独立 distilled 模型**：`ltx-2.5-22b-distilled-transformer-bf16.safetensors` 可直接加载（不再需要「dev + distilled-lora-450」叠加），4–8 步 + 手动 sigma schedule 出片，A10 摩擦更低。GGUF 仍可用 realrebelai/Abiray/VantageAI 的 Q3_K_M~10.7GiB / Q4_K_M~15.1GiB。
  2. **Multimodal Guider 节点**：把原来单一 CFG 拆成 **Prompt Adherence（CFG，锁提示词符合度）** 与 **Cross-modal Sync（STG，跨帧/跨模态一致性）** 独立可调，且视频流与音频流分别控制。抖动/时序伪影 → 提 Cross-modal Sync；不跟提示词 → 提 Prompt Adherence；两者不要同时拉满。
  3. **两阶段管线坐实**：Stage1 在基础分辨率同时出视频+音频 → 2× 空间上采样 → Stage2 精修。默认 768×512 基础 → 最终 1536×1024。默认负向词 `pc game, console game, video game, cartoon, childish, ugly`（会自动施加，注意别把"卡通/动漫"风格也误杀）。
  4. **LoRA 三类**（官方）：Standard（主体/风格/动作）、Audio-Video（嗓音+声学联合）、IC-LoRA（Union Control=Canny+Depth+Pose 合体 / Pose Control=动作迁移+跨镜一致 / Detailer=细节增强）。IC-LoRA 仅兼容 distilled 检查点 + `ICLoraPipeline`。视频域角色/风格 LoRA 训练：20–30 张高质量参考图 + 500–2000 步（官方 trainer）。
- **适用场景**：桃子视频阶段本体。独立 distilled + Multimodal Guider 是「今天就能降摩擦」的升级；Pose Control + 视频域角色 LoRA 是 Step2/3（多角色/漫剧）身份锁的正规军路径。

### B. Qwen-Image-Edit-2512 角色圣经强化：单图变法→训 LoRA（🟢 出图线 A 补强，可落地）
- **来源**：
  - 真实人物 Character LoRA 训练全流程 `http://apatero.com/blog/qwen-image-2512-character-lora-training-real-people-guide-2025`
  - CSDN 实操：`enable_consistency` 隐藏开关 + CFGNorm 预置节点 `https://blog.csdn.net/weixin_42163404/article/details/157498540`
  - 官方站 `http://qw-image.com/`（action+target+constraints 提示词范式、多图融合、Character_Seed_Lock 思路）
- **核心要点**：
  1. **从单张参考生成 30–50 变体**（不同姿态/场景但同身份基底），过滤后作为 LoRA 训练集 —— 比网上乱爬图干净，身份基线一致。caption 用触发词 `sks_xxx` / `ohwx xxx`；musubi-tuner 配置 `dim32/alpha16`、`resolution 1024`、`lr 1e-4`、`max_epochs 10`。**关键纪律：训练分辨率 = 出图分辨率（1024×1024），否则质量掉。**
  2. `enable_consistency`（QwenImageEditPlus 节点隐藏勾选，激活后节点右上角出现 ★）强制编辑不同区域时保持材质/光照/透视一致；`CFGNorm` 节点预置、2512 默认启用，治「文字生硬/擦除露边/替换违和」。
  3. 2512 对中文指令理解成熟，但避免抽象词；「保持原图光影层次」是 2512 新增语义锚定指令。
- **适用场景**：桃子角色圣经（出图线 A）的**零训练兜底 + 训练增强双轨**。当社区 `Character-2512 LoRA` / `Character_Seed_Lock` 不够用时，自训一个桃子专属 LoRA。

### C. Wan-Animate-2 实操固化（🟡 Step2/3 动作迁移，需先备驱动视频）
- **来源**：
  - 官方 ComfyUI 教程（中文）`https://www.seedance.tv/zh/blog/wan-animate-2-tutorial`
  - CSDN 整合包 `https://blog.csdn.net/yihuaixu/article/details/163591600`
  - RunComfy 工作流 `https://www.runcomfy.com/comfyui-workflows/wan-animate-2-comfyui-identity-preserving-motion-transfer`
  - 完整指南 `https://poyo.ai/en/hub/wan-animate-2-complete-guide`
- **核心要点**：
  1. **两模式**：Move（让参考图角色"演"驱动视频的动作，干净背景）/ Mix（替换原视频里的人，保留场景/运镜/道具）。
  2. **核心节点**：`WanAnimate2ToVideo` + `WanAnimate2Cache`（缓存可降约一半耗时，长镜头放 CPU 防显存尖峰）。int8 convrot 包（`wan_animate_2_int8_convrot.safetensors`）为 ComfyUI 低显存实用档，A10 量化可跑；BF16 完整档仅大显存。
  3. **输入纪律**：参考图无遮挡、构图与驱动视频匹配（特写对特写/全身对全身）；主提示词只写外观+背景、motion 提示词只写动作；81 帧窗口 ≈ 3.4s@24fps，长驱动视频需串联 `continue_motion`（传上一段末帧）+ `video_frame_offset`。
  4. **硬前置**：必须先有一段驱动视频（真人/动画/动捕均可）。这是与 LTX-2.5「文字直接出」最大的区别。
- **适用场景**：桃子**已有静帧**后想做复杂动作/舞蹈/打斗（多角色/漫剧阶段）。本地可控，但比 LTX-2.5 多一个"备驱动视频"环节。

### D. 闭源商业范式坐实：参考锁角色 = 2026 主流，Sora 退役（🟢 方向验证，不落地）
- **来源**：
  - 横评 `https://aistackdigest.com/ai-video-tools/runway-gen4-kling-3-luma-ray3-2-character-consistency-ai-video-2026`
  - 新加坡 AI 电影工具盘点 `https://aistudio.com.sg/blog/ai-movie-singapore-2026-complete-guide.html`
  - 工具榜 `https://ailove.ai/blog/ai-video-generation-tools`
- **核心要点**：
  1. **Runway Gen-4「World Consistency」**：单张参考图零样本跨场景锁身份（厨房→森林→太空舱同一人），一致性标称 96%。
  2. **Kling 3.0「SoulID / Anchor-Frame」**：高清锚帧 + i2v，物理/布料/头发更真，标称 98%，成本最低，长镜/极端角度漂移快。
  3. **Luma Ray3.2**：锁首/尾帧插值，帧级可编辑。
  4. **Gemini Omni（2026-05）**：`@character_name` 跨镜复用角色，原生音频 ~10s。
  5. **Sora 已于 2026-08 退役**（EOL），行业顶流变为 Gemini Omni / Kling 3.0 Omni / Seedance 2.5（+ Veo 3.1 次级）。
- **适用场景 / 我们的判断**：这些全为**闭源商业、非本地、且多为国外服务**（IP/出境/合规风险），**不进本地主线**；但它们一致把「参考图锁角色」确立为 2026 生产级范式 —— 与我们 LTX-2.5（IC-LoRA/Pose Control + 视频域角色 LoRA）+ Qwen（图像锁角色）的路线**同构**，方向被强验证，无需调整。

## 3. 及时调整建议

**🔴 不替换基线。** 今日资料全部与 v4 基线同向，无更优可替代项。但有三处**应立刻 fold 进现有做法的精修**（零/低成本增益）：

1. **视频阶段改用「独立 distilled 模型」接管旧「dev+distilled-lora」心智模型**：直接下 `ltx-2.5-22b-distilled-transformer-bf16`（或继续用 GGUF Q4_K_M），4–8 步出片；引入 **Multimodal Guider** 把 CFG/STG 分开调（漂移→提 Cross-modal Sync，不跟词→提 Prompt Adherence）。→ 替换的是"我们对 LTX-2.5 内部参数的理解"，不是替换工具链。
2. **出图线 A 加「自训桃子 LoRA」作为社区 Character-2512 LoRA 的兜底**：社区 LoRA 万一脸松/不够，用 Qwen 单图变法生成 30–50 变体 → musubi-tuner 训一个 `sks_taozi` 专属 LoRA（dim32/alpha16/1024）。→ 替换的是"角色圣经只有一条路"的风险。
3. **桃子第一步云快验优先用国内即梦/可灵**：中文审美 + 角色库开关 + 一站式，比调 API 更快看到"桃子故事成不成立"；IP 风险照记，不进本地主线。

**🟡 暂不改**：Wan-Animate-2 维持预研（需驱动视频，第一步非必需）；闭源商业不落地；Wan 3.0 / H3 / FLUX 3 维持云补镜候选。
