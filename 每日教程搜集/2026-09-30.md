## 1. 新发现：教程 / 工具 / 工作流

### 1.1 LTX-2.5 官方 ComfyUI 原生工作流坐实（官方文档）
- 来源：https://docs.comfy.org/zh/tutorials/video/ltx/ltx-2-5 （ComfyUI 官方教程，今日复核）
- 核心要点：
  - 官方内置三套原生工作流：**T2V / I2V / FLF2V**（首尾帧插值），均原生支持同步音频 + 原生 multishot（一次生成多镜、跨切保持角色/环境/光影/声音/风格一致）。
  - 模型集（gated，需 HF `Lightricks/LTX-2.5` 门控）：`ltx-2.5-22b-distilled-transformer-comfy-int8-convrot` + `gemma4-12b-with-proj-ltx-2.5-comfy-int8-convrot` + video-vae/audio-vae + latent-spatial-upscaler-x2。
  - **提示词铁律（官方明确）**：I2V「只写输入图像之后发生的运动/相机/声音，不要重复描述画面已可见内容；用『将提供的起始图像作为第一帧』锚定」。这正是我们 SOP v2 的「运动-only」纪律被官方点名。
  - multishot 用时间顺序散文 + 命名切法（"A hard cut transitions to a close-up…"）写多镜。
- 适用场景：本地主线「Qwen 出图 → LTX I2V 带情节」标准化模板，零成本。把社区猜测变官方标准动作，直接固化进《桃子第一步 SOP v2》。

### 1.2 reventadirecta/LTX-2.5-I2V-8GB-VRAM —— 完整可抄的本地 I2V 工作流（NEW·零成本·最高优先）
- 来源：GitHub `reventadirecta/LTX-2.5-I2V-8GB-VRAM`（AGI Hunt 报道：https://agihunt.info/en/e/1a06f427ef50eb8d123c85a9354 ）
- 核心要点：
  - Reddit 用户在 **RTX 4060 Laptop 8GB** 跑通 LTX-2.5 22B Distilled I2V，开源**完整 ComfyUI 工作流 JSON + 模型清单 + 排障说明**。
  - 技术栈：W4A8 ConvRot 量化 transformer + Gemma 12B W4A8 文本编码器 + 官方 BF16 video VAE + DynamicVRAM（活跃层进 GPU、其余放内存 offload）+ 异步权重卸载 + pinned memory。
  - 实测：576×1024 / 24fps / 约 10s 稳定生成，身份稳定、背景几何一致、无彩虹崩坏、10s 内无渐进劣化；720×1280 为 8GB 上质量/时间最佳折中。
  - **关键坑**：`--fp16-vae` 输出黑屏，改用 `--bf16-vae` 解决（印证我们 C184 结论）。
  - 作者在探 **6 keyframes + 5 prompts** 长序列执导（与 C102 思路一致）。
- 适用场景：**我们 A10 24GB 远超 8GB 需求，直接可跑且余量充足**。这是比 C184（概念验证）更完整的「现成模板」，桃子「Qwen 角色静帧 → LTX I2V 带情节单镜」第一步最高优先直接抄。
- 编号：**C191（新候选，待用户实跑）**。

### 1.3 Netflix / Eyeline Labs ID-V2V —— 身份保留视频重风格化（NEW·方法论增量·最该进「调整建议」）
- 来源：GitHub `Eyeline-Labs/ID-V2V`（AGI Hunt / ai-primer / note.com 多源；论文 SIGGRAPH Asia 2026，Apache 2.0）
- 核心要点：
  - 基于 **Wan 2.1 + VACE** 的两个微调 checkpoint（Apache 2.0，商用安全）：`idv2v.pth`（SAM3 分割前景于灰底、重打光并保留主体，其余按 prompt 重生）+ `idv2v_with_normal_depth.pth`（加 DAViD 法线 + DepthAnything-V2 深度，几何更紧）。
  - **核心范式「shoot first, restyle later」**：输入 = 一段源视频 + 一帧风格化关键帧（可加文本 prompt）。保留人物的**身份、表情、视线、动作、口型**，**只换场景 / 光照 / 风格**。
  - 实测亮点：① 编辑过的 keyframe 不必精确匹配演员姿态（Frame 0 可以错，Frame 1 起自动 snap 回源表演）；② 支持 relighting（换光不需 SAM3 预处理）；③ 720p 输出，重叠 **81 帧**拼接成更长视频；④ 坏关键帧也能自动校正。
- 适用场景：**直接服务桃子「带情节 = 多场景但必须同一张脸」的痛点**。新做法：先用任意模型（LTX / Digen / Agnes）生成「表演正确」的基片（哪怕场景是灰棚/占位），再用 ID-V2V 把场景/光/风格换掉且保脸保口型。比「每段都靠 LTX 原生多镜硬扛跨场景一致」更省、更稳。
- 编号：**C192（新候选，待用户实跑）**。注：基于 Wan 2.1（Apache 2.0），我们已有 Wan 2.2 画质备用（同为 Apache 2.0），可平滑迁；需确认 ID-V2V 权重能否直接吃 Wan 2.2 底座（待核实，先用 2.1 稳妥）。

### 1.4 SparkDiffusion —— Wan2.1/2.2 统一加速框架（NEW·本地提速·待核实 A10 适配）
- 来源：GitHub `AlibabaResearch/SparkDiffusion`（北大+清华+阿里，完全开源：权重+训练码+推理脚本）
- 核心要点：
  - 首个整合「稀疏注意力 + 少步蒸馏 + FP8 量化」的端到端框架，专治 DiT 视频生成注意力 O(L²) 瓶颈。
  - 实测：RTX **5090** 单卡 720p-14B **265× 加速**（5s 视频 18s 出）；H100 220×；VBench-2.0 仅降 0.5 点（60.2→59.77）。
  - 跨模型支持 **Wan2.1 / Wan2.2，T2V / I2V，480p / 720p**。
- 适用场景：本地 **Wan 2.2 TI2V-5B（我们画质备用）** 提速——若能在 A10 落地，可大幅缩短 Wan2.2 出片时间。
- 风险/待核实：**FP8 量化在 A10（Ampere）原生支持存疑**（FP8 主要 Ada/Hopper），A10 可能退化到 FP16 路径、加速比打折；且是研究框架、集成进 ComfyUI 工作量不小。编号：**C193（新候选，跟踪·不立即做）**。

### 1.5 LTX-2.5 vs MiniMax H3 实测对比（强化基线分工证据）
- 来源：https://www.mindtheory.sg/comfyui-video-training-ltx-minimax （Mind Theory 创意课程实录）
- 核心要点：同一张产品图给两模型同指令——**LTX-2.5 紧贴原帧、脸一致、相机不动、产品标签可读**（锁角色/产品最安全）；**H3 把每个 beat 都演出来**（看产品→笑→回看镜头，表演更完整但标签会转走）。教学强调「把方向写成按时序的 beats（0–2s 做什么、峰值保持什么、如何收尾）」。
- 适用场景：再次印证我们「LTX 锁角色主线 + H3 补表演」的分工，无需调整。beats 写法进 SOP v2 证据。

## 3. 及时调整建议（增量非推翻）

1. **第一步 I2V 模板升级**：直接采用 `reventadirecta/LTX-2.5-I2V-8GB-VRAM` 现成工作流（C191）作为桃子「Qwen 角色静帧 → LTX I2V 带情节单镜」标准起点，**替换「自己从零搭 LTX I2V 节点」**。A10 24GB 远超其 8GB 设计，余量充足；若 LTX-2.5 HF 门控仍未批，走 C169 LTX-2.3 GGUF 等价路径。
2. **新增「ID-V2V 后处理换景」进入带情节工具箱（C192）**：桃子需要「在不同场景里动且同一张脸」时，不必每段都靠 LTX 原生 multishot 硬扛跨场景一致——改为 **先出表演基片（LTX/Digen/Agnes，场景可用灰棚/占位）→ ID-V2V 换场景/光/风格且保脸保口型**。这是今天最该执行的**做法调整**（不改变「Qwen 出图→LTX 视频」主线，只在「多场景连贯」环节加一道后处理）。
3. **SOP v2 补强（零成本证据）**：① 官方 I2V「只写运动不写内容 + 锚定首帧」铁律（1.1）；② beats 时序写法（1.5）；③ 把 C191 工作流 + C192 后处理换景写进 SOP。
4. **出图线 A 不切换**：维持 Qwen-Image-Edit 2511/2512 + 三锚点（C146）+ char_consistency LoRA（C129）；2509-Lightning 仅作加速变体参考。
5. **本地 Wan2.2 提速标记为跟踪**：C193 SparkDiffusion 先核实 A10(Ampere) FP8 适配与集成成本，不立即做。
6. **基线全维持**：LTX 主线 / Qwen 出图 / Digen 单镜快验 / Agnes 免费档 / Seedance 剧作模式 / Kling 3.0 Omni / H3 补表演 / Wan 2.2 画质备用 / HunyuanVideo-1.5 运动备用 —— 全部维持。SkyReels-V4 跟踪勿追。
