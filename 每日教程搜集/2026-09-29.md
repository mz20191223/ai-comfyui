## 1. 新发现：教程 / 工具 / 工作流

### 1.1 【本地主线·强相关·新工具】ComfyUI-LTX2.5-MSR + LiconStudio「LTX-2.5-Multiple-Subject-Reference」LoRA（C189）
- **来源**：infernews 实测文 `https://infernews.com/blog/comfyui-ltx2-5-msr-standalone-multi-reference-image-conditioning`；LoRA 模型卡 `https://huggingface.co/LiconStudio/LTX-2.5-Multiple-Subject-Reference`；LTX 官方 issue #320 `https://github.com/Lightricks/LTX-2/issues/320`
- **核心要点**：
  - **MSR（Multiple Subject Reference）LoRA**：把**最多 5 张独立编码的参考图**（人物 / 服装 / 道具 / 背景）一次性注入视频 latent，每张图带 learned slot embedding + 固定排序 + 连续负时间位置，让 LTX-2.5 的 self-attention 直接读取多主体信息——**不是简单拼图**。
  - **AVref LoRA（声音参考）**：可再为**最多 2 位说话者**绑定声音参考（audio latent 配对 pic1/pic2，稀疏 slot 保留绝对时间位置，缺声不平移后续参考）。
  - 插件 `ComfyUI-LTX2.5-MSR`（ComfyUI 自定义节点，v1.2.2 把图/声参考集中到一个 LoRA loader + Reference Guide；提供 V2 两阶段 sampling + latent-upscale 示例工作流）。
  - **关键校准（来自官方 issue #320，真实用户 16GB RTX 5070Ti 实测）**：1–2 个参考角色时 MSR「几乎完美」（身份/发型/空间位置/对白分配/口型都对）；**加到第 3 个角色时可靠性骤降**（身份互渗、克隆、错人说话、口型串台）。即 MSR 的实用上限是 **2 主体对话**。
- **适用场景**：① 第一步桃子单角色——可把「角色+服装+道具+背景」一次性多参考注入，比逐镜单 I2V chaining 更稳；② 下一步多角色——**2 角色场景首选本地方案**；③ AVref 直接服务「带对白/声音」诉求。
- **硬前提**：**必须 LTX-2.5**（仍 gated，docs.comfy.org 今日再次确认需申请访问）。LoRA 必须含 `reference_slot_embedding` 权重，普通 LoRA 会被拒。

### 1.2 【本地主线·LTX-2.5 LoRA 工具箱】Creative Lab 适配器家族（C190）
- **来源**：`https://www.stablediffusiontutorials.com/2026/08/ltx-2-5-lora-models.html`
- **核心要点**（与桃子相关的几个）：

  - **LTX-2.5 Multi-Subject Reference LoRA**：即 C189 同款 MSR。
  - **IC-LoRA Reference sheet control**（= Ingredients 思路，C133/C160 已索引，现确认更广泛可用）：单张 reference sheet 控角色/道具/场景。

- **适用场景**：C189 获批后配套使用；x Z-Image 是桃子「一步出带口型对白」的本地方向候选。

### 1.3 【纪律再印证·零成本】单角色一致性的 2026 主流做法收敛（强化 SOP v2）
- **来源**：designerbox `https://designerbox.ai/blog/how-to-keep-characters-consistent-in-ai-video`；imageat `https://imageat.com/blog/how-to-keep-same-character-ai-images-videos`；lollipop `https://www.lollipop.im/blog/mastering-character-consistency-ai-video`；picazo `https://www.pixazo.ai/blog/best-consistent-character-video-generators`
- **核心要点（与现有 C98/C107/C128 一致，新增可吸收点）**：
  - **imageat 风险分级**（低/中/高风险运动）：低风险=呼吸/眨眼/微表情/小幅转头/慢推；中风险=大转头/手部动作/走一步；高风险=整圈旋转/侧脸转正面/手遮脸/奔跑冲镜/极端表情/大环绕。**建议把此分级直接折进 SOP v2 的「逐镜风险自评」**。
  - **I2V 锚定 > 文本锚定**：先定稿首帧图再 I2V，运动提示词只写「变了什么」，不重写画面——与 C181（LTX 官方「重描图=漂移根因」）完全互证。
  - **末帧 chaining + 锁 seed + 冻结身份半句提示词**（只改场景/动作/相机）——多源一致。
  - **ControlNet / FaceID / InstantID** 仅作漂移补网（高级），非第一步必需。
