## 1. 新发现：教程 / 工具 / 工作流

### 1.1 🔥【最相关】"Grid Method"（Qwen Image Edit + LTX）多镜头一致性出图法
- 来源：https://frontiermodels.cc/video/perfect-character-consistency-in-ai-video-the-grid-method-with-qwen-ltx-two （2026-01，Mandarin 实战讲解）
- 核心要点：
  - 用 **Qwen Image Edit 2512**（作者强调**不是 2511/Plus**，后者多宫格布局明显更弱）在**单张图里一次性生成 4 个分镜格（1440×720）**，所有镜头共用一次采样 → 角色/场景天然一致（比"参考图法"更稳，尤其开源模型）。
  - 用 **Unblur Anything LoRA**（兼容 Qwen 2509/2511/2512）把每格放大到 1920×1080，找回共享分辨率时被吃掉的脸部细节。
  - 每格放大图 → 喂入 **低显存 LTX Two GGUF** 工作流出 1280×720 视频片段。
  - 踩坑：Kijai 新版 VAE 在该管线会出灰/损坏，须用**旧版 VAE**。
  - 工作流在 RunningHub 可取。
- 适用场景：**正好命中我们"Qwen 出图 + LTX 出视频"基线，且直接解决第一步"单角色多镜头叙事一致"与最终"漫剧"两阶段**。

### 1.2 Create Coherent Scenes（Qwen Image Edit + Wan 2.2）电影化连贯工作流
- 来源：https://www.runcomfy.com/zh-CN/comfyui-workflows/create-coherent-scenes-qwen-image-edit-wan-2-2-in-comfyui-cinematic-coherence-workflow
- 核心要点：Qwen Image Edit 出连贯关键帧（后续镜头以"上一镜图像"为条件，锁定身份/服装/灯光）→ Wan 2.2 14B 图生视频（高/低噪变体 + Light X2V LoRA）逐镜动画 → 拼接 + 帧插值 + Huan Video Foley 音效。提供**低显存 GGUF + block swap** 路线。
- 适用场景：**视频阶段换/补 Wan 2.2 的备选方案**（Wan 2.2 I2V 被多家评为开源里对"角色参考图"支持最好的）。需 24GB 显卡。

### 1.3 LTX 2.3 多场景电影工作流（Movie Builder / Director / Digital Human）
- 来源：
  - Movie Builder：https://www.runcomfy.com/comfyui-workflows/ltx-2-3-movie-builder-workflow-in-comfyui-multi-scene-ai-filmmaking
  - Director（时间线）：https://www.runcomfy.com/comfyui-workflows/ltx-2-3-director-in-comfyui-timeline-ai-filmmaking-workflow
  - Digital Human：https://ltxworkflow.com/resources/tutorials/ltx-23-digital-human-workflow-comfyui
  - 节点库（MIT）：https://github.com/mickmumpitz/ComfyUI-Mickmumpitz-Nodes
- 核心要点：
  - **Movie Builder** 用 `[VISUAL]/[SPEECH]/[SOUNDS]` 提示词结构；含 Shot Assembler（镜头拼接）、ColorMatch（跨镜色彩统一）、LTX‑2.3 ID LoRA（锁角色）、参考音频对口型。
  - **Director** 时间线式多镜：Stage1 预览 → Stage2 上采样精修，支持 LTXDirector 全局/局部提示。
  - **Digital Human** 强调：参考图条件 + ControlNet 姿态 + LoRA 风格 + 同 seed，保证多镜一致。
  - Mickmumpitz 节点含 Consistent Character Creator、迭代视频、镜头拼接等实用节点。
- 适用场景：**第一步的"分镜组装/成片"与最终"漫剧"** 直接可用，且与我们 LTX 主线同源。

### 1.4 "Last Frame Continuity" 链式拼接（低显存做长叙事）
- 来源：https://civitai.com/articles/30897
- 核心要点：把片段 A 的**最后一帧**作为片段 B 的**首帧**输入，单 ComfyUI 运行中链式生成无缝长视频；对抗漂移靠"在后续片段提示里**重申主体描述** + 复用同 seed"。作者 10GB 显存跑通。
- 适用场景：**第一步里把桃子单镜头拼成 15–20s 连贯小情节**，低显存友好，与 LTX 基线契合。
