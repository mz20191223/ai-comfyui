## 1. 新发现：教程 / 工具 / 工作流

### 1.1 🆕【重大·可能改变视频主线】Wan 2.7 —— 开源「多参考帧一致性」模型（2026-03 发布）
- 来源：
  - studiolist.co 深度指南：https://studiolist.co/guides/wan-2-7-multi-shot-character-consistency
  - dev.nemovideo.ai 本地部署：https://dev.nemovideo.ai/blog/run-wan-2-7-locally-comfyui-setup
  - wan27.org 开源与中文教程：http://wan27.org/blog/wan-2-7-open-source-guide 、https://wan27.org/zh/blog/wan-2-7-image-edit-comfyui
- **核心要点**：Wan 2.7（MoE 14B，训练于 15 亿视频）是**首个认真解决多镜一致性的开源视频模型**：
  - **9-grid 图生视频（I2V）**：一次喂 9 张参考图，跨序列保持身份。
  - **150+ 参考帧一致性**：可在多次生成间锁定面部结构/服装/身材比例/光照连续性（3 张是底线，9 张覆盖多数角度，专业用 50+）。
  - **原生音频**：同步生成音视频（加入 Kling 3.0 / Veo 3.1 的「原生音频俱乐部」）。
  - **NVFP4 量化**：官方称可在低配硬件以 **60% 更少显存**运行 → **24GB 卡（我们的 A10）可跑**；也有 GGUF 社区量化版。
  - ComfyUI 接入：`kijai/ComfyUI-WanVideoWrapper`（核心节点 WanVideoModelLoader / TextEncode / Sampler / Decoder）；或 Wan 官方节点。文本编码器为 **UMT5-XXL**（与 LTX 的 Gemma 3 不同）。
  - 硬件实测：RTX 4090（24GB）FP8 跑 5s/720p 约 2–4 分钟；云 API（阿里云 / fal.ai / Atlas）可免硬件。
- **适用场景**：**直击「下一步多角色」「最终漫剧」的多镜叙事一致性**——这是它相对 LTX 2.3（仅首帧条件 + 外部锚点 hack）的架构级优势。对「第一步单角色叙事」同样适用且可能更稳。

### 1.2 🆕 LTX 2.3 官方模型文件清单 + 两阶段管线（坐实下载细节）
- 来源：docs.ltx.io I2V 教程：https://docs.ltx.io/open-source-model/usage-guides/image-to-video ；docs.ltx.video ComfyUI：https://docs.ltx.video/open-source-model/integration-tools/comfy-ui
- **四个模型文件（约 28GB 总下载，仅一次）**：
  - `ltx-2.3-22b-dev-fp8.safetensors`（FP8 主权重，约 22GB → **A10 24GB 正好**）
  - `ltx-2.3-22b-distilled-lora-384.safetensors`（蒸馏 LoRA，加速/稳定）
  - `gemma_3_12B_it_fp4_mixed.safetensors`（**文本编码器是 Gemma 3 12B 的 FP4 混合量化**，比纯 12B 小很多，不是之前笼统说的 12B）
  - `ltx-2.3-spatial-upscaler-x2-1.1.safetensors`（空间超分 2x）
- **两阶段管线**：Stage1 半分辨率（默认 640×360）8 步，源图以 strength 0.7 注入；空间超分至全分辨率；Stage2 全分辨率 3 步，源图以 strength 1.0 重新注入保细节；**音频在 Stage1 与视频联合生成并贯穿输出**。
- 帧数规则：(frames-1) % 8 == 0，即 9/17/25/…/97/121/145…；尺寸须 32 的倍数。

### 1.3 🆕 LTX 2.3 ID-LoRA —— 身份锁定的「正规军」实现（比 Likeness Guide 更严谨）
- 来源：GitHub princetrunks/ID-LoRA-LTX2.3-ComfyUI：https://github.com/princetrunks/ID-LoRA-LTX2.3-ComfyUI （arXiv 2603.10256，ID-LoRA: Identity-Driven Audio-Video Personalization with In-Context LoRA）
- **核心要点**：把「参考肖像 + 参考音频」转成身份条件，**无需训练**，直接控制 LTX 2.3 的口型/身份。节点：`IDLoraModelLoader` / `IDLoraPromptEncoder` / `IDLoraOneStageSampler` / `IDLoraTwoStageSampler`。提供 one-stage / two-stage 工作流模板与示例。
- **量化建议**：int8 是质量/显存平衡点；fp8 更省显存但伪影更多。降显存组合：int8 + max_resolution=512 + one-stage 可在 24GB 跑。
- **与 frontiermodels 的 Likeness Guide 关系**：Likeness Guide 是「轻量潜空间锚点」思路；ID-LoRA 是论文级「In-Context LoRA 身份个性化」。**两者可并存**，优先试 ID-LoRA（更可控），Likeness Guide 作补充锚点。

### 1.4 🆕 10S-Comfy-nodes —— LTX2 稳定性补丁包
- 来源：GitHub TenStrip/10S-Comfy-nodes：https://sota.jiqizhixin.com/project/10s-comfy-nodes （仓库 https://github.com/TenStrip/10S-Comfy-nodes.git）
- **核心要点**：专为 LTX2/LTX-AV 双流音视频 DiT 设计，基于 PyTorch 前向钩子，**无需重训**。解决：身份保留、潜空间稳定、超分阶段色调偏移、音视频对齐。`LTX Tiled Sampler` 是 `SamplerCustomAdvanced` 的分块替换，直接修超分阶段的色偏/条件漂移。可选装 MediaPipe 提升人脸检测。
- **适用**：与 1.3 搭配，提升 LTX 2.3 成片稳定性（尤其超分后色偏、口型对齐）。

### 2.2 关键风险（必须正视）
- **LTX 2.3 文本编码器是 Gemma 3 12B FP4 混合量化**（非纯 12B、非 Qwen 的 qwen_2.5_vl）；单独下、放 `text_encoders/`，别和出图权重混。
- **A10 24GB 跑 LTX 2.3 FP8**：FP8 主权重约 22GB + 文本编码器 + 工作显存≈临界；优先 one-stage 或 ID-LoRA int8 + max_resolution=512 控显存。T4 15.9GB 仅能 INT4/小分辨率兜底。
- **Qwen-Image-Edit 误用**：绝不拿它做跨对象变换（桃子→蘑菇）；那是能力边界外。跨对象创意走 Qwen base T2I。
- **Wan 2.7 与 LTX 不共用文本编码器/节点**：引入 Wan 需独立模型（UMT5-XXL）+ WanVideoWrapper，与现有 LTX 环境并存但占用额外磁盘/显存，先评估再决定迁移。
- **Seedance 2.5 API**：走即梦/火山属第三方，注意额度/限流；仅作验证渠道，不进主线。
