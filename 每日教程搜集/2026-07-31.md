### 1.2 🆕 LTX 2.3「All-in-One」一体化工作流（Civitai, v2.0）—— Director + ID LoRA + ControlNet + Upscaler 一站
- 来源：Civitai `LTX2.3 All in one` https://civitai.red/models/2553704/ltx23-all-in-one-sfw-nsfw-ltx-director-id-lora-controlnet-detailer-upscaler-interpolator （作者定期更新，2026-07-15 仍可跑 10Eros）。
- **核心要点**：把 07-30 分散讲的 Director / ID LoRA / ControlNet / Detailer / Upscaler / Interpolator **打包成一个 JSON**，提供 3 个版本随实例选：
  - `LTX23Legacy.json`（无 Director，手动流）/ `LTX23LTXDirector13.json`（Director v1.3）/ `LTX23LTXDirector2.json`（Director v2.0）。
  - 支持模型：Standard LTX 2.3 / Distilled / **Distilled GGUF** / 10Eros（我们 SFW 用 Standard 或 Distilled，避开 10Eros）。
  - **⭐ 关键纪律（作者原话）**：「Always use **2 phase sampling (half res + 2x upscaler)**，this yields the best quality and character consistency. **LTX is not good at all at preserving character ID**, so don't make it worse by doing a single pass generation.」—— 与我们 07-29 的 draft-then-upscale 完全一致，且**诚实点出 LTX 保 ID 弱**，印证「视频身份锁必须靠 IC-LoRA/参考表，不能只靠 I2V」。
  - 升级点：Prompt Relay、8 个关键帧（原更少）、智能放大（所有关键帧当参考）。
- **适用**：想「一次装好全套」时的**开箱一体化方案**，可作我们自搭 Director 链的对照/兜底；但 NSFW 站点、含多余模型组，建议只取 Director2 + ID LoRA 部分。

### 1.3 🆕 IC-LoRA-Ingredients 精炼堆栈（修正 07-29 参数）—— Distilled 0.6 / IC-LoRA 1.4 / VBBR 0.7 + NAG + MelBandRoFormer
- 来源：aistudynow 实战 https://aistudynow.com/how-to-keep-characters-consistent-in-ltx-2-3-ic-lora-ingredients （2026-06-24，实测）。
- **要点（对 07-29 的修正 / 细化）**：
  - **LoRA 三件套正确叠法**（Dev FP8 基座）：
    1. **Distilled LoRA strength = 0.6（不是 1.0！）**——速度 LoRA 太强会忽略脸参考表、把角色搞坏；0.6 护脸。
    2. **IC-LoRA-Ingredients strength = 1.4**（官方推荐，最佳贴合参考表）。
    3. **VBVR LoRA strength = 0.7**——修重力/物理（漂浮、不自然运动）。
  - **⚠️ 两条推理路径（务必分清）**：
    - **Distilled 路径**：CFG=1 + **必须加 NAG 节点**（否则忽略反向提示）；快、省步。
    - **Dev 路径**：CFG=4.0 / steps 30（即 07-29 记的 `strength 1.4 / steps 30 / CFG 4.0 / 768×448 121f 24fps`）——慢但更可控。
    - 我们 07-29 的 CFG 4.0 是 Dev 路径；若走蒸馏提效，须改用 Distilled 0.6 + NAG。
  - **音频更干净 → 口型更好**：生成音频用 **MelBandRoFormer sampler** 节点。
  - **参考表提示词公式**（铁律）：开头 `reference: ` 逐条描述参考表每个面板细节（脸/衣/道具/背景）→ 换行 `Generated video: ` 描述动作并**复述参考表的衣服**保一致。
  - **续场不漂**：参考表与 `reference:` 提示词不动，只改写 `Generated video:` 即可无缝续到新场景。
- **适用**：**视频身份锁正规军的标准参数**，替换 07-29 的简版；第一步桃子带情节单镜用它锁脸/衣。

### 1.7 🆕 LTX Trainer ID-LoRA 训练参数澄清（rank 128 / 4090 24GB 可跑）—— 服务「长期锁身份」
- 来源：crepal.ai 指南 https://crepal.ai/blog/aivideo/ltx-2-3-ic-lora-guide/ ；sohu.com《LTX Trainer 本地定制》https://m.sohu.com/a/1038020746_122413774 。
- **要点**：
  - **ID-LoRA（身份锁）训练**：rank **128**、**4000–6000 步**（标准 LoRA 仅 1000–2000）；参考硬件 H100 80GB，但 **RTX 4090 24GB + 梯度检查点 + 分辨率 768×432 可跑**；A100 80GB < 3 小时。
  - **原生 ComfyUI 支持**已于 2026-03-24 合并上游（PR #13111），无需自定义节点；模型资产：LTX-2.3 基座(~44GB) + Gemma 文本编码器(~6GB) + spatial/temporal upscaler + Distilled LoRA(~900MB，两阶段推理必需)。
  - **IC-LoRA vs 标准 LoRA**：IC-LoRA 在推理时吃「参考图 + 音频」激活身份映射，不需触发词；标准 LoRA 靠文字触发词学风格。
  - LTX Trainer 支持**本地训练**（IP 不外泄）、音频+音画联合训练、后处理规则（降噪/超分/配色）。
- **适用**：**第一步跑通后启动「本地训桃子 Character/IC-LoRA」**（rank 128），彻底解决 LTX 保 ID 弱的问题，跨集一致；4090 24GB 可训（我们 A10 24GB 临界，建议借大显存实例或降分辨率）。
