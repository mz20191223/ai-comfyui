## 一 创作工程
素材 `D:/Aicomfyui/minimax3创作内容/重制版/`；文档 `…\deepseek分镜\`。

1. **信息边界**：只写本次调用看得见做得到的。越界三类必删——跨镜｜跨时（分镜图禁秒数/尾帧）｜跨层（起手态/结果态/Picture N）。说明进 `> 📋【工作流注释·勿喂模型】`。
2. **编号两层**：文本层 `参考图N`/`Image N` **1 起**；参数层 `ref_image_0` **0 起**，刻意差 1（`Image N == ref_image_(N-1)`），**别去统一**。侧别基数：image 1 起、video 0 起（UI 徽标/新增/reorder 按 side 取值）。
3. **四层分工**：素材声明→画面主体（含动作自身时长）→时序指令（**只此层写 `X–Y秒`，0 起连续覆盖满**）→硬约束。**唯一出口＝`video_prompt`**；`action_beats` 只存不进模型；**缺层＝看不到也发不出**。**实测（2026-09-18，查 `generation_tasks.payload.prompt` 反推）**：进模型的**只有** `video_prompt` ＋「硬约束：」＋自动编号的 `hard_constraints`；`> 📋【工作流注释】` 段、`post_audio_note`、`audio_note`、`action_beats` **都不进**——所以注释里可以放开写诊断结论与旧措辞引述，正文与硬约束里不行。
4. **图/视频分离**：分镜图只写画面、**禁 POV/运镜**；单角色不写他角；空镜不塞人物。
5. **防转场句必写**：严禁黑场/黑帧/淡入/淡出/溶解/叠化。
6. **台词** `**角色："台词"**` 加粗独立成句；时长≥音频（mutagen）；4.5 字/秒、动作 2.5 秒/拍；`ref_audio` 给**音色＋节奏**（模型照它念，非逐字播放；音频头/尾静音不会带进成片）。
7. **过客锁定句**：`严格锁定过客的面部特征、发型、服饰与体型`；同一人写「与参考图N同一人」。
8. **参考图红线**：`手机群聊/红色警报/键盘/终端/公司办公室_场景参考图` 只作风格氛围参考，**严禁还原布局/拼贴/色值**；手机镜头必传道具图。
9. **形态锚点**：已出片角色用**真实渲染帧**；**例外：权限魅影一律用 `权限魅影_角色参考图.jpg`**。
   - 🎭 **形体总则（2026-09-18 设定反转，用户决策）**：权限魅影＝**完全实体的人形**——有血有肉的实体面孔（眉/眼/鼻/嘴与唇形齐全、**正常人的嘴部结构**）＋**一双紫色发光的瞳仁**（唯一光效特征）＋身形修长＋深色高领长袍。**旧设定「半透明雾态人形／边缘飘散／下身渐隐／面部留暗部不显五官」全部作废。**
   - **"雾"只作攻击特效与登场前态**：14a-1／14a-2／14b-1 的雾态登场（尚未凝形、无人声）照旧；第2集的黑雾侵入/侵蚀/挤压是特效，保留。
   - **根因（为什么必须改）**：本平台配音**以"画面里说话人的口型"为同步锚点**。旧设定下魅影是全片唯一"无面说话人"（无脸无嘴），14d 成片人声退化成**不成词的乱语**（ASR 六语种皆"像话"却不属任何语言）；旁证是本片所有**真人对口**镜头（5/11/12b/13d/14c）ASR 逐字正确。**结论：凡有台词的角色，画面里必须有脸有嘴。**
   - ⚠️ **待用户执行（2026-09-18 定稿方式）**：**垫旧版 `权限魅影_角色参考图.jpg`（黑雾态设定稿）做 i2i 具象化**，出**白底三视图**（面部大特写 ＋ 正面/90°侧面/180°背面全身四格，横版 3:2），出图后**仍存同名**（旧图先复制改名 `_旧黑雾态版` 留档，勿覆盖）；→ 再重出 `0114d.jpg`（旧图是无脸剪影）→ 重生成 14d。规格与中英文两版提示词在 `第1集_分镜图提示词_GPT-Img2.md` 的「权限魅影_角色参考图（实体人形版）· 三视图出图规格（待重出）」段。
   - **纪律③（2026-09-18 补，用户明令）**：**角色参考图提示词「要素从简」**——参考图已携带的设计语言（长袍款式／王冠造型／紫光色相／体态轮廓）**一律不在文字里复述**，只留「具象化 ＋ 四格版式 ＋ 嘴部清晰 ＋ 东亚面孔无发」几条必需项。元素堆多了模型会顾此失彼（实测：堆到 17 处锁定后仍出欧美骨相＋惨白蜡像皮肤＋立领包下巴＋繁复刺绣袍＋时装式夸张比例）。**只写参考图上「真有的」**——凭空给参考图安元素（如写「保留它原有的深色长袍与王冠」，而图上其实没有）会引导模型照不存在的设定乱发挥；写之前先打开图核一遍。**且改动范围只限该出图提示词段——其他镜头、分镜图一律不排查、不修改（用户明令）。**

   - **纪律**：`md 带序号 / DB hard_constraints 不带序号` → 同一条替换要写两份 old 串，否则 DB 静默漏改（本次踩过）。
   - **纪律②（2026-09-18 补，踩过）**：**复核必须「全表全列」**——`shot_details` 有 **34 列**，`image_refs_note`（参考图清单）与 `shot_asset_links.take_note/raw_text`（形态锚点备注）**都实际进模型**，是最易漏网的字段（上一轮只扫 7 列，漏了 19 处）。且同一描述要备**三套字面变体**：`shot_details` 用 `**加粗**`＋`——`；`shot_asset_links` 用**无加粗**＋`（括号）`；md 用反引号包文件名。一套 old 串只能命中一处。追加式批注（new ⊃ old）会让「old 残留」断言**假报警**，判据应为「new 已存在＋命中数正确」。
10. **锚点分级**：**POV 尾帧只锚暗部光效与色调**，不能当机位/景别锚点；锚机位只用同机位独立构图；体量差靠「局部入画+出画」。
11. **分镜图正式名不可动**：`image_target_name`（如 0114d.jpg）被视频槽0首帧锚点与提示词按**文件名**引用，**永不改名**、换图只换内容（旧版自动存档 `_1` 不丢）。候选区＝任务结果 ∪ 目录扫描；两条路：`set-keyframe`（候选扶正）/`replace-keyframe`（上传替换，格式不符按正式名转码）。

12. **动作/方位口径**：手势写**摊开、掌心朝上**，忌「勾手」（模型会演成勾手指）；左右一律按**画面左右**（写「画面左侧的手臂」而非「左手」），并把**每只手与它唤出的对象一一对应**——角色自身左右模型常算错镜像。

13. **台词情绪不写进提示词**：情绪／语速／节奏／停顿一律交给 `ref_audio`——提示词只写「**严格照搬 Audio N／严格贴合参考音频**」。**严禁写「阴冷／缓慢／带笑意／居高临下」等形容词**（写了模型会自行演绎、放慢语速，**念出分配区间**）；**硬约束里也不要举例这些词**（举例＝又把词喂给模型）。**分界**：`语气/语速/节奏/声音发愣/尾音上扬/字字用力/带轻蔑`＝台词交付，**一律换成「照搬 ref_audio」**；`一愣/眉头微松/眼睛微睁/咬牙绷劲/身体微绷`＝**画面内容，必须保留**（模型得靠它演出表情）。改法：`过客低声疑惑地说`→`过客低声说`；`（语气XX带YY）`→`（语气、语速、节奏一律照搬 Audio N）`；`- 语气：<形容词>`→`完全由 ref_audio 文件本身决定`；并在既有「台词必须一气呵成」硬约束**末尾追加**一句「台词的语气、语速、节奏、停顿一律以 Audio N 为准，严禁按形容词自行演绎情绪」（**不新增条目，避免 md ①②③ 编号改动**）。台词由**模型生视频时与画面同步合成，不存在后期叠轨**，故每句**必须能在分配区间内念完**；判据用音频的**人声净长**（≈文件总长减去头尾静音，**别拿文件总长当语音时长**）。

14. **合成取片只认时间轴，人工指定优先**：合成读的是 `timeline_clips.file_path`（`compose` **强制**要有启用片段，否则 400、走不到退路）。优先级：**① 时间轴里手动换过的（`manual=1`）→ ② `shots.final_video_path`（详情页「设为成片」／`set-final-video`）→ ③ 自动（该镜最新成功任务里第一个存在的文件）→ ④ 按镜号扫「分镜视频」目录**。`final_video_path` 曾经**只写不读（空操作）**，2026-09-18 已修；**改完视频不重建/更新时间轴，合成还用老片段**。`auto_build` 的 `existing` **必须只认非空 `shot_id`**（NULL 会塌缩成同一个 key → 每镜多插一条重复片段 → 合成把每镜拼两遍；实测 ep1 曾 50 条 = 25×2），合成侧另有运行时去重保护（按 `(file_path, sort_order)`，只报 `skipped_duplicates`）。

15. **失败归因必须区分「本地拦截」与「上游拒绝」**（2026-09-18）：账号被标 `exhausted`／`invalid`／`disabled` 后**不会自动恢复**（只有 `cooling` 到期会自动回 `active`），且启动时的种子 `_add_credential` **只写 alias/sort_order/enabled，不覆盖 status**——所以账号表 `updated_at` 变了**不等于**用户点过「恢复」（「恢复」必同时清 `fail_count` 与 `last_error`）。池内无可用账号时**请求根本没发出**：文案必须写清「**本次请求未发出（未消耗额度）**」+ 账号状态 + 上次原因 + 「到设置页点该账号的『恢复』」指引，否则用户会把本地拦截误读成上游答复。**判断"到底有没有真发出去"的铁证是账号行三件套**：`last_used_at`／`fail_count`／`last_error`——三者都没动＝没发请求；`mark_credential` 无论成功失败都会写 `last_used_at`。

16. **需要念台词的镜头，画面主体必须"能开口"**（2026-09-18 实证，本地 whisper 对照）：H3 生成配音**依赖画面说话人的口型做同步锚点**——提示词一旦写「不开口、无口型」，成片**要么完全没有语音**（14a1／14a2：ASR 零输出；**这两个镜头是用户有意做成不发声的，不算缺陷**），**要么念出不成词的乱码音流**（14d 三版全如此，v3 转写为「我床制算辞职课是在肉依和你扯」）。**对照：真人开口的过客／林岚镜头台词逐字可识别**（14c「你是谁」、13d「我的管理员权限没了」、12b「难道这就是师傅说的死循环妖」）。故：雾态魅影若要说话，必须给它开合（写「说话时嘴部区域有雾团随音节开合，面部仍留暗部、五官不可辨」）；**禁止开口的镜头不要给它台词**。**推论：把「人声／低语／气声／念咒／拟声词」成串写进提示词（负向静默锁）＝反向提示，会让人声变多**（14d 3.66s→5.24s）——**文本层压不住"没有发声主体"这个结构性缺陷**。**⚠️ 2026-09-18 四版实测：让魅影"开口"这条路已被证伪**（详见铁律 18）。已落地提示词改动照旧保留（硬约束⑤ 由「不开口、无口型」→「嘴部按正常人的方式张合、唇部动作清晰可见」，时序层句1／句2 补口型运动，新增硬约束⑱ 绑定「口型—发声」；**视觉类负向措辞同样会反噬**，「严禁做成静止不动的雾团」「不得做成实体嘴唇」这类句子一律删掉改成正向着装），但**它解决不了根因**。

17. **md↔DB 双写有两个隐蔽坑**（2026-09-18 实证）：① **`hard_constraints` 数组元素的序号由 `task_runner` 按数组下标自动生成**（`①②③…` + `content`，见 `task_runner.py:216-225`），**元素内部绝不能自带序号**——旧 14d 最后一条自带「⑮ 」前缀，实际发出的是「⑮ ⑮ …」；多条挤在一个元素里会整体错位（已拆成 ⑮/⑯/⑰ 三条独立元素，现 18 条）。② **`video_prompt` 是独立字段，不是从 md 正文实时渲染的**——改 md 正文后必须**单独同步 vp**。但发现字面差异时**先分清"漏同步"还是"用户有意删改"，别默认当 bug 补回去**：14d 那 3 处「如何」↔「如何啊」的差字，经用户确认是**他自己删掉的口语虚词「啊」**（且**只删了 14d 这一镜**，不是全库系统性漏字）；2026-09-18 用户明确"这次可以不删"，故保留「啊」。遇到 `嗯/啊/吧/呢` 这类虚词增删，先问一句再动。**校验口径**：去空白后 `md 段正文 == vp`、`md 硬约束 == " ".join(编号+条目)`、`post_audio_note` 每行都在 md 段内。

18. **无面孔的说话人＝台词必然念不对（2026-09-18 四版实证，根因已定）**：H3 的配音通道**要挂在一个"看得见的口部"上**——它的正确性依赖画面里有可辨的说话人；给不出这个锚点，模型仍会出声，但吐出的是**"音色像、音节像中文、词全错"的乱语**。
   - **14d 实测四版全败**：task6（09-17，**单音频**，ASR「失去最高拳线的最如何…说得出来吧」＝勉强能认）→ task12／13／14（09-18，双音频，全是乱语，如「我除日双慈美康是在用分朝道」）。**这一镜从第一次生成起就有病**，不是 09-18 才出现的。
   - **画面铁证**：`0114d.jpg` 首帧锚点里魅影的头是**一颗纯黑、零五官的剪影**（4× 放大可见：无眼、无鼻、无嘴），全片 29 帧头部始终如此——**"唇部动作清晰可见"这条指令根本没有可落地的对象**。对照：**台词逐字可识别的镜头，说话人都是有脸有嘴的真人**（5／12b／13d／14c／11，ASR 全对）。
   - **推论**：① 想让模型念对，**说话人必须在首帧锚点里就有可辨的口部**（要改锚点图，不是改提示词）；② 否则**不要指望模型出声**，走后期叠轨（角色设定本就是「声音从雾中传来」）；③ 魅影这类无面角色，**台词改由可见角色说**或**直接叠轨**才可控。
   - **取证方法（可复用，另存技能 `shot-video-forensics`）**：本地 whisper ASR ＋ **语种扫（zh/en/ja/ko/yue）** ＋ **候选台词 initial_prompt 偏置重打分**（avg_logprob 对不上任何一句＝它没在念真实文本）＋ **变速率扫描**排除时域处理。**⚠️ 倒放/变速后的"通顺假句"是 whisper 幻觉**——必须拿一段已知真语音频做同样处理当对照，别据此下"音频被倒放"的结论。

**规格**：768x1344/24fps/h264+aac；¥0.04/秒；**先音频后图片**；白模 mp4 不进 API。接口 **A（多图）/B（首尾帧）**：精确停靠→B，动态过程→A+I2VA；**成片时长**按 `17n+5` 帧对齐（7s→7.29s）。

## 二 短剧工作台
Vue3+EP+Vite / FastAPI+SQLite。**后端 8770、前端 5180**。md 与素材目录＝真相源，工作台只索引+写回。

**三条不可动摇**：①**单轨任务态**（任务态从 `generation_tasks` 聚合）；②**全配置化**（Jinja2+JSONPath，换平台只改设置）；③**项目隔离**（按 project_id；`?ep`＝集号）。

**三通道**：①剧本 DeepSeek（**model 发 `deepseek-flash`**）；②资产图 gpt-image2.5＝ListenHub（本地素材走 `inlineData`）；③视频 MiniMax H3@AutoDL（**裸 token 无 Bearer**；URL 极短效须即下；`ref_*` 只收 URL）。**⛔ 真实付费调用前先问用户。**

**机制**：**LLM 必须流式**（否则卡 5%）；详情页**两闸门**；成片落 `storage\pending\`，页点归档/废弃才进素材。
