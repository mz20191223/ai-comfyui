## TTS平台说明

- **TTS引擎**：Microsoft Edge TTS（中文多语气语音）
- **音色**：均为 Edge TTS 中文语音，括号内为英文名
- **语速/音调**：以百分比表示相对调整，"默认"表示不额外调整
- **音频文件命名**：`第2集_镜头X_[角色名]_[台词简写].mp3`
- **单人台词**：每个有台词的镜头生成独立的音频文件，标注为 `ref_audio_0`
- **双人对话**：两位角色分别生成音频，标注为 `ref_audio_0` 和 `ref_audio_1`
- **多人对话**：按角色出场顺序依次标注 `ref_audio_0`、`ref_audio_1`、`ref_audio_2`……
- **同一角色多次发言**：每次发言生成独立的音频文件，按顺序递增编号
- **无台词镜头**：不生成音频文件，不传 ref_audio
- **角色音色性格设定**：
  - 过客（云希）：中性沉稳，主角默认音色
  - 小七（小小）：偏快偏高（+10%），体现活泼调试助手
  - 内存黑洞王（云泽）：低沉缓慢（-30%/-15%），吞噬者压迫感
  - 死循环妖（云枫）：偏快（+30%），重复急促特性
  - 权限魅影（云健）：低沉（-20%/-10%），隐秘诡谲
  - 终极Bug王（云泽）：极低沉缓慢（-40%/-20%），终极压迫感

## API调用指南

### 参数填写规则

| 参数 | 填写内容 |
|---|---|
| duration | 5（所有镜头统一5秒） |
| prompt | 正文中的画面描述+运镜段落（不含音频信息块） |
| ref_image_0 | 该镜头的分镜图（从分镜图提示词文档生成） |
| ref_image_1 | FL2VA镜头：尾帧分镜图；I2VA镜头：可选，补充角色/场景参考图 |
| ref_audio_0 | 音频信息块中标注的 ref_audio_0 文件 |
| ref_audio_1 | 音频信息块中标注的 ref_audio_1 文件 |
| ref_audio_2 | 音频信息块中标注的 ref_audio_2 文件 |

### ref_audio上传顺序规则

**prompt中台词的出现顺序 = ref_audio编号顺序**
- 第一个说话的角色 → ref_audio_0
- 第二个说话的角色 → ref_audio_1
- 第三个说话的角色 → ref_audio_2
- 同一角色多次发言 → 每次发言生成独立音频，按顺序递增编号
- 无台词镜头 → 不传 ref_audio

### prompt文本提取方法

直接复制每个镜头正文中的画面描述段落（从"参考上传的图片"或"以上传的图A"开始，到"运镜：……"结束），不要复制音频信息块。
