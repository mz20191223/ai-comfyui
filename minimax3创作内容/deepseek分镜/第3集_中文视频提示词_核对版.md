## TTS平台说明

- **TTS平台**：Edge TTS（微软 Azure 语音服务）
- **音色映射**：使用中文音色名（云希/小小/晓甄/云野/云泽），括号内为英文名
- **语速调整**：正值为加快，负值为减慢；"默认"表示不传 rate 参数
- **音调调整**：正值为升高，负值为降低；"默认"表示不传 pitch 参数
- **ref_audio**：每个有台词镜头生成对应角色参考音频文件，用于声音克隆/对齐
- **双人/多人对话**：按出场顺序分配 ref_audio_0、ref_audio_1、ref_audio_2
- **无台词镜头**：标注"无台词，不传 ref_audio"

## API调用指南

### 参数填写规则

| 参数 | 填写内容 |
|---|---|
| duration | 5（所有镜头统一5秒） |
| prompt | 正文中的画面描述+运镜段落（不含音频信息块） |
| ref_image_0 | 该镜头的分镜图（从分镜图提示词文档生成） |
| ref_image_1 | FL2VA镜头：尾帧分镜图；I2VA镜头：可选，补充角色/场景参考图 |
| ref_audio_0 | 音频信息块中标注的 ref_audio_0 文件 |
| ref_audio_1 | 音频信息块中标注的 ref_audio_1 文件 |
| ref_audio_2 | 音频信息块中标注的 ref_audio_2 文件 |

### ref_audio上传顺序规则

**prompt中台词的出现顺序 = ref_audio编号顺序**
- 第一个说话的角色 → ref_audio_0
- 第二个说话的角色 → ref_audio_1
- 第三个说话的角色 → ref_audio_2
- 同一角色多次发言 → 每次发言生成独立音频，按顺序递增编号
- 无台词镜头 → 不传 ref_audio

### prompt文本提取方法

直接复制每个镜头正文中的画面描述段落（从"参考上传的图片"开始，到"运镜：……"结束），不要复制音频信息块。
