## 二、小七（调试助手）

### 基础音色
- 性别：无（偏中性，略偏童声）
- 年龄感：活泼少年感
- 音高：偏高，清亮
- 语速：快，机关枪式
- 音质：带轻微电子质感，但不机械——像精灵而非机器人
- 尾音：句尾常带上扬，带着调皮

### 情绪变化轴

| 集数 | 阶段 | 情绪 | 语速 | 语气特征 |
|---|---|---|---|---|
| 第2集 | 初登场 | 调皮+得意 | 偏快 | 跳跃感，像在炫耀 |
| 第2集 | 解释能力 | 认真 | 中 | 变得靠谱，但尾音仍带俏皮 |
| 第2集 | 战斗提醒 | 焦急 | 很快 | 声音变尖，带紧迫感 |
| 第2集 | 发现弱点 | 兴奋 | 快 | 上扬，像发现了宝藏 |
| 第2集 | 被抓 | 虚弱 | 慢 | 气息断续，声音发颤 |
| 第3集 | 虚弱求助 | 气弱 | 慢 | 声音很小，带颤抖 |
| 第3集 | 贴符文 | 急促连贯 | 很快 | 念咒式，一字一顿 |
| 第3集 | 恢复后 | 如释重负 | 中 | 松了口气，带笑意 |

### 关键台词读法

## 三、林岚（线上负责人）

### 基础音色
- 性别：女
- 年龄感：30-35岁
- 音高：中音，清亮
- 语速：中等偏快，但不慌乱
- 音质：干净利落，职业感
- 尾音：句尾下沉，有分量感，不带多余的语气词

### 情绪变化轴

| 场景 | 情绪 | 语气特征 |
|---|---|---|
| 电话催过客 | 急切但不失条理 | 语速快，咬字清楚 |
| 现场拦产品经理 | 冷静权威 | 放慢，一字一顿，有压场感 |
| 对峙产品经理 | 不退让 | 声音不大但很稳，"我担"二字重读 |
| 事后递咖啡 | 温和 | 声音放柔，带笑意 |

### 关键台词读法

| 台词 | 读法 |
|---|---|
| "线上客户投诉，收到订单异常消息，你那边怎么回事？" | 急促，但每字清楚，尾音下沉不拖 |
| "谁都不准碰他的电脑。" | 低沉有力，"不准"重读，压场 |
| "最后提交不是根因。他正在追踪源头。" | 冷静，陈述事实，不卑不亢 |
| "我担。" | 两个字，极短，极稳，掷地有声 |
| "给他最后六十秒。你要是敢拔电源，我就在事故报告里写清楚，是你销毁了最后的日志。" | 前半句克制，后半句逐字加重，最后一句像宣判 |
| "过客不是事故制造者。他是唯一找到根因的人。" | 平静陈述，"唯一"重读 |
| "事故复盘上午十点。" | 公事公办，不带情绪 |
| "尤其是大圣。" | 带笑意，轻松收尾 |

## 五、内存黑洞王（反派1）

### 基础音色
- 性别：男（扭曲变声）
- 音高：极低，带混响回声
- 语速：慢，有威压感
- 音质：浑厚+电子失真，像从深井里传出来的声音
- 尾音：拖长，有余韵，像黑洞在吞噬声音本身

| 台词 | 读法 |

| "你敢删掉核心数据吗？" | 威胁，低沉，尾音拖长 |
| "我还会回来的……" | 渐弱渐远，像被吞噬 |
| "你以为吞噬只是我的能力？"（回声） | 从远处传来，带混响 |

## 六、死循环妖（反派2）

### 基础音色
- 性别：不明（多重叠声音）
- 音高：中音，但有多层叠加
- 语速：快，重复性强
- 音质：机械+人声混合，像卡带重复播放
- 尾音：每句末尾轻微重复（像回声echo）

| 台词 | 读法 |
|---|---|
| "欢迎！欢迎！欢迎！" | 三次重复，每次音调微升，像循环 |
| "执行！重试！失败！再执行！" | 机关枪式，四个词节奏一致，机械感 |
| "你永远打不完！" | 带笑意，嘲弄，尾音上扬 |
| "你必须从第一行重新开始！" | 惊恐，声音发颤，"第一行"重读 |

## 八、终极Bug王（最终反派）

### 基础音色
- 性别：男（三重叠加）
- 音高：极低，但比黑洞王更厚重
- 语速：极慢，每字都有重量
- 音质：三层声音叠加——黑洞王的低沉+死循环妖的机械重复+权限魅影的气声失真
- 尾音：每个字都有回响，像在巨大的空腔里说话

### 关键台词读法

| 台词 | 读法 |
|---|---|
| "程序员，你还有最后一行代码。你准备写什么？" | 极慢，居高临下，"最后一行"重读 |
| "只要根因还在，删掉我一万次，我就重生一万次。" | 平静叙述，不带情绪，像在陈述物理定律 |
| "你连一种都处理不干净，还妄想修复整个世界？" | 蔑视，"妄想"二字重读 |
| "你和他们一样，只想在天亮前把问题藏起来。" | 慢，每个字都重，"藏起来"三字最重 |
| "把真相公开，你自己也有错误！" | 突然拔高，带攻击性 |
| "没有人想看真相！他们只想找一个人背锅！" | 愤怒，"背锅"重读 |
| "停下！你删不掉我！" | 嘶吼，带恐慌（第一次感到威胁） |
| "你修掉的，从来不是我们。你们只是把错误藏得更深。" | 最慢，最沉，像在宣判 |

### 音频格式要求
- 格式：MP3 或 WAV
- 采样率：32kHz 或 44.1kHz
- 声道：单声道（角色台词）或立体声（环境音效）
- 每条音频时长：不超过对应镜头时长（5秒镜头 = 音频不超过5秒）
- 文件命名建议：`第X集_镜头Y_角色名_台词简写.mp3`
  - 例：`第1集_镜头5_过客_我马上处理.mp3`
  - 例：`第2集_镜头9_小七_快用火眼金睛.mp3`
