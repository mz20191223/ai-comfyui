# 音频准备清单

> 配合 MiniMax H3 多图多音频接口使用。
> 每个说话镜头需要准备的台词音频，按集数→镜头→角色排列。
> 音频上传到接口的 `ref_audio_0`（单人说话）或 `ref_audio_0` + `ref_audio_1`（双人对话）。

---

## 文件命名规范

```
第X集_镜头Y_角色名_台词简写.mp3
```

例：
- `第1集_镜头5_过客_我马上处理.mp3`
- `第2集_镜头3_小七_我是小七.mp3`
- `第3集_镜头14_过客_我当然有.mp3`

## 接口上传对照

### 单人说话镜头（大多数）

```
ref_audio_0 = 该镜头台词音频
ref_image_0 = 分镜图（GPT-Img2生成）
ref_image_1 = 角色参考图
ref_image_2 = 场景参考图（如有）
```

### 双人对话镜头（少数）

如第2集镜头6（过客+小七对话）、第3集镜头6（林岚+产品经理对峙）：

```
ref_audio_0 = 第一说话人台词音频
ref_audio_1 = 第二说话人台词音频
ref_image_0 = 分镜图
ref_image_1 = 第一说话人角色图
ref_image_2 = 第二说话人角色图
ref_image_3 = 场景参考图
```

### 无台词镜头

```
ref_audio = 不传
ref_image_0 = 分镜图
ref_image_1 = 角色参考图
ref_image_2 = 场景参考图
```
