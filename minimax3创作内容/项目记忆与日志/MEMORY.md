## 一 创作工程（铁律摘要，全文见详细档案）
1. 信息边界：只写本次调用看得见做得到的；跨镜/跨时/跨层三类必删；说明进 `> 📋【工作流注释·勿喂模型】`。
2. 编号两层：文本 `Image N` 1 起、参数 `ref_image_0` 0 起，刻意差 1，别统一。
3. 四层分工：素材声明→画面主体→时序指令（唯一写秒处，0 起连续覆盖满）→硬约束。唯一出口=`video_prompt`；实测进模型的只有 vp＋「硬约束：」＋自动编号 hc；注释段/post_audio_note/action_beats 都不进。
4. 分镜图只写画面、禁 POV/运镜；单角色不写他角；空镜不塞人。
5. 防转场句必写：严禁黑场/黑帧/淡入淡出/溶解/叠化。
6. 台词 `**角色："台词"**` 加粗独立成句；时长≥音频的人声净长（非文件总长）；4.5 字/秒、动作 2.5 秒/拍。
7. 过客锁定句：`严格锁定过客的面部特征、发型、服饰与体型`；同一人写「与参考图N同一人」。
8. 参考图红线：拼贴/场景图只作风格氛围参考，严禁还原布局/拼贴/色值；手机镜头必传道具图。
9. 形态锚点：已出片角色用真实渲染帧；权限魅影参考图正重出**带嘴版**（09-21 用户自己出，我不调图）。
10. POV 尾帧只锚暗部光效与色调；体量差靠「局部入画+出画」。
11. 分镜图正式名（image_target_name）永不改名，换图只换内容。
12. 手势写「摊开、掌心朝上」忌「勾手」；左右一律按画面左右；每只手与唤出对象一一对应。
13. 台词情绪不进提示词：语气/语速/节奏一律写「照搬 Audio N」；表情动作词（一愣/微睁/咬牙）是画面内容必须保留。
14. 合成取片只认时间轴：manual=1 → final_video_path → 自动最新 → 扫目录；auto_build 的 existing 必须只认非空 shot_id。
15. 失败归因分「本地拦截/上游拒绝」；铁证=账号行 last_used_at/fail_count/last_error 三件套全没动=没发请求；exhausted 不会自动恢复须设置页点「恢复」。
16. **无面孔说话人=必然乱语（根因已定）**：H3 配音通道要挂画面里可辨的口部；OS/画外音只在「画面内另有有脸角色可挂靠」时有效。凡有台词的角色画面里必须有脸有嘴。
17. **⚠️ 14d 最终口径（2026-09-21 五次调整·用户拍板）：改回「有嘴」**——14d v4 实片取证证明 OS 在画面内无有脸角色时仍乱语，故恢复给魅影一张 human-like 嘴、本人开口、唇部动作与 ref_audio 同步（口型同步锚点）；形态维持雾态人形+紫瞳。**17／21／第2集魅影 8 句台词尚未套用，等 14d 出片验证后批量。**
18. md↔DB 双写：hard_constraints 序号由 task_runner 按下标生成，元素内禁自带序号；vp 是独立字段，改 md 后必须单独同步（先分清漏同步还是用户有意删改）；校验口径=去空白后逐字相等。

规格：768x1344/24fps/h264+aac；¥0.04/秒；**先音频后图片**；白模 mp4 不进 API；接口 A（多图·动态）/B（首尾帧·精确停靠）；成片时长按 `17n+5` 帧对齐。

## 二 短剧工作台
Vue3+EP+Vite / FastAPI+SQLite。**后端 8770、前端 5192（固定）**。md 与素材目录=真相源，工作台只索引+写回。
三不可动摇：①单轨任务态（从 generation_tasks 聚合）②全配置化（Jinja2+JSONPath）③项目隔离（project_id）。
三通道：①剧本 DeepSeek（发 `deepseek-flash`）②资产图 gpt-image2.5（本地素材走 inlineData）③视频 MiniMax H3@AutoDL（裸 token 无 Bearer；URL 极短效须即下；ref_* 只收 URL）。**⛔ 真实付费调用前先问用户。**
机制：LLM 必须流式；详情页两闸门；成片落 storage\pending\ 页点归档才进素材。失败必须带 `kind`（QuotaExceeded/pool_fail_kind：exhausted>invalid>cooling），fail_label=短分类、message=原始报文。
铁律：不做配音生成；wizard_service 绝不覆盖手写；DB 线程内长连接、禁自建 connect；同文件多处改动串行+立刻回读；不移动既有文件；加按钮必定义 handler；负向测试不用真实数据；落盘防撞 `_free_path`；thumb 缓存含 mtime+size。
改码纪律：绿盾 .py/.vue 用 python 脚本改；补丁含 `${}`/反引号→Write 落脚本文件；改完 .py 必重启+验 openapi 新路由；宿主吞字→结论用 python count() 写文件再读。
起服务：后端 `envs\default\Scripts\python.exe run.py`（别用 C:/Python313）；前端 `npm run dev`（5192）。杀 Vite 先确认真死（netstat LISTENING），它会随 vite.config 改动自动重启抢端口。
前端：字号只用 `--fs-*`；操作列改后跑 tools/check_opcol.cjs；成片产物卡片定宽 168px。
