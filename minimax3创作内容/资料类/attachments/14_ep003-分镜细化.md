# 《大圣协议：程序员终极幻想》
# 第3集分镜制作包：如意金箍棒·终极调试

> 版本：分镜细化 V1.0
> 画幅：9:16 竖屏
> 目标时长：约135秒
> 镜头数量：18个
> 视觉基调：根目录崩塌 → 现实争分夺秒 → 日志真相回溯 → 金色终极调试 → 轻松下班彩蛋
> 核心主题：删除错误不等于修复错误，公开根因才能让系统真正恢复

---

## 一、连续性锁定

- **承接第2集：** 第2集结尾过客金甲开裂、金箍棒脱手、小七被黑色数据手抓住；第3集第1镜必须保持三项状态。
- **终极 Bug 魔王：** 服务器猿魔体型遮天，胸口红色“ROOT”目录是唯一真实核心；吞噬、复制、隐身三种能力同时存在。
- **现实世界：** 林岚第一次正面出现，承担“守住最后调试窗口”的现实行动线。
- **主题转折：** 过客前半段用删除和攻击解决问题，失败后主动恢复全部原始日志，完成从“修表象”到“修根因”的成长。
- **结尾状态：** 系统恢复绿灯，过客回到现实；彩蛋中的迷你 Bug 只能作为轻松续作入口，不推翻本集闭环。

## 二、逐镜分镜表

### 镜头01｜0:00—0:07｜根目录崩塌

- **景别：** 超大全景
- **机位：** 从红色根目录向下俯压，缓慢逼近过客
- **画面：** 根目录天宫碎裂，红色代码像暴雨坠落；终极 Bug 魔王遮住整个天穹，过客半跪，金甲裂纹清晰可见，金箍棒插在远处。
- **声音：** 低频轰鸣、系统倒计时归零音。
- **台词：** 终极 Bug 魔王：“程序员，你还有最后一行代码。你准备写什么？”
- **构图：** 魔王占上三分之二，过客位于底部中央，强化绝对压迫。

### 镜头02｜0:07—0:15｜删除失败

- **景别：** 中近景动作镜头
- **机位：** 侧面跟随过客跃起，再迅速拉近金箍棒击中ROOT
- **画面：** 过客召回金箍棒，跃向魔王胸口，击碎“ROOT”目录；碎片刚散开，数十个相同ROOT目录立刻重生。
- **对白：**
  - 过客：“写你的删除命令。”
  - 小七：“删除无效！它在自动恢复！”
- **声音：** 金箍棒撞击声后接故障重启声。
- **剪辑：** 不要一击成功，保留失败后的停顿。

### 镜头03｜0:15—0:23｜三种能力同时反扑

- **景别：** 三段快切特写
- **画面：** 黑洞吞掉恢复数据；分身从代码地面爬出；黑雾缠住过客胸口的大圣协议权限。
- **台词：** 终极 Bug 魔王：“只要根因还在，删掉我一万次，我就重生一万次。”
- **动作：** 过客连续挥棒抵挡，仍被三股力量击飞。
- **声音：** 吸入、复制、耳语三种音效叠加后突然切断。

### 镜头04｜0:23—0:31｜主角跌入低谷

- **景别：** 近景
- **机位：** 低机位拍过客撑地起身，镜头轻微失焦
- **画面：** 金甲裂纹扩大，工牌被黑雾遮住一半，金箍棒光线变弱。
- **对白：**
  - 终极 Bug 魔王：“你连一种都处理不干净，还妄想修复整个世界？”
  - 过客：“至少我敢进来面对你。”
  - 终极 Bug 魔王：“你和他们一样，只想在天亮前把问题藏起来。”

### 镜头05｜0:31—0:39｜现实世界同步崩溃

- **景别：** 全景
- **机位：** 现实会议室正面固定
- **画面：** 大屏所有服务变红，产品经理冲向过客工位，林岚伸手拦住电源线。
- **对白：**

  - 林岚：“谁都不准碰他的电脑。”
- **声音：** 会议室人声、报警声、电话同时响起。
- **构图：** 林岚站在过客与电源之间，形成保护性阻挡。

### 镜头06｜0:39—0:47｜林岚争取最后窗口

- **景别：** 中景对峙
- **机位：** 产品经理前景虚化，焦点落到林岚
- **对白：**
  - 产品经理：“最后提交是他，你还护着他？”
  - 林岚：“最后提交不是根因。他正在追踪源头。”
  - 产品经理：“倒计时归零了！责任谁担？”

- **声音：** 所有报警声短暂压低，只留下林岚的最后一句。

### 镜头07｜0:47—0:54｜六十秒倒计时

- **景别：** 屏幕特写 → 过客工位近景
- **画面：** 大屏显示“最后调试窗口：00:60”；过客仍趴在键盘前，连接进度从1%跳到2%。
- **台词：** 林岚：“给他最后六十秒。谁敢拔电源，就在事故报告里写清楚是谁销毁了最后的日志。”
- **转场：** “最后的日志”几个字在现实屏幕上变成代码世界里的金色文字。

### 镜头08｜0:54—1:02｜过客改变策略

- **景别：** 虚拟空间近景
- **机位：** 从过客耳边向前推进，现实声音作为画外声延续

### 镜头10｜1:10—1:19｜日志时间线回溯

## 四、连续性与验收标准

- 第1镜必须保留第2集结尾的金甲裂纹、金箍棒脱手和小七被抓状态。
- 第2镜删除失败必须明确发生，不能让终极大招变成第一次攻击的重复。
- 第6、7镜林岚的现实线必须与虚拟空间同步，证明过客不是孤立战斗。
- 第10、11镜必须让观众看懂五个时间节点及“跳过权限校验”这一根因。
- 第14镜的“ROOT CAUSE FIX”是过客成长的视觉标志，必须清晰可读。
- 第17镜三个状态必须按权限、循环、内存顺序依次变绿，完成技术逻辑闭环。
- 第18镜先完成系统恢复，再放入职场笑点和彩蛋，不能让彩蛋削弱终局满足感。

## 五、竖屏剪辑提示

- 魔王与过客对峙时采用垂直压迫构图，魔王头部在上，过客位于下方中轴。
- 日志时间线回溯采用全屏纵向滚动，让手机屏幕上的时间节点一条条落下。
- 终极大招使用中央垂直编辑光标，避免横向爆炸造成主体出框。
- 现实会议室段保持较少镜头切换，让林岚“我担”的力量落地。
- 结尾彩蛋控制在最后5秒内，保证完整结局先于续作暗示出现。
