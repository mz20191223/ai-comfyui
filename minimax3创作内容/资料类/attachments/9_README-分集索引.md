- `characters.md`：角色档案

- `三集质量自检报告.md`：全剧质量审核

## 推荐制作顺序

1. 先锁定三大神通和三大 Bug 的统一视觉设定。
2. 拍摄现实办公室的三集共用场景。
3. 制作第1集末尾的大圣协议转场。
4. 按内存、循环、权限顺序完成第2集三场战斗。
5. 制作第3集日志回溯、终极调试和系统绿灯状态。
6. 最后统一片名、系统界面、错误码和声音设计。
