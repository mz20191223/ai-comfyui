# 《大圣协议：程序员终极幻想》
# 第1集分镜制作包：凌晨两点，Bug 成精了

> 版本：分镜细化 V1.0
> 画幅：9:16 竖屏
> 目标时长：约120秒
> 镜头数量：15个
> 视觉基调：现实冷白压迫 → 故障红色侵入 → 大圣协议金色觉醒
> 核心钩子：普通程序员被背锅，最终主动按下“大圣协议”

---

## 一、统一制作锁定

### 角色锁定

- **过客：** 28岁男性程序员，黑色连帽衫、工牌、轻微黑眼圈；前半集肩膀内收、动作急促，后半集逐渐抬头，最后按键时眼神坚定。
- **林岚：** 只在电话声和手机界面出现，不提前露正脸；声音冷静、判断明确。
- **三大 Bug：** 内存黑洞王=吞噬；死循环妖=复制；权限魅影=隐身窃权。三者必须有清楚的形状差异。

### 竖屏构图规范

- 过客脸部和关键屏幕信息放在中上部安全区。
- 手机群聊和终端文字不堆满画面，每次只保留一条核心信息。
- 三大 Bug 首次同框时采用上下叠层：中间过客，顶部黑洞王，左下死循环妖，右下权限魅影。
- 第14—15镜的金色觉醒必须从画面中央向上下延展，避免被竖屏裁切。

### 颜色与声音规范

- 现实办公区：冷白、灰黑、少量蓝色屏幕光。
- 故障状态：红色只用于报警、倒计时和危险边缘。
- 大圣协议：金色代码、金色眼睛、金色战鼓。
- 音效主线：键盘声 → 报警声 → 低频 Bug 回声 → 金色编译音 → 战鼓。

## 二、逐镜分镜表

### 镜头01｜0:00—0:05｜前5秒故障钩子

- **景别：** 超近特写 → 快速推远
- **机位：** 电脑屏幕正面，轻微手持震动
- **画面：** 黑屏中突然跳出红色“P0级故障”，数据丢失风险从45%瞬间跳到87%。报警波形占满竖屏上半部。
- **构图：** 红色警报居中，过客的眼睛倒映在屏幕下方。
- **动作：** 过客猛地睁眼，手从桌面抬起。
- **声音：** 一声尖锐报警，紧接低频心跳。
- **台词：** 过客：“不是吧？偏偏是现在。”
- **转场：** 红色报警数字直接切入手机群聊。
- **生成提示：** 竖屏近距离电脑故障界面、程序员眼睛倒影、红色P0警报、强烈悬念、真实办公室夜景。

### 镜头02｜0:05—0:11｜职场背锅

- **景别：** 特写
- **机位：** 手机俯拍，屏幕占画面80%
- **画面：** 群聊消息连续弹出：“谁动了线上？”“最后一次提交是过客。”“又是你？”
- **构图：** 消息从下向上覆盖，最后一条停在中央。
- **动作：** 过客拇指停顿，未回复。
- **声音：** 消息提示音加快，键盘声若有若无。
- **台词：** 过客：“我提交的是日志格式，不可能影响订单服务。”
- **表演：** 不是委屈哭诉，而是疲惫、克制、已经习惯被怀疑。
- **转场：** 群聊最后一个问号变成电话来电图标。

### 镜头03｜0:11—0:19｜倒计时建立

- **景别：** 中近景
- **机位：** 侧前方45度，缓慢推近过客
- **画面：** 过客一边接电话，一边打开终端。屏幕右上角倒计时“00:27:00”。
- **动作：** 一只手夹手机，一只手快速敲键盘。
- **声音：** 林岚电话声清晰，背景有远程会议杂音。
- **对白：**
  - 林岚：“过客，先别解释，系统在掉数据。”
  - 过客：“我知道，我现在回滚。”
  - 林岚：“回滚已经失败两次了。还有二十七分钟，找根因。”
- **运镜：** 从过客脸部移到倒计时，再回到眼睛。

### 镜头04｜0:19—0:27｜第一次失败

- **景别：** 屏幕特写 + 手部特写
- **机位：** 俯拍键盘，快速摇到终端
- **画面：** 过客执行回滚；终端显示“ROLLBACK FAILED / MEMORY USAGE 99.9%”。
- **动作：** 他按下回车，立刻又敲击撤销，手指出现短暂颤抖。
- **声音：** 回车声被系统失败音截断。
- **对白：**
  - 过客：“如果找不到呢？”
  - 林岚：“那就不是今晚谁背锅的问题，是明天所有用户都进不了系统。”
- **转场：** “99.9%”数字膨胀成黑色漩涡。

### 镜头05｜0:27—0:36｜内存黑洞王现身

- **景别：** 特写 → 中景
- **机位：** 从屏幕内部向外冲出，模拟故障穿屏
- **画面：** 黑色内存曲线撑破终端，化成带巨大黑洞腹部的怪物。订单、头像和缓存碎片被吸入。
- **构图：** 黑洞王占上半屏，过客在下半屏仰视，形成压迫比例。
- **对白：**
  - 内存黑洞王：“数据？进了我的肚子，就别想出来！”
  - 过客：“你不是进程。你在主动吞噬缓存。”
  - 内存黑洞王：“你们舍不得删的垃圾，才是我最好的晚餐。”
- **声音：** 吸入声像服务器风扇被拉长。

### 镜头06｜0:36—0:44｜死循环妖复制

- **景别：** 全景感中景
- **机位：** 以过客为中心360度环绕，屏幕分裂配合镜头旋转
- **画面：** 一段错误代码复制到多块显示器，死循环妖的相同面孔从每个屏幕中探出。
- **动作：** 过客切断一个节点，三个新节点立即亮起。
- **对白：**
  - 死循环妖：“执行！重试！执行！重试！再来一遍！”
  - 过客：“同一个请求被重复调用了三千次……”
  - 死循环妖：“三千次？不够！”
- **声音：** 同一句台词以不同延迟叠加，制造循环压迫。
- **转场：** 所有分身同时转头，办公室灯光熄灭。

### 镜头07｜0:44—0:52｜权限魅影贴近

- **景别：** 近景
- **机位：** 过客背后低机位，缓慢向肩侧推进
- **画面：** 黑雾从画面四角汇聚到过客耳边，雾中登录头像不断变换。
- **动作：** 过客突然回头，身后空无一人；黑雾在另一侧闪现。
- **对白：**
  - 权限魅影：“我删掉了审计日志，也拿走了管理员权限。现在，谁能证明我来过？”
  - 过客：“访问记录不会凭空消失。”
  - 权限魅影：“那就让它们一起消失。”
- **声音：** 低声耳语左右声道移动，增强隐身感。

### 镜头08｜0:52—1:00｜三魔同框与现实压力

- **景别：** 全景构图
- **机位：** 正面固定，三块屏幕构成垂直层级
- **画面：** 上方黑洞王、左下死循环妖、右下权限魅影；过客居中，电话仍贴在耳边。倒计时“00:18:42”。
- **对白：**
  - 林岚：“监控中心问是不是你改坏了权限！”
  - 过客：“不是我。”
  - 林岚：“我知道。但你得拿出证据。”
  - 过客：“证据被它们吃了。”
- **表演：** 过客第一次直视屏幕里的魔头，但身体仍被压在椅子上。
- **音乐：** 低频鼓点第一次进入。

### 镜头09｜1:00—1:08｜过客开始反击

- **景别：** 手部特写 → 中近景
- **机位：** 键盘上方俯拍，跟随手指移动到脸部
- **画面：** 三个终端窗口依次打开：限流、缓存隔离、异常权限回收。
- **动作：** 过客屏住呼吸，连续执行三条命令。
- **对白：** 过客：“先限流，再隔离缓存，最后回收异常权限。”
- **声音：** 键盘节奏与鼓点同步加速。
- **转场：** 三个窗口同时闪出绿色进度条。

### 镜头10｜1:08—1:15｜第一次小爽点

- **景别：** 蒙太奇快切
- **机位：** 三个极短特写，每个约2秒
- **画面：** 死循环分身减少；黑洞王腹部被隔离框撑住；权限魅影露出半截手臂。
- **动作：** 过客微微抬头，第一次露出“抓到你了”的神情。
- **对白：**
  - 过客：“抓到了！”
  - 林岚：“恢复了吗？”
  - 过客：“恢复了一个节点。给我十秒，我能把它们全锁——”
- **声音：** 绿色成功音只响半秒，随即被刺耳反扑音盖住。

### 镜头11｜1:15—1:23｜补丁被反杀

- **景别：** 中景
- **机位：** 低角度仰拍三魔，过客位于前景下方
- **画面：** 三大 Bug 同时反扑：黑洞吞回隔离区，分身暴涨，黑雾擦掉刚出现的日志。
- **对白：**
  - 内存黑洞王：“一个补丁，也敢叫修复？”
  - 死循环妖：“你堵住一个，我就生出一百个！”
  - 权限魅影：“你抓到的，只是我允许你看到的影子。”
  - 过客：“这不是三个独立故障……”
- **表演：** 过客由抬头变成僵住，意识到问题比想象更深。

### 镜头12｜1:23—1:31｜根因级灾难提示

- **景别：** 超近特写
- **机位：** 正面锁定屏幕，轻微故障跳帧
- **画面：** 所有窗口同时黑屏，红色倒计时跳到“00:00:59”，电话断开。
- **动作：** 过客站起来，第一次失控喊出林岚名字。
- **对白：** 过客：“林岚？林岚！”
- **声音：** 所有环境声突然抽空，只剩服务器风扇。
- **转场：** 黑屏中央出现一条金色细线。

### 镜头13｜1:31—1:42｜信息钩子

- **景别：** 近景 → 超近特写
- **机位：** 从过客侧脸推向屏幕
- **画面：** 金色细线展开成古老眼睛图标，文字逐字出现：“检测到根因级灾难。检测到唯一适配者：过客。”
- **动作：** 过客的脸被金色文字照亮，手指停在确认按钮上方。
- **对白：** 过客：“我只是想修个 Bug，怎么还得上天？”
- **声音：** 低沉金属提示音，远处出现若有若无的战鼓。
- **文字：** “是否启动——大圣协议？”

### 镜头14｜1:42—1:52｜主动选择

- **景别：** 半身近景
- **机位：** 正面微仰拍，背景三大魔头形成暗影
- **画面：** 三个按钮/警告窗口在过客身后重叠，三大 Bug 的脸像审判者一样压在上方。
- **对白：**
  - 三大 Bug 魔头：“你不敢。”
  - 过客（抬眼）：“我最不缺的，就是加班。”
- **动作：** 过客从悬停改为坚定按下“确认”。
- **声音：** 按键声被放大，所有报警声瞬间静音。

### 镜头15｜1:52—2:00｜大圣协议觉醒卡点

- **景别：** 超大全景 → 金色强光
- **机位：** 以过客为中心向后拉远，代码从中央向上下延展
- **画面：** 金色代码沿过客手臂攀升，工牌在强光中保留；办公室、服务器和城市碎裂成代码星河。一只金色手掌握住由代码编辑器变形的长棒。
- **对白：**
  - 系统提示音：“大圣协议，启动。”
  - 过客（画外音）：“既然你们把代码世界变成了妖界，那我就亲自来当一回——齐天大圣！”
- **声音：** 键盘声转为编译成功音，随后一记战鼓。
- **转场：** 金光闪白，切黑。
- **片尾文字：** “下集：我这一棒，叫代码重构。”

| 时间 | 声音设计 |

| 0:19—0:52 | 回滚失败音、黑洞吸入声、循环回声、耳语声 |
| 0:52—1:15 | 低频战鼓逐渐增强，绿色成功音短暂出现 |
| 1:15—1:31 | 三魔反扑音、电话断线、环境声抽空 |
| 1:31—1:52 | 金属提示音、低沉战鼓、呼吸声 |
| 1:52—2:00 | 按键静音、金色编译声、战鼓、强光冲击 |

## 四、连续性与制作验收

- 第1镜的红色故障界面必须与剧本中P0级故障一致。
- 第8镜三魔位置固定，后续第2集可作为三大 Bug 能力的视觉识别基础。
- 第10镜只能短暂恢复一个节点，不得让观众误以为系统已解决。
- 第13镜必须清楚读出“唯一适配者：过客”，这是第2集身份觉醒的直接依据。
- 第15镜必须保留过客工牌，确保现实程序员身份没有被金甲完全覆盖。
- 最后一帧只展示金色手掌和代码金箍棒，不提前展示完整大圣造型，把完整亮相留给第2集。

## 五、竖屏生成与剪辑提示

- 画面主体尽量保持在中轴线，三魔同框时使用上下分层而非横向铺开。
- 所有系统文字采用短句、大字号、高对比度，确保手机端可读。
- 镜头1、5、14、15为视觉重点，建议保留更长的特效反应时间。
- 镜头6、10、11使用快切，避免三种 Bug 的差异被拖慢。
- 现实段落剪辑偏硬切，代码世界转场使用故障撕裂和金色编译光。
